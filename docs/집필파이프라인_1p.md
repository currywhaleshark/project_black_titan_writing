# 연재 집필 공정 — 1장 요약

> 설계는 **위에서 아래로**, 기억은 **아래에서 위로**. 승인된 변화가 다음 화의 진입 상태가 될 때 한 회차가 끝난다.

## 1. 충돌이 나면 위가 이긴다 — 섞지 않는다

`① 지금의 사용자 지시 → ② 설정집·전체 플롯 → ③ 승인 상태·선례대장·승인 본문 → ④ 이번 브리프 → ⑤ 구고 = STYLE_ONLY`

작중 인물의 설명은 정본이 아니다(누가 누구에게). 최근 회차는 인물의 규정이 아니다(규정은 대개 옛 회차에 있다).

## 2. 계층과 관문

| 계층 | 산출물 | 관문 |
| --- | --- | --- |
| L0 | 바이블 · 문서 레지스트리 | **0** 정본 개정 — 영향 문서를 `KEEP/REVISE/RETIRE/REBUILD`로 전수 분류 |
| L1–L3 | 전체 → 대단위 → 소아크(4~6화) | **A** 플롯 |
| L4 | 화별 개요 — A/B/C · 변화 · 훅 | **B** 개요 |
| L5 | 회차 브리프 · 씬 · **비트 표** | **C** 브리프 |
| L6 | 내용 잠금 · 문체 · 말투 카드 · 공간 시트 | — |
| L7 | 본문 · 검사 · 교차검증 | **D** 본문 |
| L8 | 델타 · 상태 갱신 | **E** 정사 |

표준 화는 B·C 묶음 승인, 중요 화는 개별(지정은 Gate A에서). **같은 단계에서 두 번 반려되면 한 단계 위를 고친다.**

## 3. 회차 루프 8단계

| | 단계 | 지키는 것 |
| --- | --- | --- |
| 1 | **정본 스윕** | 브리프보다 **먼저**. 인물 전원·**방** 단위 장소·소품·회고 사건. 지면 문장 그대로 인용 |
| 2 | 개요 | A는 매 화, B·C는 쉬어도 되되 **마지막 진전 화**를 기록 |
| 3 | 브리프 | 진입 상태·욕구·방해·전환점·공개/은폐·종료 변화·다음 동기 + **비트 표** |
| 4 | 내용 잠금 | 잠근 **뒤에** 문체 검색. 인물 전원 말투 카드 열기. 전투는 전장 구조 먼저 |
| 5 | 초고 | **처음부터 목표 분량.** 대사는 청자를 정하고 쓴다 |
| 6 | 기계 검사 | 분량·문체 밴드 / 말투 / 번역투 / 정합·축자중복 / 금칙어 |
| 7 | 교차검증 | **작성과 분리된 패스.** `FAIL` 하나면 Gate D 금지 |
| 8 | 델타 → 상태 | 6~8은 **한 트랜잭션**. 반려안은 공식 기억을 안 바꾼다 |

**비트 표** — 목표 자수 ÷ 비트당 자수 = 필요 비트 수. 새 사실·새 동작·새 판단·대사 한 덩이만 비트다. **마감 씬부터 채운다.** *사전에 세우면 비트, 사후에 붙이면 분량.*

## 4. 기억 — 저장은 무손실, 컨텍스트는 의도적 손실

| 층 | 갱신 |
| --- | --- |
| 불변 정본 | 사용자 지시로만 |
| **현재 스냅샷** | 승인마다 **교체**(누적 요약 금지) |
| 활성 스레드 | 마지막 진전 화·예상 구간 |
| **회차 델타** | 변한 것만 = 감사 추적 |
| 아크 캡슐 | 8~12화 |
| 전체 아카이브 | 컨텍스트 밖 |

**델타 3원칙** — 해석 말고 사실 / 지식 비대칭 보존(「가족이 안다」 금지) / 파손·분실·소모·수리를 구분.
**10화마다 체인 감사** — 델타로 재구성해 스냅샷과 대조. **요약에만 있는 사실**을 찾는다.

**컨텍스트 조립** — 정본 발췌 → 스냅샷 → 아크 캡슐 → 관련 스레드 → 최근 2~3화 델타 → 브리프 → 말투·문체 카드.
넘치면 **해결 이력 → 무관 정본 → 문체 예문 → 오래된 델타** 순으로 뺀다. 상태 압축은 최후.
떡밥의 **최종 진실은 생성 컨텍스트에 넣지 않는다** — 허용/금지 공개치만.

## 5. 회차가 남기는 것

승인 본문 · Gate D 검증서 · 델타 · 상태 스냅샷 · 떡밥 트래커 · **등장 대장** · Gate E 반영서 · 프로젝트 상태 갱신 · 리뷰 페이지 재발행.
승인 요청은 **사용자가 읽는 매체에 먼저** 올린다.

## 6. 규칙이 쌓이는 자리

행동 규칙 → 상시 가드 · 인계서 / 지면 사실 → **선례대장** / 기계로 잡히는 것 → **검사기**(임계값은 승인본 전수 실측).

**지적은 계통으로 본다**(한 곳이 틀렸으면 전 회차를 쓸어 본다). **「정독한다」로 안 지켜지는 규칙은 도구로 강제한다.**

## 7. 새 작품 — 채울 슬롯과 만드는 순서

**슬롯** 반복 루틴 · 대단위 축 · 회차 규격(자수/씬) · 비트 밀도 · 문체 밴드 · 말투 표 · 금칙어 · 공간 시트 · 말투 카드 · 적 시트(원형/**치명 — 수단·조건·대가**/목적) · 감시목록

**순서** ① 권위 순서·레지스트리 ② 스냅샷·델타 양식 ③ 관문 A~E → ④ 정본 스윕 도구 ⑤ 브리프·비트 표 ⑥ 말투 카드·검사기 ⑦ 선례대장 → ⑧ 문체 밴드 ⑨ 아크 캡슐·압축 감사

**①~③이 없으면 나머지는 무의미하고, ④~⑦이 실제 사고를 가장 많이 막는다.**
