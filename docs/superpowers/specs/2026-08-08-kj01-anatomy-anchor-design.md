# KJ-01 괴수 구조 앵커 재제작 설계

## 목표

KJ-01 회수형 괴수의 블렌더 목업을 구조적 단일 기준으로 삼아, 각도에 따라 다리 수·집게 위치·몸통 비례가 바뀌지 않는 일반적인 2D 애니메이션 스타일의 시각 앵커를 제작한다.

## 확정 기준

- KJ-01은 생물이 아니라 기계다.
- 전장 약 70m다.
- 상체를 들어 올린 자세에서 최대 높이가 약 30m다.
- 보행 다리는 좌우 4개씩, 총 8개다.
- 굵은 압쇄 집게는 **괴수 자신의 왼팔**이다.
- 가는 절단 집게는 **괴수 자신의 오른팔**이다.
- 괴수를 정면에서 보면 굵은 집게는 **화면 오른쪽**, 가는 집게는 **화면 왼쪽**에 보인다.
- 표면은 암적색·검붉은 기계 장갑, 내부 구조는 검게 막힌 형태다.
- 전면의 녹색 두 점은 눈이 아니라 오목하게 들어간 고정 발광부다.
- 따개비는 70m 크기에 비해 작고 드물며, 해조류는 가늘고 성기게 붙는다.

## 자료의 우선순위

1. 블렌더 목업: 실루엣, 몸통 구조, 관절, 다리 수, 집게 크기와 위치
2. 설정 문서: 크기, 재질, 기능, 생물처럼 보이지 않아야 한다는 규칙
3. 기존 v3 생성본: 색감과 일반적인 2D 애니메이션 선화만 참고

기존 v3의 몸통 형태나 집게 해석은 구조 참고로 사용하지 않는다.

## 선행 교정

현재 블렌더 좌표 정의는 `+Y`를 전방으로 두면서 `+X`를 해부학적 왼쪽이라고 표기해, 정면 카메라에서 굵은 집게가 화면 왼쪽에 나타난다. 제작 전에 다음과 같이 교정한다.

- 해부학적 왼쪽을 `-X`, 오른쪽을 `+X`로 정리한다.
- 압쇄 집게를 `-X`, 절단 집게를 `+X`로 옮긴다.
- 정면 카메라는 `+Y`에서 괴수를 바라보게 유지한다.
- 교정 후 정면 렌더에서 압쇄 집게가 화면 오른쪽인지 검수한다.

## 제작 방식

다각도 시트를 한 번에 생성하지 않고, 각도를 한 장씩 확정한 뒤 마지막에 조립한다.

1. 교정한 블렌더 정면 3/4 렌더로 2D 애니메이션 스타일 앵커를 만든다.
2. 실루엣·집게·다리·상체 상승 자세가 목업과 일치하는지 검수한다.
3. 승인된 앵커와 각 각도의 블렌더 렌더를 함께 참조해 정면, 측면, 후면을 각각 생성한다.
4. 모든 각도의 구조가 일치한 뒤 설정 시트로 조립한다.

## 생성 제약

- 각 생성에는 해당 각도의 블렌더 렌더만 구조 기준으로 넣는다.
- 압쇄 집게와 절단 집게의 형태 차이를 과장해 서로 바뀌기 어렵게 한다.
- 보이지 않는 반대편 다리를 임의로 추가하지 않는다.
- 유기적인 갑각, 살, 눈, 입, 촉수처럼 해석되는 요소를 금지한다.
- 여러 각도와 문자 레이아웃을 한 번에 생성하지 않는다.
- 문자와 수치는 생성 이미지에 맡기지 않고 후편집으로 넣는다.

## 합격 조건

- 정면에서 압쇄 집게가 화면 오른쪽에 있다.
- 모든 각도에서 같은 팔에 같은 집게가 연결된다.
- 보행 다리가 총 8개이며 좌우 각 4개다.
- 압쇄 집게와 절단 집게의 체급 차이가 즉시 구분된다.
- 몸통과 다리의 주요 실루엣이 블렌더 목업과 일치한다.
- 상체를 들어 올린 기계 회수체로 읽히며 생물로 보이지 않는다.
- 기존 v3의 구조로 회귀하지 않는다.

## 선택한 접근과 제외한 접근

선택한 방식은 **단일 각도별 생성 후 시트 조립**이다. 직접 다각도 생성은 구조 변동이 크므로 제외하고, 블렌더 툰 렌더만 사용하는 방식은 정확하지만 최종 2D 애니메이션 삽화와의 화풍 연결이 약해 보조 수단으로만 사용한다.
