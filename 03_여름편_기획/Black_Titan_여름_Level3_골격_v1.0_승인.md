## 1. 시즌 척추 (필수 비트 — v2.2 + 사용자 확정)

1. **아이언 앵커 첫 출현(v2.2 §4-2 고정):** 속도형 등각류전 데뷔.
   좌측 하박 로켓 앵커(세포기원 소재·사슬 역장 연동 — 원리는 작가용).
   영진 코칭 문면: **`무기를 쏜다고 생각하지 마라. 왼팔이 길어진다고
   생각해`** — 신체이미지 확장 실패→수용의 아크. 단 **속도형 ≠ 여름
   첫 적**(사용자): 공격 의도 노출·맨손 한계가 먼저
2. **통증성 피드백 누출(v2.2 §5-1):** 여름 중반 — 코너에 몰려 감정
   격화·연결 강화 상태에서 피격 압력·관절 부하가 **통증으로 돌아옴**
   (누적 신경손상과는 구분 — 작가용). 상대 = **공작갯가재형(사용자
   확정)**. 감각 설계(사용자): `정말로 한 대 맞았나` 싶은 **눈의
   불꽃** — 주먹을 직접 주고받는 착각 속에서 심도가 깊어짐. **직후
   비트(v2.2):** 귀환 후 흥분이 안 풀린 단아가 `설정값·감도가
   잘못됐다`며 영진에게 날카롭게 항의 — 영진은 표면상 보정 약속,
   내심 의심
3. **수아 첫 출격(v2.2 §5-3):** 통증 사건 후 증상 급속 악화 → 영진이
   단아 **출격 정지** → 공백에 전투형 출현 → 수아 탑승. **반응 지연이
   예상보다 짧음**(몇 차례는 결심 순간 즉각 기동 — 보정 차이로만
   수용·원인 봉인). 수아 전투 문법 = 지형·사슬·앵커 궤도 계산.
   이후 **대체출격 띄엄띄엄 반복(사용자)** — 지연 더 짧아짐·신체
   해방감·내밀한 쾌감(동조 강도 징후 — 타락 아님)
4. **자매의 미묘한 경쟁(v2.2 §5-4):** 단아 = 안도+열등감·경쟁심 /
   수아 = 자부심+숨기는 쾌감. 다정함은 유지·말과 표정에 작은 가시.
   영진 = 죄책감 심화(보호 장치가 아이들을 병기로)
5. **혜정 위기상황 플롯(v2.2 §5-2 — 전문 확보):** 패턴 인지(출현
   때마다 사라짐·다음 날 앓아누움) → 집 방문 → **미행 1회 → 수리점
   근처 군용급 기자재 목격** → 예진 만류 → **삼촌 명준에게 상담**
   (`군에서 어린애에게 위험한 일을 시키는 경우도 있느냐`) → 명준이
   결석 시점·구래동 정보와 작전 기록의 겹침 감지 → **구래동 검문·
   순찰 강화·수리점 접근** → 영진·단아 간신히 은폐 → 혜정 자책·
   예진이 관계 붙듦 → **군 확증 실패·위기감만 남김**
6. **여름방학 마지막 날 = 관통상·데뷔·해체(v2.2 §5-6~5-8 — 중간점):**
   외형상 약해 보이는 전투형(**사용자: 관통 촉수 계열로 설계** —
   모티프는 조정 가능 항목) 출현 → 단아 = 몸살+경쟁심의 **심통 섞인
   결정 `오늘은 네가 나가라`** → 수아 우세→승리 확신→**쓰러진 척하던
   괴수가 요추 관통** → 순환액 노출(기계가 아니라는 첫 노골적 노출 —
   C2 지불) → 완전동조 근접 상태의 수아 = 격통·실신·**하반신 회복
   불가 손상** → 단아 = 모니터로 지켜보며 절규 → **화이트 센티널
   데뷔(그레이트 마징가 문법):** XLG-5 유선유도 미사일이 역장을 뚫고
   직격·USS CARVER 전개·압도적 제압 → **고명준의 확보:** 수아 병원·
   단아 보호시설·영진 구치소·타이탄 남방사 격납고(무반응) — **가족
   해체 클리프행어로 시즌 종료**(가을 = 붕괴와 재구성)

## 2. 확정 설계 (사용자 + v2.2)

- **여름 첫 적 = 성게형 재래(개수형·사용자):** 가시 사격 — 투사체
  무효(현상만·역장 서술 금지 유지)·맨손의 답답함 각인. 가시 조각
  회수 창구
- **아이언 앵커 = 기태 조달품 조립(사용자):** 고철의 재간(영진
  제작·기태 소싱). v2.2 원리(세포기원·역장 연동)는 작가용 층위
- **재검 6월 = 여름 첫 생활 화(사용자):** 이상 없음 판정 후 시즌에
  걸쳐 꺾기
- **기후·복장 정본(사용자):** 온난화 진행 세계 — 6월 = 이미 한여름
  (`초여름` 어휘 금지). 교복 없음(초등 사복)
- **몸살 증상 정본(v2.2):** 갑작스러운 열·시야 흐림·손발 저림·맛과
  소리가 잠깐 사라짐 — 주변 해석 = 과로·여름감기(작가용 = 면역거부성
  신경손상). ※ 저림·흐림 어휘 = 봄 금지어였음 — **여름 해금 시점을
  Level 4에서 잠금**(부인 가능 구간에서는 유지)
- **현서 암시 = 우편물(사용자·C3와 별개)** / **센티널 암시 = 외신 한
  줄 + 푸른 슬릿 한 컷(관통상 직전 화 훅)**
- **적 행동 원칙(사용자):** 회수 목적 유지 — 방해물 정리 후 탐색
  재개. 톡토기형 = 동시 진행 실험(놓친 한 놈이 학교로)
- **학교 파손 정본(v2.2):** 체육관+교실 일부 — 전면 폐쇄 아님·임시
  교실·냉방 부족·바뀐 동선·복구·보호자 불안이 **여러 화에 걸쳐
  일상에 잔류**(봄 = 성호 한 사람의 몸 → 여름 = 공동 생활공간)
- **주호 수위(사용자 확정):** 단아가 **뭔가 힘든 일을 짊어지고
  있다는 것까지는 눈치챔** — 정체 추리·질문 0, **조용히 할 수 있는
  지원을 해 주는 역할**(봄의 무언 배려〔상체 종목·딱 한 타〕 계보의
  확장: 결석 처리·과제 유예·자리 배려 등 담임의 재량 층위)

## 3. 국면 배치 (v2.2 통합)

### 국면 A — 재검과 재래 (6월 초~중순, 약 8~10화)

- 재검(이상 없음)·학교 일상 복원(바이올린·동그라미·떡볶이 창구)
- **성게형 재래전** — 첫 공격 의도·투사체 무효·맨손의 답답함
- **농게형전(v1.1)** — 거대 집게발과 **주고받는 첫 육탄전**(공격
  의도의 근접판 — 봄의 회수 동작과 확실히 다른 `치고받기`). 승리하되
  집게의 위력 각인(합성 1호 보완 서사의 밑돌)
- 군 공세 전환 기록·**외신 한 줄(사다리 1단)**

### 국면 B — 고철의 재간 (6월 하순~7월 초, 약 10~14화)

- **투구게형전(질량)** — 한계 2연타 → **앵커 개발 아크**(기태 조달품)
- **따개비형전(인프라 공성)** — 방재벽·수문 고착을 맨손으로 뜯어내는
  소모전(앵커 필요성 3연타)
- **등각류전 = 앵커 데뷔**(v2.2 §4-2: 조준·신체이미지 실패 → `왼팔이
  길어진다고 생각해` → 붙잡기·사슬 투척·클로 — 몸의 확장으로 승리)
- **현서 우편물(암시)** 배치 후보

### 국면 C — 통증과 균열 (7월 중~하순, 약 12~16화)

- 연전(딱총새우·갯지렁이·**갑오징어〔은신전〕**·톡토기 — 간격 단축·
  심도 상승 누적: 처음엔 이점처럼)
- **톡토기형 = 학교 파손**(체육관+교실 일부 → 임시 교실 일상 개시)
- **공작갯가재형 = 통증 첫 체감** → 귀환 후 `설정값 항의` 비트
- **혜정 플롯 개시:** 패턴 인지 → 집 방문 → 미행·기자재 목격
- 몸살 전조(열·감각 이상의 산발 — 과로/여름감기 해석)
- **방학식**(7월 말 — 이후 방학 국면)

### 국면 D — 꺾임과 검문 (8월 초~중순, 약 12~16화)

- **통증 사건 후 악화 → 출격 정지 → 수아 첫 출격 — 상대 = 바닷가재형
  개수(확정):** 봄 첫 적의 전투형 재래를 동생의 첫 전투에서(즉각
  기동의 위화감 — 봉인. 수아 문법 = 지형·사슬·앵커 궤도 계산) →
  **대체출격 띄엄띄엄 반복**(단아 복귀↔재이탈). 가오리형(비행 —
  앵커 사거리전)도 이 국면
- **자매의 작은 가시**(§5-4) + 영진 죄책감
- **크릴형전 = 군의 첫 승리(확정 — 여름 후반):** 물량·군체(피난
  방해)·타이탄 타격 무효 → 고폭탄 유효. **전투 격화 속 군의 `결심`
  계기** — E 국면 확보 판단(즉시 투입)의 개연성 축
- **혜정 플롯 절정:** 삼촌 상담 → **구래동 검문·순찰 강화·수리점
