## 1. 아크 상위 잠금

- **달력(확정):** 5/18(수) 봄 종료 → **약 2주 경과 → EP41 = 6월
  첫째 주(6/7 화 전후) 재검.** S8 = 6월 초~중순(1학기 계속)
- **기후·복장 정본(사용자 2026-08-12):** 온난화가 한참 진행된 세계 —
  **6월 초 = 이미 한여름 날씨**(`초여름` 어휘 금지·폭염/스콜 계보는
  봄 EP29부터 정합). **교복 없음 — 초등 사복**(전 시즌 공통)
- **2주의 공백(작가용):** 적이 **새 방향을 모색하는 시간**이 필요했음
  (재분류 후 전투형 준비 — 해설 0). **지면 = `그간 잠잠했다`까지만**
- **적 전환의 노출 곡선:** 지면은 `공격당했다`는 사실까지 — 재분류·
  목적 해설 0(작가용). 군 기록 = `행동 양상 변화` 층위
- **투사체 무효 = 현상만:** `맞는데 뚫리지 않는다`·불꽃·물보라는
  일되 피해 0(역장 서술 금지 유지 — G0-010 계보)
- **개수(改修) 흔적 = 위화감 층위:** 낯익은 놈이 다르게 왔다는 감각
  (단아 = 몸으로, 수아·영진 = 가시 조각 대조로). 원리 해설 0
- **암시 사다리 1단:** 외신 한 줄(태평양 건너 함대 — 무해한 구석
  기사 결). 이 아크에서 1회만
- **상시 가드 전부 유지:** 전투 톤(균열 2~3)·자신감(봄 최고점에서
  출발 — 첫 피격의 동요는 균열로)·수아/혜정 톤·장소·숫자·시간 지시어
- **금지:** 저림·흐림 어휘(해금 전), 몸살 전조(S10 몫), 센티널·현서
  암시 과다(1단 1회만), 앵커 관련 일체(S9 몫 — 필요성의 `느낌`까지만)

## 2. 개체 잠금

### 성게형(개수 — 재래)

- **정체:** 봄 S2에서 굴려보내고 생사 확인이 안 된 그 개체(영진·군
  기록 층위로 동일성 암시 — 확정 명언은 가시 조각 대조 창구에서)
- **외형(확정):** G0-012 기반(반구형 흑색·따개비 질감·녹색 점광) +
  **개수 흔적: 가시 재정렬·발사 기부가 두터워짐·가시 끝이 작살
  모양으로 변형**(꽂히기 위한 형태라는 위화감 — 해설 0)
- **행동:** 원거리 가시 사격(연사·조준 보정), 접근 거부 기동(봄의
  부동과 대비 — 이동함), 회수 목적 잔존(도시 아닌 기체 조준)
- **약점 구도:** 투사체 무효 확인 후 = 접근전 강행이 답 — 단 가시
  발사 간격과 재장전 리듬을 몸으로 읽어야 함(단아 문법)
- **격파(확정):** **`다시 굴려보내면 또 나타난다 — 이번에는 격파한다`**
  는 마음가짐 → 접근 후 **손에 닿는 대로 가시를 부러뜨리고** → 몸통
  노출 → **주먹으로 계속 내려치기.** ※ 아직 격투의 감각(정권 지르기)
  아님 — **부서질 때까지 단순히 내려치는 것**(여름 격투 성장 곡선의
  출발 눈금 — EP48 `주고받기`·이후 국면과 대비)
- **지면 지칭:** `가시 쏘는 놈`·`그 공` 계열(작가용 `성게형` 금지)

### 농게형(신규 — 첫 육탄전)

- **외형(확정):** **비대칭 두꺼운 집게가 포인트**(한쪽이 몸통만 한
  거대 집게·반대쪽은 왜소)·갑각·저지대 보행
- **행동:** **집게 타격 — 치고받는 첫 상대**(봄의 회수 동작〔잡기·
  끌기·굳히기〕과 명백히 다른 `때리기`). 방어에도 집게 사용(가드
  개념을 가진 첫 상대)
- **격파(확정):** 육탄전 승리 — **집게 관절 역방향 꺾기**(주고받다
  잡아낸 팔을 반대로 꺾는 육탄전다운 마무리). 집게의 위력 각인
  (맞으면 밀려나는 첫 경험 — **합성 1호 보완 서사의 밑돌**)
- **지면 지칭:** `집게` 계열

## 3. 화별 개요 (EP41~50)

### EP41 「재검」 — 생활(개시 화)

- **A:** 6월 첫째 주 재검 — 시력·신경 반응 검사. **이상 없음**(안경
  도수 유지). 병원 가는 길의 여름 공기(초여름 완성)
- **B:** 재검 결과에 안도하는 가족(영진 = 장부의 여백은 그대로 둠 —
  무언). 떡볶이 청구권 회수(혜정 수금 — 이자 논쟁 결말)
- **훅:** 밤 수리점 — 새 장부의 첫 장을 펴는 영진. 부표 그래프는
  잔잔. `잔잔한 것을 믿기로 한` 여름의 첫 페이지
- 협의 ⑤: 동그라미(가방 2호) 회수를 이 화에 넣을지 EP42로

### EP42 「발표 주간」 — 생활(수아 라인)

- **A:** 하랑 바이올린 발표(**앵커 필수** — 간격 14). 수아의 방과후
  라인 복원·관객석의 가족
- **B:** 학교 일상 완전 복원(성호 재활 진전 — 달리기 요구 재청구
  예고), 동그라미 회수(협의 ⑤)
- **훅:** 외해 관측 — 낯익은 결의 신호 하나(영진, 옛 기록을 꺼내
  대조하기 시작 — 명언 0)

### EP43 「낯익은 신호」 — 전환

- **A:** 영진의 대조 — 봄 기록과 겹치는 이동 패턴(굴러가던 놈의
  결). 군 공개 통지(외곽 통제 재개 — 봄 문법의 재가동)
- **B:** 수아 = 가시 조각(선반 아래 통)을 꺼내 오는 손(대조 준비 —
  확인자 문법 재가동). 학교 = 통제 소문의 온도
- **훅:** 방재벽 밖 수면 — **물을 가르며 접근하는 반구형 실루엣.
  봄과 달리, 멈추지 않고 곧장 온다**

### EP44 「다른 여름」 — 전투(중요 화 후보)

- **A:** 출격·조우 — **첫 가시 사격**(봄에 없던 것: 이쪽을 겨냥해
  쏜다). 첫 피격의 충격(자신감 봄 최고점에서의 첫 동요 — 균열 축)
  → **투사체 무효 발견**(맞는데 뚫리지 않는다·현상만·놀라움은 그대로)
- **A2:** 무효인데도 무서운 이유(쏜다는 사실 자체 — 의도의 공포).
  원거리 상대에 맨손이 닿지 않는 답답함 개시
- **훅:** 가시 연사 속에서 접근 각을 재는 단아 — 발사 간격의 리듬이
  들리기 시작

### EP45 「빗속을 걷는 법」 — 전투(격파)

- **A:** 간격 읽기 → 접근전 강행 — `이번에는 격파한다` 결심(굴려
  보내면 또 온다) → **가시를 손에 닿는 대로 부러뜨리고 몸통 노출 →
  부서질 때까지 내려치기**(정권 아님 — 원시적 타격). 용해
- **B:** 격파 직전/직후의 위화감 — 낯익은 축·낯선 배열(개수 흔적 —
  몸의 감각 층위)
- **훅:** 귀환 후 — 수아의 가시 조각 대조: **`봄에 그놈이에요.
  근데 가시가 달라요`** 계열(사실만 — 확인자 문법)

### EP46 「기록의 온도」 — 생활(후처리)

- **A:** 군 기록 = 행동 양상 변화 기록(공격 행동 첫 기재·`미식별
  검은 거인` 문법 유지). **외신 한 줄(사다리 1단)** — 인트라넷 뉴스
  구석
- **B:** 학교 소문(공격당했다더라 — 검은 거인 걱정 여론의 결),
  혜정·예진 수다 창구(수다 가드), 영진 = 새 장부가 두꺼워지기 시작
- **훅:** 남쪽 얕은 물 — 다른 결의 신호(집게형 접근 예고)

### EP47 「집게」 — 전환·전투 진입

- **A:** 농게형 출현 — 상륙 국면(방재벽 근접·거대 비대칭 집게의 첫
  실루엣). 출격
- **A2:** 첫 접촉 — **저놈은 때리러 온다**(회수 동작 문법과의 차이를
  몸이 먼저 인지). 첫 합 교환
- **훅:** 정면에서 마주 선 두 실루엣 — 집게가 들리는 순간

### EP48 「치고받기」 — 전투(중요 화 후보)

- **A:** **첫 육탄전 교환** — 때리고 맞는 싸움(봄에 없던 문법: 가드·
  카운터·맞으면 밀려남). 집게의 위력(첫 넉백 계열 경험)
- **A2:** 승리 — 그러나 `주고받는` 싸움의 값을 처음 지불(피로·충격
  잔향. 통증 아님 — S10 예약과 명확히 구분)
- **훅:** 쓰러진 집게를 내려다보는 단아 — `여름 것들은 다르다`의
  확정(문면 협의)

### EP49 「여름의 셈」 — 생활(후처리·아크 정리)

- **A:** 연이은 두 전투의 후처리(세척·점검 일상 — 봄 계보의 재가동)·
  가족의 저녁
- **B:** 성호 재대결 재청구 비트(B~C 창구 예고)·학교 일상. 혜정 =
  아직 평온(패턴 인지 전 — S10 예약)
- **훅:** 영진의 장부 — 두 출현의 간격을 적는 손. **봄보다 짧다**

### EP50 「간격」 — 아크 마감

- **A:** 생활과 관측의 교차 — 도시의 여름(폭염 초입·수산시장 결).
  군 = 공세 전환 판단 기록(내부 층위)
- **B:** 가족 회의 결(명시 회의 아님 — 각자의 준비: 영진 = 조달
  목록을 적기 시작〔**앵커의 씨앗 — 명명 0**〕, 수아 = 기록 체계
  확장, 단아 = 몸 만들기)
- **훅(S9 인계):** 외해 — **크고 느린 질량의 신호**(투구게형 예고).
  들어오는 것들의 간격이, 확실히, 좁아지고 있다
