## 4. 이 회차가 한 일

### 4-1. ★★★★★★ 축은 「닫히지 않는 칸」

> **[EP126]** 값이 맞았다. **맞으면 확인할 것이 없다.** (…) **열일곱 개가 다 닫혔다.**

| 오늘 | |
| --- | --- |
| 개체 처리 | **판정 불가** |
| 사상자 | **★★★★★ 빈칸** — `0은 확인한 값이고 저기는 확인한 것이 없다` |
| 교전 시간 | **종료 없음** |
| 사용 무장 | **넷 중 둘** |
| XLG-5 | **★★★ 잔여 넷 — 받은 것을 그대로 갖고 돌아간다** |

### 4-2. ★★★★★★ 딘이 결론을 안 받쳐 준다

> `딘, 전위 벽면 등반 소요.` / **`해당 기체 자료 없음.`**
> `딘, 블랙 타이탄 기동 판정.` / **`해당 기체 자료 없음.`**

**★★★ 「할 수 있는데 안 했다」는 루시 혼자 선 결론이다.**
**★★★★★ 서술자는 정정하지 않는다.** 딘이 값을 안 주는 것으로 독자가 안다.

**근거는 EP139에 있다** — 어제 **서식으로 물어서 받은 값만** 갖고 있고,
`그런데 있잖아요`로 시작하는 문장은 잘랐다. **★★ 그 연결은 지면 0.**

### 4-3. ★★★★★★ 시간은 지켰다

> **`스물여덟 초였다.`** · **`삼십 초를 줬고 스물여덟 초에 끝났다. 시간은 지켰다.`**
> **`요청한 것을 다 했다. 벽을 올랐고, 팔을 뻗었고, 걸었다. 걸린 데가 부러진 데였을 뿐이다.`**

| 회차 | |
| --- | --- |
| EP133 | 시켜도 못 했다 |
| EP140 | 거기까지 해 줬는데 못 갔다 |
| EP141 | 아무도 안 시켰는데 갔다 |
| **★★★★★★ EP142** | **갔다. 했다. 시간도 지켰다. 그런데 아무것도 안 됐다** |

### 4-4. ★★★★★ 안 묻는 물음 둘

> **`아까는 왜 안 왔습니까.`** / **`지금은 되고 아까는 안 됐던 것이 무엇입니까.`**
> **`둘 다 서식에 없는 물음이었다. 물으면 대답이 오고, 오는 대답을 적을 칸이 없다.`**
> **`그래서 셋만 말했다.`**

**★★★ 「왜 막았습니까」가 감정이 아니라는 것이 여기서 증명된다.**
