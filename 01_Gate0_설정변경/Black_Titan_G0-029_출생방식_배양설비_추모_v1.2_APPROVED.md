## 7. ★★★★★★ EP145 설명 범위 (사용자 확정)

> **[사용자]** **「141에서 나온 내용과 1차 거체 배양, 통제 실패 후 폐기(실패를 우려해 내부에 소각 수단을
> 마련했다는 걸로, 외부의 손상은 막지만 내부는 막지 못함) 남은 신경세포로 단아를 만들고
> 2차 배양으로 블랙 타이탄과 수아를 만들고, 이후 3살과 갓난아기였던 수아를 남기고
> 갈 수 밖에 없었던 사정까지」**

### 7-1. 순서

| # | |
| --- | --- |
| ① | **★★★ EP141에서 나온 것** — 저 밖의 괴물들에게서 왔다 |
| ② | **1차 거체 배양** |
| ③ | **★★★★★ 통제 실패** — 성장 과정에서 자아를 형성해 거부한다(정본) |
| ④ | **★★★★★★ 폐기 — 내부 소각** |
| ⑤ | **★★★ 남은 신경세포로 단아를 만든다** |
| ⑥ | **2차 배양 → 블랙 타이탄 + 수아** |
| ⑦ | **★★★★★ 3살과 갓난아기를 남기고 떠난 사정** |

### 7-2. ★★★★★★ ④ — 내부 소각 수단

> **[사용자]** **「실패를 우려해 내부에 소각 수단을 마련했다는 걸로,
> 외부의 손상은 막지만 내부는 막지 못함」**

**★★★★★★ 이것이 G0-028 §1-2와 정확히 대칭이다.**

| | |
| --- | --- |
| **[EP142]** | **외부 충격에 사실상 면역이지만 자기들끼리는 간섭 가능** |
| **★★★★★ [EP145]** | **밖에서 못 뚫으니 안에 넣어 뒀다** |

**★★★ 그리고 EP001의 `바위를 쏘는 것 같았다`부터 3단으로 이어진다.**

| 회차 | |
| --- | --- |
| **EP001** | 안 통한다 |
| **EP142** | **왜 안 통하는지** |
| **★★★★★★ EP145** | **그래서 어떻게 했는지** |

**★★★ 만들면서 죽이는 방법을 같이 만들었다.**
**★★★★★ 그게 「통제」의 실체다.** 현서는 처음부터 그걸 준비해 뒀다.

**★★ 그리고 그 말을 아이들 앞에서 한다.**

### 7-3. ★★★★★ ⑤ — 남은 신경세포

| | |
| --- | --- |
| **★★★★★★ 태운 뒤에 남은 것** | 그걸로 단아를 만들었다 |
| **★★★ 그래서 단아 = 1차 계통** | G0-019 §3층 |
| **★★ 면역거부의 뿌리** | **1차가 2차를 자기 몸처럼 쓰려 한다** |

**★★★★★ 단아는 폐기된 것에서 나왔다.** 수아는 새로 배양한 것에서 나왔다.
**★★★ 그 차이가 열두 해 뒤에 몸으로 온다.**

### 7-4. ★★★★★★ ⑥ — 블랙 타이탄과 수아는 같은 배양이다

> **[전체 플롯 2-5]** 현서가 미국으로 떠난 뒤 영진은 **2차 거체**를 청해 수몰지구 차량기지에 은닉하고
> **블랙 타이탄이라 이름 붙인다.**
> **[통합설정집]** 수아 — **2차 계통** · 우회 필터가 약하다

**★★★★★ 수아와 블랙 타이탄이 한 배양에서 나왔다.**
**★★★★★★ 그것이 원 플롯 대사 「블랙 타이탄은 수아와 같은 신경계통이야」의 뿌리이고,**
**EP141에서 루시가 안 한 말이다.**

**★★ 여기서 처음 나온다.**

### 7-5. ★★★★★ ⑦ — 떠난 사정

> **[전체 플롯 2-5]** 미국 정보당국은 현서의 연구를 포착하고,
> **두 딸의 자유를 보장한다는 조건으로 사실상 강제 소환한다.**
> **[통합설정집 연표]** **수아 탄생. 현서는 미국으로 소환된다.**

| 항목 | |
| --- | --- |
| **시기** | **★★★ 수아 탄생 직후** — 단아 세 살 · 수아 갓난아기 |
| **조건** | **★★★★★★ 두 딸의 자유** |
| **★★★ 그래서** | **아이들을 두고 간 것이 아이들을 지킨 것이다** |
| **★★ 그런데** | **아이들은 그걸 모르고 열두 해를 살았다** |

**★★★★★★ 이것이 단아가 가장 못 받아들이는 대목이다.**
**★★★ 「나를 위해서였다」는 말이 열두 해 뒤에 온다.**

### 7-6. ★★★★★ 지면 규칙

| 쓴다 | 안 쓴다 |
| --- | --- |
| **★★★ 소각 수단** · 남은 신경세포 · 2차 배양 | **★★★★★ 「Project IRONSHORE」 · 「3차 거체」 = 0** |
| **두 딸의 자유를 보장받았다** | **★★ 루시의 출생 = EP152** |
| **★★★★★★ 회상 교차**(개요 §2-2) | **현서의 정당화 · 변명** |
| **햄스터 한 마디**(§1-5) | 서술자의 논평 **0** |

**★★★★★★ 설명은 조각으로 온다.** 한 번에 다 말하면 강의가 된다.
**★★★ 조각마다 회상이 하나씩 붙는다.**
