## 1. 외형 잠금

- **몸체:** 검붉은 빛이 도는 흑색의 반구형. 수면 위 노출부 직경 약 40미터.
  물이 빠져도 노출 높이가 변하지 않는다(고착 — 떠 있는 것이 아님).
- **가시:** 길이가 제각각인 가시 수백 개, 최장 약 30미터. 방향을 미세하게
  바꾸는 움직임만 보인다. 이동·보행·유영은 없다.
- **질감:** 가시와 몸체 표면에 따개비·해조 부착 — G0-008 바닷가재형과 같은
  심해 계보의 질감 통일.
- **하부:** 해저지반과 방파제 기초에 고착. 수중 구조는 지면에서 직접
  묘사하지 않는다(정찰·소문·추정의 언어로만).
- **안광:** 가시 뿌리 사이 함몰부 다수에 **녹색 점광**. 맥동·명멸 없음.
  괴수 계보 공통 마커(G0-009) — 첫 점등 연출은 EP8 지휘실 화면 확대 장면.

## 2. 행동·음향 잠금

- 평상시 **무음**. 위협·단말마의 쇠 긁는 소리(G0-010)는 접촉 국면(EP9
  이후)에만 허용.
- 공격 행동 없음 — 접근하는 것(선박·포탄·어구)이 **밀려나거나 잘리는
  현상**만 관측된다. 원인(역장) 명명·시각화 금지(G0-010).
- 같은 자리 유지가 행동의 전부다. 자리에서 밀려나는 것 = 기능 상실이라는
  내부 사정은 작가 전용(EP12 제한 기록 전까지 전면 봉인).

## 3. 명명 경계

- 군: `고착형 미식별 개체` 계열 임시 식별어.
- 시민·학생: `성게 같다`는 **서술 비유까지만** — 고유 별명으로 정착시키지
  않는다.
- 서사 외 작가용 명칭: 성게형.

## 4. 크기 관계 참고

- 블랙 타이탄 52m / 바닷가재형 약 70m / 성게형 노출부 40m + 가시 30m —
  가시 포함 전폭은 타이탄 신장을 넘는다. 정면 힘겨루기가 아니라 접근 각도
  문제라는 EP9 실패 설계의 물리적 근거.
