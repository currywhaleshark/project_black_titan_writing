## 1. ★★★★★★ 영진 — 불구속 송치

| 단계 | 상태 |
| --- | --- |
| 8/31 | 현장 자진(`내가 만들었고, 내가 태웠습니다` — EP103) |
| 9월 | 조사 · **EP110 명준의 「보류」로 서류가 멈춘다** |
| **10월 중순** | **★★★ 보류가 풀리고 수사가 종결된다** |
| **10/20 이전** | **★★★★★★ 불구속 송치** — 검찰로 넘어갔다 |

**★★★ 「불구속 송치」의 정확한 뜻:**

| 끝난 것 | 안 끝난 것 |
| --- | --- |
| **경찰 수사** | **기소 여부** |
| **구속 필요성 판단** — 도주·증거인멸 우려 없음 | **재판** |
| 신병 구속 | **처벌 여부와 정도** |

**★★★★★ 몸만 나온 것이다. 사건은 진행 중이다.**
**계속 불려 다니고, 출석 요구에 응해야 하고, 나가면 안 되는 데가 있다.**

### 1-1. ★★★ 왜 지금 풀렸나 — **지면 0**

**EP130 조건 ③의 귀결이다** — `켜려면 만든 사람이 있어야 합니다`.
**★★★ 그런데 이것도 「거래」가 아니다.** 구속 필요성이 없어진 것이 형식적 이유고,
**필요가 생긴 것이 실질적 이유다.** 둘은 서류에서 만나지 않는다.

**★★★★★★ 단아도 수아도 왜 나왔는지 끝까지 안 듣는다**(EP136·EP138 지면 확정).

### 1-2. 표기 정정

| 잘못 | 정본 |
| --- | --- |
| 불구속 **전환** | **★ 불구속 송치** |
| 「나왔다 = 끝났다」 | **★★★ 나왔다 ≠ 끝났다** |

**★★ 지면 규칙: 「송치」·「기소」·「검찰」 = 어휘 노출 0.**
**아이들 시점에서는 「나왔다」와 「또 불려 간다」로만 나타난다.**

## 2. ★★★★★★ 단아 — 처분 미정 · 임시위탁

### 2-1. 상태

| 항목 | 확정 |
| --- | --- |
| 지위 | **촉법소년**(만 12세 · G0-020) — **형사처벌 0** |
| 절차 | 경찰 → **가정법원 소년부 송치 완료** |
| **현재** | **★★★★★★ 심리 미종결 · 임시조치로 아동보호시설 위탁 중** |
| 처분 | **★★★ 아직 안 났다** |
| 기일 | **★★★★★ 안 잡혔다** |
| **소년분류심사원** | **★★ 안 갔다** — G0-020 §5 ②는 **회피됐다**(EP130 협상의 성과) |

**★★★ 죄명은 여전히 미확정이다**(G0-020 §3 유지). **쓸 칸을 못 찾았다.**
**심리가 안 끝나는 이유의 절반이 그것이다.**

### 2-2. ★★★★★★ 왜 보호자가 생겼는데도 못 가나 — **핵심**

**세 겹이다.**

| # | 이유 |
| --- | --- |
| **①** | **임시조치는 법원이 푼다.** 보호자가 생긴 것과 위탁 해제는 **다른 절차**다 |
| **②** | **보호자 부재는 위탁의 한 사유였지 유일한 사유가 아니다** — 단아는 **사건 당사자**다 |
| **③** | **★★★★★★ 그 보호자가 「불구속 송치된 피의자」다** |

**★★★★★★ ③이 가장 잔인하다.**
**영진이 나온 것 자체가 단아를 못 가게 하는 이유가 된다.**
**같은 사건의 피의자 집으로 그 사건의 소년을 보내는 결정을 법원이 쉽게 안 한다.**

### 2-3. ★★★★★★ 그래서 EP115가 완성된다

> **[EP115]** 큰애는 걷는다. **만 열두 살이고 사법절차 안에 들어와 있다.**
> 작은애는 아직 못 걷는다. **만 아홉 살이고, 그 나이에는 손댈 조문이 아예 없다.**

| | 나이 | 법 | 결과 |
| --- | --- | --- | --- |
| **수아** | 만 9세 | **손댈 조문이 없다** | **★ 간다** — 보호자 칸만 채우면 된다 |
| **단아** | 만 12세 | **촉법소년 · 사건 당사자** | **★ 못 간다** — 법원 결정 대기 |

**★★★★★★ 걸을 수 있는 쪽이 못 가고, 못 걷는 쪽이 간다.**
**EP138 「같이 못 간다」의 정확한 뿌리가 이것이다.**

### 2-4. 처분 전망 — **작가용 · 지면 0**

| 가능한 처분 | 비고 |
| --- | --- |
| **불처분 결정** | 죄명이 안 잡히면 이쪽 |
| 1호 감호위탁(보호자) | **★ 영진 사건이 끝나야 가능** |
| 6호 아동복지시설 감호위탁 | **★★ 지금 상태의 연장** |

**★★★ 어느 쪽이든 영진 재판이 먼저 굴러가야 한다.**
**두 사건이 묶여 있고, 아이 쪽이 어른 쪽을 기다린다.**

## 3. ★★★★★★ 탑승과 처분 — 구조적 연결만

**★★★ 명시적 거래는 없다. 명준이 제안한 적이 없고 누구도 말로 꺼내지 않는다.**

### 3-1. 그런데 구조적으로는 연결돼 있다

| 고리 | |
| --- | --- |
| ① | **매일 「오늘도 하시겠습니까」를 묻고 대답을 받아 적는다**(EP135) |
| ② | 그 기록이 **「반응 확인」 넉 자로 보고서에 올라간다**(EP135) |
| ③ | 보고서는 **협조 사실의 기록**이 된다 |
| ④ | **★★★ 소년보호사건에서 그런 기록은 유리한 정상으로 읽힌다** |
| ⑤ | **★★★★★★ 아무도 그걸 단아에게 말하지 않는다** |

### 3-2. ★★★★★★ 단아가 감지한 게 맞았다

> **[EP135]** 그 말을 매번 묻는다. (…) **`적는 데가 있는 것 같았다.`**
> **`안 하겠다고 하면 안 하는 건지는 모르겠는데, 묻는 걸 보면 안 하겠다고 할 수 있는 자리이기는 한 모양이었다.`**

**★★★ 맞았다. 그리고 반만 맞았다.**
**적는 데가 있는 것도 맞고, 안 하겠다고 할 수 있는 것도 맞다.**
**★★★★★ 다만 안 하겠다고 하면 적히지 않는다는 것까지는 못 갔다.**

### 3-3. ★★★★★ 명준은 나쁜 사람이 안 된다

**압박한 적이 없다. 조건 ④를 만든 것이 오히려 거절 가능성을 제도화한 것이다.**
**★★★ 그런데 제도가 거절을 기록하지 않는 방식으로 만들어져 있다.**

**★★★★★★ 이게 이 라인의 정서다 — 아무도 나쁜 짓을 안 했는데 아이가 못 나간다.**

## 4-A. ★★★★★★ 흘림 배분 (사용자 정정 2026-08-26)

> **「너무 숨겨두면 읽는 입장에서 이상하게 생각되니 좀 흘려두기는 해야할듯」**

**★★★ 「설명 0」은 「정보 0」이 아니다.**
**은폐하면 독자가 「왜 안 가지?」에서 멈춘다.**

### 4-A-1. 원리 — **단아는 못 알아듣고 독자는 알아듣는다**

**이 시리즈가 계속 써 온 방식이다**(EP131 「명단」 · EP134 「직계」).
**아이가 어른 말을 그대로 옮기면, 뜻은 독자 쪽에서만 완성된다.**

### 4-A-2. ★★★★★ 흘리는 것 / 계속 안 주는 것

| **흘린다** | **계속 안 준다** |
| --- | --- |
| **뭔가가 「정해져야」 한다** | **누가 정하는지** |
| **정할 데가 어딘가 있다** | **「법원」 · 「소년부」 어휘** |
| **아직 안 정해졌다** | **기일 · 죄명 · 조문** |
| **어른은 아는데 말 안 한다** | **탑승-처분 연결** |
| **영진 쪽도 안 끝났다** | **「송치」 · 「기소」 · 「불구속」** |

### 4-A-3. 흘림 스케줄

| 시점 | 분량 | 내용 |
| --- | --- | --- |
| **EP115**(기존) | 1문 | 명준 — **`만 열두 살이고 사법절차 안에 들어와 있다`** |
| **★ EP138**(v1.1 소급 보강) | **4비트** | **「정해지면 온대.」** + 수아의 해석 + **영진의 침묵** |
| **EP140~141** | **1비트** | **★ 영진이 「또 불려 간다」** — 어른 쪽도 안 끝났다 |
| **S15 초** | 본격 | **처분 기일이 잡힌다** — 새 시한 |

### 4-A-4. ★★★★★★ EP138 v1.1 소급 보강 — 실제 지면

> 「…언제 와?」
> **「정해지면 온대.」**
>
> 수아는 그 말도 받아 놨다.
>
> **`정해지면이라는 건 아직 안 정해졌다는 뜻이다. 정할 데가 어딘가 있고 거기서 아직 안 정한 거다.`**
> **`누가 정하는지는 언니도 모르는 것 같았다. 안다면 그렇게 말 안 했을 것이다. 아는 사람은 누가 정한다고 말한다.`**
>
> 할아버지는 그 말에 아무것도 안 보탰다.
> **`수아는 그것도 봤다. 아까 병실에서는 안 묻는 쪽이었는데 지금은 말 안 하는 쪽이었다.`**

**★★★ 세 겹이 한 번에 선다:**

| 겹 | |
| --- | --- |
| ① | **뭔가가 정해져야 한다** — 절차가 있다는 신호 |
| ② | **단아도 모른다** — 아이 둘 다 정보 밖에 있다 |
| ③ | **★★★★★ 영진은 안다. 그리고 말 안 한다** — 어른은 알고 있다는 신호 |

**★★★ ③이 결정적이다.** 독자는 여기서 **「말 못 할 사정이 있구나」**로 간다.
**아무도 조문을 안 읽었는데 구조가 전달된다.**

**★★ 「해 볼게」·「아직」 계보를 그대로 재사용했다**(EP109·136) —
**말 한 겹 벗기기가 이 자매의 문법이라 설명처럼 안 읽힌다.**
