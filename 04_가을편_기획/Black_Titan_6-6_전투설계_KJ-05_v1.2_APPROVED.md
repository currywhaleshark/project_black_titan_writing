**★★★★★★ 바다로 들어가면 아예 못 쫓는다.**
**★★★ 그래서 「놓쳤다」가 유예가 아니라 종결이 된다.** 다음 회차에 다시 붙을 수가 없다.

**★★ 전례도 있다** — EP124에서 **개체가 스스로 물러났다.** 이번이 처음이 아니다.

### 7-A-2. ★★★★★ 왜 물러나나

**다리가 넷 부러졌다.** 속도가 전부인 개체에게 그건 전부를 잃은 것이다.

| | |
| --- | --- |
| **★★★ 등각류는 물에서도 산다** | 원형이 이미 그렇다 |
| **★★★★★ 그래서 손상되면 물로 간다** | **행동으로만 보인다** |
| **★★ 왜 오는지(중층)는 여전히 지면 0** | **★ 왜 돌아가는지도 안 준다** |

**★★★★★★ 지면에는 「바다 쪽으로 갔다」까지만 있다.** 판단은 관측반 소견이지 서술자의 앎이 아니다.

### 7-A-3. ★★★★★★ 그런데 경로가 시가지를 지난다

**개체는 이미 방재벽 안쪽에 있다.** 바다로 가려면 **되돌아 나가야 한다.**

| | |
| --- | --- |
| **★ 벽을 다시 넘지 못한다** | 다리가 넷 부러졌다. **넘어올 때는 성했다** |
| **★★★★★★ 그래서 물에 닿는 데로 간다** | **부두**(정본 67회 · EP121·139·140) — **벽이 거기서 끊긴다.** 배가 드나들어야 하니까 |
| **★★★★★ 그 경로가 시가지를 가로지른다** | **정착이 아니라 통과** |
| **★★ 둘이 쫓는다** | 시가지라 **포격을 못 쓴다** |
| **★★★★★★ 그 와중에 두 거체가 부딪힌다** | **EP143** |
| **★ 개체는 그동안 빠져나간다** | **바다** |

**★★★★★★ 그래서 EP143이 더 나빠진다.**
**놓친 것도 실패인데, 서로 싸우느라 놓쳤다.**

### 7-A-4. ★★★ 벽을 못 넘는 것이 회차 안에서 증명돼야 한다

**★★ 한 번은 시도해야 한다.** 붙었다가 미끄러지거나, 올라가려다 주저앉거나.
**★★★★★ 그걸 보고서야 둘이 「저건 벽으로 안 나간다」를 안다** — 그리고 그때 시가지 방향이 정해진다.

**★ 이건 관측 사실이지 추론이 아니다.** 단아도 루시도 같은 것을 봤다.
