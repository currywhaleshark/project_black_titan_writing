## 6. 자주 틀린 사실 Top

1. **성호의 6/23 목격 = 언덕**(옥상 아님 — 옥상은 딴 애 얘기고 흐지부지됐다)
2. **안전 지도 = EP36 제출 완료** / **떡볶이 이자 = EP41 어묵 셋으로 종결**
3. 관측 단말 = **가게**(격납고 아님) / 쟁반(유일 실물) = **격납고 작업대**
4. 방재벽(6/23 작업) ↔ 간척지 창고 벽(6/27) — **벽이 두 개다. 혼동 금지**
5. 트럭 배송 = **금요일 6/24**(목요일 아님 — 「하루 늦게」가 승인 사항)
6. 조종석 안에서는 **냄새를 못 맡는다**
7. EP52~53 투구게전 — **밀린 쪽은 단아**(무거워서 안 밀린 건 상대)
8. `잘했다` 초출 = **EP64**(그 이전 영진은 `수고했다`)
9. 수건 주체 = 영진, 점검 = 수아(귀환 의식)
9-B. **관절 역방향 꺾기 = 소진**(농게형 EP47~48 · EP64). 결착 방식 재사용 금지
9-C. **방재벽 = EP56에서 따개비를 뗀 자리**(붙인 게 아니다) · **보폭 20미터**(EP19)
10. 성호는 거인 화면·소문 앞에서 **무반응일 수 없다** / 나래의 만화는 실제를 따라온다
11. **★ 척도 — 52미터 기준을 사람 기준으로 되돌리지 않는다**(2026-08-17 등재 · 2회 반복). 팔 길이 = **버스보다 큼** · 전투 흔적은 **포클레인이 필요한 규모**(발로 못 민다) · 개체 크기는 **버스·비행기**로 잰다
12-B. **★ 자매는 아파 본 적이 없다**(2026-08-17 등재) — **단아·수아 둘 다.** 감기·몸살 병력 0. **EP61의 「아프다」는 결석용 거짓말이었다.** 그래서 EP70~ 통증은 **본인도 비교 대상이 없다.** 이유(기원)는 **가을 전 공개 금지** — 인물은 사실만 알고 이상하다고 여기지 않는다
12-C. **★ 보정값 = 실체 없는 위장 설명**(2026-08-18 등재 — 컨텍 유실 사고 1회). 동조 시스템에 보정값이라는 물건은 **없다.** EP2의 「보정값은 단아에게 맞춰져 있다」는 **수아를 태우지 않기 위한 핑계**(가족 내부용+독자용). **값을 바꾸거나 되돌리는 연출 금지.** 수아 즉각 기동의 위장 설명이 불필요한 이유: **이상함을 아는 사람이 영진뿐**(수아 = 비교 기준 없음 · 단아 = 숫자 안 봄)
12. **명명 게이트** — `타이탄`·`블랙 타이탄`은 **가족 3인 한정.** 외부(교실·게시판·소문) = `거인`·`검은 거인`·`우리 동네 거인` / 군 = `미확인 대형체`
