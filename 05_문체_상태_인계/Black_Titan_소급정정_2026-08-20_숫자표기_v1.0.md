# Project Black Titan — 소급 정정 기록 2026-08-20 (숫자 표기)

| 항목 | 내용 |
| --- | --- |
| 근거 | 사용자 지시 — 「날짜 시간이 많이 나오니까 한글로 풀어쓴 게 눈에 잘 안 들어온다. 숫자로 해야겠는데」 → **「통일하자」** |
| 사유 | S12에 들어오면서 날짜·시각이 한 화에 여러 번 나온다. 특히 **수아의 관측 종이**처럼 숫자가 목록으로 쌓이는 장면에서 한글 표기는 **표로 안 읽힌다** |
| 범위 | **EP93~97 승인본 5화 · 21건** + EP98 초고 적용 |

## 1. 확정 규칙 (변경)

| 구분 | 표기 | 예 |
| --- | --- | --- |
| **날짜** | **아라비아 숫자** | `8월 31일` · `25일` · `9월 1일` |
| **시각** | **아라비아 숫자** | `8시 15분` · `9시` · `30분` |
| 구체 수치 | 아라비아 숫자 | `13초` · `7번 부표` · `3교시` · `52미터` |
| **기간·밤 수** | **한글 유지** | `닷새` · `두 밤` · `이틀` · `넉 달` · `여섯 밤` |
| 어림치·관용 | 한글 유지 | `한 시간쯤` · `반 박자` · `세 걸음` |

**★ 기간을 한글로 두는 이유:** 그건 수치가 아니라 **화자가 세는
방식**이다. `31일까지 두 밤`처럼 한 문장에 섞여도 자연스럽다.

## 4. 효과

**EP97 수아의 종이**가 대표 사례다.

| 전 | 후 |
| --- | --- |
| `이십오. 이십육. 이십칠. 이십팔.` | **`25. 26. 27. 28.`** |

EP98에서 이 종이에 시각이 채워지는데(`25, 8시 10분` …),
**한글이었으면 문장으로 읽히고 숫자라서 표로 읽힌다.**
이 화의 주제가 「적어 놓으면 하나로 묶인다」이므로 표기가 곧 주제다.
