## 1. 무엇이 문제인가

**등장인물은 저것들을 분류해서 부르지 않는다.**

`성게형`·`문어형` 같은 표기는 작가가 로스터를 관리하려고 붙인 이름이다.
지면에 나오면 두 가지가 동시에 깨진다.

1. **시점** — 열세 살이 처음 보는 것에 분류명을 붙일 리 없다
2. **명명 게이트** — 개체는 지면에서 명명하지 않는다는 원칙

**기준:** `가재`·`문어`·`성게` 같은 **생물 이름을 비유로 쓰는 것은
정상**이다(`가재처럼 생긴 것`). **`-형`이 붙는 순간 작가용**이다.

## 2. 정정 내역 (7곳)

| 화 | 원문 | 정정 |
| --- | --- | --- |
| EP9 | `성게형은 처음 그대로였다` | `그것은 처음 그대로였다` |
| EP9 | `등 뒤에서 성게형은 끝까지 움직이지 않았다` | `등 뒤에서 그것은 끝까지 움직이지 않았다` |
| EP10 | `작전도에는 성게형의 위치와` | **`작전도에는 대상의 위치와`**(군 문서 화자) |
| EP10 | `반 호흡 뒤에 성게형 너머 바다에서` | `반 호흡 뒤에 저것 너머 바다에서` |
| EP10 | `성게형이 기울었다.` | `그것이 기울었다.` |
| EP10 | `성게형이 저항했다.` | `그것이 저항했다.` |
| EP48 | `봄에 문어형한테 붙잡혔을 때는` | `봄에 팔 여덟 개짜리한테 붙잡혔을 때는` |

- **지칭만 바뀌고 내용·리듬·문단 구조는 그대로다.** 상태 문서 영향 0
- EP10 군 작전도 건은 화자가 군이라 `대상`으로 잡았다. 바로 다음
  문장에 `개체`가 이미 있어 중복을 피했다
- EP48은 뒤에 `여덟 개가 머리를, 팔꿈치를…`가 이어지므로
  **`팔 여덟 개짜리`**가 앞뒤로 맞는다

### 정정하지 않은 것

- **EP38·EP44 머리표(정정 반영 란)** — 본문이 아니라 문서 메타이고,
  작가용 표기가 거기 있는 것은 정상
- `바닷가재`(EP9) — **`-형`이 없다.** 생물 이름을 비유로 쓴 정상 용법

## 3. 도구 보강

`scripts/check_draft.py`에 **`CREATURE_TAXA` 19종**을 신설해
지식 경고(`knowledge_warnings`)로 잡는다.

```
성게형 · 문어형 · 가재형 · 바닷가재형 · 농게형 · 갯지렁이형 ·
관갯지렁이 · 군부형 · 투구게형 · 따개비형 · 등각류 · 딱총새우형 ·
톡토기형 · 공작갯가재형 · 크릴형 · 갯민숭달팽이형 · 갑오징어형 ·
가오리형 · 바다나리
```

- 기존 금지어 목록에는 `성게형`·`농게형` **둘뿐**이었다.
  그래서 `문어형`이 초고 검사를 그대로 통과했다
- **로스터에 개체를 추가할 때마다 이 목록에도 추가한다**

## 4. 지면에서 과거의 개체를 가리키는 법

| 방법 | 예 |
| --- | --- |
| **시기 + `괴수`**(사용자 문안) | `3월의 첫 괴수` |
| 몸의 특징 | `팔 여덟 개짜리`·`가시 쏘는 놈`·`집게` |

| 군 문서 | `대상`·`개체` |

※ `괴수`는 승인본에 57건 쓰인 **정상 지면 용어**다.
