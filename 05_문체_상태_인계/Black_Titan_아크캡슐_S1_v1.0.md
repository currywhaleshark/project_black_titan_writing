# Arc capsule — S1 「첫 침공」

- Arc: 봄 S1 (첫 침공과 첫 승리, 아크명 「첫 침공」)
- Chapter range: EP001 「벚꽃과 사이렌」 ~ EP006 「교실의 거인」
- Story-time range: 2050년 전후 3월 초의 약 1주 — 체험학습 날 사이렌부터 첫 승리 사흘째 아침까지
- Source state version: SNAP-006 v1.0 (복선추적기 SNAP-006, S1 종료장부 대조서 v1.0)

## Entry state

평범한 6학년 도단아. 수리점 할아버지 도영진, 동생 수아와 구래동의 일상.
지난가을부터의 시력 저하와 둥근 안경, 5개월 전의 VR 체험. 청해는 방재벽에
둘러싸인 채 수몰 구도심을 안고 사는 도시. 독자와 단아 모두 블랙 타이탄의
존재를 모른다.

## Irreversible events

- 첫 침공 — 바닷가재형 회수 개체가 청해 남부에 상륙 (EP1)
- 단아가 블랙 타이탄의 존재와 자신의 훈련(VR·수면학습)의 실체를 알게 됨 (EP2)
- 단아의 선택적 첫 출격 — 수몰역 기립, 첫 교전 (EP2~3)
- 첫 격파 — 방재벽 붕괴 저지, 괴수 사체는 붉게 용해되어 소실 (EP4)
- 영진의 설명 이행 — 적의 출처(현서의 발견)와 부녀의 준비 공개, 18년 전
  회상으로 도현서 선행 등장 (EP5)
- 가족 비밀 규칙의 명문화 — 공개 시 순서(압수·체포·양육 이관)와 `셋이
  같이 못 산다`의 수용 (EP6)
- 도시가 `검은 거인`이라는 우호적 미확인 존재를 얻음 — 군은 `소속 불명
  전략무력`으로 기록 (EP4~5)
