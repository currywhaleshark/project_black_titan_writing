# Project Black Titan — 작중 달력 v1.0 (2050년 3월 ~ 2051년 2월)

| 항목 | 내용 |
| --- | --- |
| 문서 ID / 버전 | CALENDAR / v1.0 |
| 작성 | 2026-08-15 — 달력 정정 v1.0 직후 |
| 정본 | **실제 2050년 그레고리력.** 요일은 실제 달력과 일치한다 |
| 반영 범위 | EP1~EP61 승인분 + 학사·계절 고정점 |

**쓰는 법.** 새 회차의 날짜를 정할 때 이 달력에서 **요일을 먼저 확인**하고
Gate C 브리프 → Level 6 → 초고 → SNAP에 **같은 날짜**를 옮긴다.
여름편 21화가 통째로 2일 어긋났던 것은 브리프와 초고가 다른 날을 가리킨 채
승인됐기 때문이다. 자세한 것은 `Black_Titan_달력정정서_v1.0.md`.

표 안의 숫자는 **화수**다. `41화`는 EP41이 그날로 기록됐다는 뜻이고,
한 칸에 여러 화가 있으면 같은 날을 나눠 쓴 것이다.
