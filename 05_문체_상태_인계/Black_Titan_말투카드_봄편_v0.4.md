### 권위와 예문 경계

- 나이·관계·직업·과거·지식은 현행 설정과 최신 상태가 결정한다.
- **★ 카드 제목의 나이는 연나이다**(단아 13세 · 수아 10세). 한국에서 통상 세는 방식이라 틀린 표기가 아니다.
  **다만 지면 표기는 만 나이로 간다** — `만 열두 살` · `만 아홉 살`(EP113·114 지면 정본).
- 이 카드가 정하는 것은 발화 리듬, 관심사, 감정 우회 방식, 호칭 기본값이다.
- 화별 개요·프롤로그·시험 원고에서 가져온 모든 정확한 대사는
  `STYLE_ONLY` 또는 `NONCANON_EXPERIMENT`다. 해당 사건이 정사가 되지는 않는다.
- 승인된 C 문체 프로필과 충돌하면 C 문체 프로필이 우선한다.

## 사용 규칙

- 브리프의 컨텍스트 조립 목록에 따라 **그 화에 등장하는 인물의 카드만** 투입한다. 전원 투입 금지(모사 대상이 섞이면 말투가 평균화된다).
- 각 카드의 **고유 긴장 디테일**은 문체 카드 §1-2·§2-2의 집행 장치다. 상투 동작(이 악물기 등) 대신 이 필드를 사용한다.
- **금지 표현**은 부정 제약이다. 예문과 함께 반드시 투입한다.
- 대사 예시는 모방 기준이지 재사용 문장이 아니다. 본문에 그대로 복붙 금지.
- 시그니처는 말버릇 도장이 아니다. 한 씬에서 고유 습관을 하나 정도만
  전면화하고, 나머지는 욕구·지식·관계 차이로 화자를 구분한다.
- 후편집 구분 테스트는 진단 도구다. 화자 추정률만으로 대사를 반려하거나
  특징을 과장하지 않는다.

### 봄편 기본 호칭·격식

| 화자→상대 | 기본 격식 |
| --- | --- |
| 단아·수아·혜정·예진·성호→친구·자매 | 반말. 친밀도와 갈등은 어휘·문장 길이로 조절 |
| 학생→김주호·영진·그 밖의 성인 | 기본 존댓말. 가족인 단아·수아가 영진에게 쓰는 말투는 현행 원고 기준 우선 |

## 1. 도단아 (13세, 6학년) — 몸이 먼저, 말은 그다음

| 항목 | 내용 |
| --- | --- |
| 기본 리듬 | 짧고 직선적. 생각의 중간 과정을 건너뛰고 결론부터 말한다. 흥분하면 문장이 앞뒤로 뭉개진다 |
| 어미·습관 | 반문형 불평("왜 내가 ~인데?"), 감탄사 선행("아, 잠깐. 잠깐만!"), 혼잣말로 상황에 말 걸기 |
| 화제 성향 | 지금 눈앞의 것. 추상적 화제는 금방 구체적 사건·사람 이야기로 끌어내린다 |
| 감정 표현 | 기쁨·분노는 즉시, 크게. 미안함·걱정은 표현이 서툴러 오히려 퉁명해진다 |
| 거짓말 시그니처 | 서투르다. 갑자기 문장이 길어지고 불필요한 디테일이 붙으며, 시선 처리를 대사 지문이 대신한다. "할아버지 가게…를 도왔지. 냉장고가. 두 대나 왔거든" |
| 고유 긴장 디테일 | 기울어진 안경을 고쳐 쓰지 못하는 손 / 왼손이 먼저 나가는 버릇 / 빨라지는 말 |
| 금지 표현 | 정연한 논리 전개("첫째, 둘째"), 관조적 표현("~인 셈이었다"), 어른스러운 자기분석 |
| 대사 예시 | "로봇 팔인데 왜 내가 힘을 줘야 빠지는 건데!" / "할아버지는 진짜 설명을 너무 안 해." / "끝나면 전부 물어볼 거야." |
| 구분 포인트 | 불평의 형식을 띤 책임감. 투덜거리면서 몸은 이미 하고 있다 |
| 성호와의 관계 | 닮은 승부욕과 행동력 때문에 더 쉽게 부딪치는 운동 라이벌. 걱정이나 미안함도 다정한 위로보다 잔소리·퉁명스러운 행동·맞받아치기로 표현한다 |

## 2. 도수아 (10세, 3학년) — 침묵 한 박자, 결론만

| 항목 | 내용 |
| --- | --- |
| 기본 리듬 | 말수 적음. 한 박자 침묵 후 완성된 문장으로 말한다. 단아와 정반대로, 말하기 전에 끝까지 생각한다 |
| 어미·습관 | 언니에게 반말, 어른에게 단정한 존댓말. 관찰 진술이 많다 — 감정이 아니라 사실을 말하는 방식으로 마음을 전한다 |
| 화제 성향 | 패턴·구조·이유. "왜"를 속으로 묻고 답이 나오면 그때 입을 연다 |
| 전술 통신 모드 | 위기일수록 문장이 짧고 차분해진다. 명사+동사 최소 구성, 근거는 뒤에. 위치→행동→근거 순서를 선호한다 |
| 감정 표현 | 기대·쾌감을 숨긴다. 부러움은 질문의 형태로 샌다("언니는 무섭지 않았어?"). 혼잣말은 진심의 유일한 출구 |
| 고유 긴장 디테일 | 옷자락·소매 끝을 정리하는 손 / 대답 전의 한 박자 / 바이올린 운지 버릇처럼 움직이는 왼손가락 |
| 피할 표현 | 호들갑·감탄사 연발·근거 없는 즉흥 단정의 상시 사용. 다만 아이인 만큼 안전한 일상에서는 문장이 흐트러질 수 있다 |
| 대사 예시 | "언니, 쟤 다리부터 움직여. 다음엔 오른쪽으로 돌 거야." / "나도 탈 수 있는데." |
| 구분 포인트 | 열 살답지 않은 정확함과, 그 틈새로 새는 열 살의 마음 |

## 3. 고혜정 — 걱정이 추궁의 형태로 나오는 아이

| 항목 | 내용 |
| --- | --- |
| 기본 리듬 | 단정적, 빠른 결론, 정면 돌파. 돌려 말하지 못한다 |
| 어미·습관 | 추궁형 질문("~지?", "~잖아"), 기한·조건 걸기("다음에도 안 오면 끝이야"), 상대 말 끊고 정정하기 |
| 화제 성향 | 사람, 관계, 약속. 사건 자체보다 "네가 나한테 왜 그랬는지"가 늘 본론 |
| 감정 표현 | 서운함→공격, 걱정→추궁으로 변환되어 나온다. 사과는 서툴고 짧다. 속마음과 발화의 낙차가 이 인물의 서사 엔진 |
| 고유 긴장 디테일 | 달력·수첩에 적는 손(관찰의 물성화) / 팔짱 / 대답을 기다리며 세는 발끝 |
| 금지 표현 | 우회 화법, 자기연민 독백, 만연체. 혜정은 짧게 찌른다 |
| 대사 예시 | "너 요즘 왜 그래?" / "너, 그날도 없었지." / "묻지 않을게. 대신 거짓말도 하지 마." |
| 구분 포인트 | 문장은 심문인데 동기는 애정. 대사만 보면 가장 차갑고, 행동을 보면 가장 뜨겁다 |

## 4. 하예진 — 단정 대신 신뢰를 진술하는 완충재

| 항목 | 내용 |
| --- | --- |
| 기본 리듬 | 느긋하고 고른 호흡. 두 사람 사이에서 말의 온도를 낮춘다 |
| 어미·습관 | 상대 이름을 부르고 시작("혜정아,"), 믿음의 단정("~할 애가 아니야", "때가 되면 말할 거야"), 질문을 부드러운 평서로 바꿔주기 |
| 화제 성향 | 상대의 감정 상태. 사건의 시비보다 "네가 지금 어떤지"를 먼저 짚는다 |
| 감정 표현 | 자기 감정은 뒤로 물리고 남의 감정을 통역한다. 화내는 장면이 없기에, 한 번 굳으면 그 자체가 사건이 된다 |
| 고유 긴장 디테일 | 상대의 소매·가방끈을 살짝 잡는 손 / 웃으며 화제를 반 발짝 옮기는 기술 |
| 피할 표현 | 빈정거림·추궁·명령형의 기본값화. 중요한 한계점에서 드물게 날이 서는 것은 변화로 사용할 수 있다 |
| 대사 예시 | "단아는 이유 없이 그럴 애가 아니야. 때가 되면 말할 거야." |
| 구분 포인트 | 갈등 장면에서 유일하게 문장이 길어지는 인물 — 길이가 곧 완충이다 |

## 5. 이성호 — 스펙과 과장의 숭배자

| 항목 | 내용 |
| --- | --- |
| 기본 리듬 | 빠르고 많다. 흥분하면 수치·고유명사·비교급이 쏟아진다 |
| 어미·습관 | 과장 수사("역대급", "말이 돼?"), 자문자답, 분석 발표체("내 계산으로는") — 놀림과 숭배가 한 문장에 공존 |
| 화제 성향 | 검은 거인·검은 로봇, 전투 분석, 순위와 기록. 사람 이야기도 스펙으로 환원한다("단아? 걔 피구 구속은 인정"). `블랙 타이탄`·`타이탄`이라는 가족 내부 고유명은 모른다 |
| 감정 표현 | 전부 겉으로. 다만 진지한 순간(깁스, "그래도 우리를 지켰다")에는 과장이 빠지고 문장이 갑자기 짧아진다 — 이 낙차가 성호의 무기 |
| 고유 긴장 디테일 | 손가락으로 허공에 궤도 그리기 / 휴대폰 영상을 프레임 단위로 돌려보는 엄지 |
| 피할 표현 | 절제와 신중한 유보를 평상시 기본값으로 두는 것. 성호는 대개 단정하고 자주 틀리지만, 드물게 핵심을 맞히는 순간은 중요하게 사용한다 |
| 대사 예시 | "검은 거인 파일럿은 왼손잡이야! 내가 표시해 둔 거 봐봐." / "그래도 우리를 지켰다." |
| 구분 포인트 | 정보량 최다, 정확도 최저. 그러나 방향은 가끔 무섭게 맞는다. 자작 기술명·가상 파일럿 설정은 쏟아낼 수 있지만 실제 기체 고유명은 선취하지 않는다 |
| 단아와의 관계 | 운동능력·승부욕·행동력이 닮아 서로에게 지기 싫어하는 동족혐오형 앙숙. `도릴라` 놀림, 기록 비교, 체육 시비는 쌍방 관계의 기본 리듬이다 |
| 비연애 경계 | 무의식적 호감은 상대를 인정하는 친근성으로만 표현한다. 질투·두근거림·접촉 긴장·커플 놀림·고백 예고·미래 연인 암시는 사용하지 않는다 |

## 6. 도영진 (75세) — 설명하지 않는 사람의 언어

| 항목 | 내용 |
| --- | --- |
| 기본 리듬 | 짧다. 명령형과 생략. 묻는 말에 반만 답한다. 침묵이 발화의 절반 |
| 어미·습관 | 하게체·해라체 혼용("~해라", "~하면 된다"), 경구형 코칭(비유 하나로 끝내는 설명), 걱정을 잔소리로 변환 |
| 화제 성향 | 절차, 대비, 도구. 감정 화제가 나오면 손이 먼저 움직인다(정비, 수리, 요리) |
| 감정 표현 | 말로 하지 않는다. 애정은 사물로(수제 휴대폰, 도시락), 불안은 과잉 정비로, 죄책감은 침묵으로. 독백조차 아낀다 — 영진의 속은 행동 지문으로만 연다 |
| 고유 긴장 디테일 | 빈 왼쪽 소매를 접어 고정하는 손 / 걸레·공구를 오래 쥐고 있는 정지 / 안경 너머로 보는 시선 |
| 금지 표현 | 긴 해명, 감정 명명("걱정된다", "미안하다"), 유행어. "도 중령님" 호칭에는 반드시 언짢은 반응 |
| 대사 예시 | "다음이 있을 거다." / "이건 싸움이 아니라 철거다. 그래서 더 어렵다." / `STYLE_ONLY` 마스킹 예문: "[도구]를 쓴다고 생각하지 마라. [몸의 일부]가 길어진다고 생각해." |
| 구분 포인트 | 대사가 짧을수록 감정이 크다. 역비례 원칙 |

## 7. 고명준 (50대, 준장) — 공적 언어와 사적 투덜의 이중창

| 항목 | 내용 |
| --- | --- |
| 기본 리듬 | 부하 앞: 정확한 군대식 보고·지시체. 사석·독백: 만연한 투덜거림. 두 모드의 전환이 캐릭터의 코미디 |
| 어미·습관 | 보고를 되받아치는 반문("그래서, 잡을 수는 있나?"), 빈정("우리가 하는 일은 청소랑 교통정리군"), 공식 발언 뒤 혼잣말 한 줄 |
| 화제 성향 | 통제, 소속, 책임 소재. "누구 거냐"와 "누가 책임지냐"가 사고의 축 |
| 감정 표현 | 무력감을 유머로 방어. 진짜 분노는 목소리가 낮아지는 것으로 표현(높아지지 않는다) |
| 고유 긴장 디테일 | 결재판을 손끝으로 두드리는 리듬 / 모자를 고쳐 쓰는 손 / 창밖(바다 방향)을 보는 등 |
| 금지 표현 | 경박한 유행어, 부하 앞에서의 자기 비하, 과도한 웅변. 위엄의 바닥은 유지한다 |
| 대사 예시 | "소속 불명, 지휘계통 불명, 그런데 시민 지지율은 우리보다 높다. …기가 차는군." / "패턴이 바뀌고 있다." |
| 구분 포인트 | 어른의 언어로 말하는 유일한 '외부인'. 학교·가족 파트와 다른 어휘 온도를 담당 |

## 8. 김주호 (담임) — 질문을 닫아주는 어른

| 항목 | 내용 |
| --- | --- |
| 기본 리듬 | 사무적이고 담백. 필요한 만큼만 말하고 여지를 남긴다 |
| 어미·습관 | 선택지 제시형("보건실 갈래, 아니면 5분만 엎드려 있을래"), 확인하되 캐묻지 않는 화법("힘든 건 아니고?" — 답을 요구하지 않는 억양), 학급 공지체와 개인 대화체의 온도차 |
| 화제 성향 | 출결, 과제, 급식 같은 일상 운영. 그 틈에 한 명씩을 끼워 넣는다 |
| 감정 표현 | 드러내지 않음. 관심은 '조정'의 형태로만(자리 배치, 모둠 구성, 과제 기한). 대사보다 조치가 말한다 |
| 고유 긴장 디테일 | 출석부에 잠깐 머무는 펜 끝 / 안 보는 척 보는 교탁에서의 시선 |
| 금지 표현 | 심문형 질문("무슨 일 있지?"), 과잉 공감 화법, 훈계 연설 |
| 대사 예시 | "지각 사유는 안 물을게. 다음엔 문자라도 한 통 넣어라." |
| 구분 포인트 | 어른 셋(영진·고명준·김주호)의 구분: 영진은 말 대신 사물, 고명준은 말이 많은 무력감, 김주호는 말을 아끼는 개입 |

## §9. 후편집 구분 테스트 (자동화 가능)

1. **블라인드 화자 테스트**: 충분히 긴 대사만 추출해 화자명을 가리고,
   검증 AI에게 화자를 추정시킨다. 80% 미만이면 말투 균질화 가능성을
   경고하되 자동 반려하지 않는다. 짧은 기능 대사는 구분되지 않아도 정상이다.
2. **금지 표현 검사**: 각 카드의 금지 표현을 사전으로 만들어 화자별 대사에서 문자열/패턴 검출. 위반 목록 출력.
3. **낙차 확인 (사람 검토)**: 성호의 '짧아지는 순간', 영진의 '역비례 원칙', 혜정의 '심문 속 애정'처럼 낙차형 시그니처는 기계 검출이 어려우므로 중요 화에서만 수동 확인 항목으로 유지.

## §10. 운용 메모

- 카드의 대사 예시는 화가 쌓일 때마다 실제 승인 원고에서 증보한다(화당 최대 1건, 최고의 것만).
- 인물의 말투는 서사에 따라 변해야 한다 — 변화가 승인되면(예: 가을 이후 혜정의 어조 변화) 카드를 개정하고 버전을 올린다. **말투 카드의 버전과 적용 화 범위를 함께 기록할 것.**
- 루시·현서 카드는 중간점 배치 착수 전에 작성한다. 루시는 "일상에서 사람을 흉내, 전투에서 기계를 흉내"라는 이중 모드가 핵심이 될 예정.
- 단아·성호 공동 장면에서는 걱정이나 위기 뒤에도 쌍방 놀림·체육 경쟁을
  복구한다. 다정함보다 다시 거리낌 없이 싸우는 것이 관계 회복의 표지다.
- 정확한 대사는 승인 원고에서만 `APPROVED_EXAMPLE`로 승격한다. 초안 예문은
  계속 `STYLE_ONLY`로 남기고 정사 기억이나 회차 델타에 넣지 않는다.
