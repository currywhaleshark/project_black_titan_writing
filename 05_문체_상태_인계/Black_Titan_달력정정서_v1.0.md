## 1. 무엇이 틀렸나

요일이 기록된 44화를 실제 2050년 달력과 대조한 결과:

| 구간 | 화수 | 실제 달력과의 차이 |
| --- | --- | --- |
| 봄편 EP1~EP40 | 23화 | **전부 일치** |
| 여름편 EP41~EP61 | 21화 | **전부 정확히 −2일** |

분기점은 EP40(5/18 수 · 정상) → EP41이다. 여름편은 자기들끼리는 완전히
일관됐지만(회차 간 요일 간격 전부 정합), **작품 안에 달력이 둘**이었다.

그리고 **EP41 한 화 안에서 지면끼리 충돌**하고 있었다.

| 위치 | 표기 |
| --- | --- |
| §1 첫 문장 | `6월 첫 월요일은 아침부터 한여름이었다.` |
| §5 영진 장부 | `날짜부터 적었다. 6월 2일.` |
| SNAP-041 | `6월 2일 화요일 밤` |
| 회차브리프 v0.1 | `2050년 6월 1일 월요일 전후` |

같은 하루가 **월요일이자 6월 2일이자 화요일**이었다. 브리프(6/1 월)와
초고(6/2)가 어긋난 채로 승인까지 흘러간 것이 출발점이다.

셋째로 **방학식 요일이 어느 달력으로도 틀렸다.** 지면(EP50)은 날짜만
적었으나(`방학식은 7월 15일이었다`) 선례대장·standing-guards·SNAP은
**목요일**로 기재했다. 여름 달력이면 수요일, 실제 달력이면 금요일이다.

## 2. 무엇을 했나

**여름편 전 날짜 +5일.** 요일 라벨은 −2 ≡ +5 (mod 7)이므로 **21화의
요일 표기가 한 글자도 바뀌지 않는다.** 발표회 금요일, 주말 작업, 결석한
화요일이 전부 그대로 유지된다.

**방학식은 7월 15일 → 7월 22일(금)로 연기.** +5 시프트만 하면 EP61에서
방학식까지가 22일 → 17일로 줄어 S10이 좁아진다. 연기로 24일을 확보했다.

### 2-A. 지면 수정 — 딱 세 곳

| 화 | 전 | 후 |
| --- | --- | --- |
| EP41 §1 | `6월 첫 월요일은` | **`6월 첫 화요일은`** |
| EP41 §5 | `6월 2일` | **`6월 7일`** |
| EP50 | `방학식은 7월 15일이었다` | **`방학식은 7월 22일이었다`** |

2050년 6월 7일은 실제로 **6월의 첫 화요일**이다. 개막 문장의 리듬이
그대로 살고, 장부 날짜·SNAP·브리프가 처음으로 한 날을 가리킨다.

### 2-B. 상태·기록 문서

사전 정정 6건(EP41의 날짜 표기를 6/2로 통일) 후 **126개 파일 / 501건**
일괄 치환. 백업 보관. 이어서 낡아 있던 범위·기간 서술 10건을 정정했다
(S9 종료일, S10 잔여 기간, EP50→방학식 간격, 선례대장·standing-guards).

### 2-C. ★ 일괄 치환의 함정 — 아크 카운터

`M/D` 날짜 표기는 이 프로젝트의 **아크 진행 카운터와 형식이 같다.**
기계적 치환은 다음을 전부 망가뜨린다.

| 형태 | 실제 뜻 |
| --- | --- |
| `S8 7/10` · `S9 6/12` · `S6 완결(6/6)` | 아크 진행(10화 중 7화) |
| `진행 중(6/10)` | 아크 진행 |
| `Level 6/7 전 장부 대조` | Level 6/7 |
| `종료장부 7/7·8/8` · `(7/7·6/6 부합)` | 대조 건수 |
| `buoys 7/5/2` · `부표 7/5/2` | **부표 번호** |

분류기로 91건을 걸러 냈다. **앞으로 날짜를 일괄로 손댈 일이 있으면 이
표를 먼저 볼 것.**
