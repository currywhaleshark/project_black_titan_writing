## 1. 아크 한 줄

이상 없다는 검사 결과로 열린 여름은 낯익은 놈이 쏘고 새 놈이
때리면서 `이번 여름은 다르다`를 몸에 새겼고, 아크가 닫힐 때
세 사람은 각자 다른 종이 앞에 앉아 있었다 — 목록, 표, 그리고
아무것도 안 든 팔.

## 2. 사건 골격 (EP별)

- **EP41 「재검」** — 6월 재검·**이상 없음**(안심 확정)·2주의 잠잠함·
  여름 장부 개시(`이상 없음`)
- **EP42 「발표 주간」** — 하랑 첫 무대·동그라미 지불·떡볶이 청구권
  지불(어묵 낙착)·수아 라인 생활
- **EP43 「낯익은 신호」** — 통제 소문 재가동·혜정 **반의식 1눈금**
  (실무 즉시 정리·자문 0)·신호 복귀
- **EP44 「다른 여름」** ★ — **여름 첫 출격.** 수몰 구시가지(수심 =
  기체 허벅지·물 위 열몇 층)·**첫 피격**(관통 0·밀림 다수)·
  `저건 나를 부수려고 왔다`·맨손의 한계·훅 = `간격이 있다`
- **EP45 「빗속을 걷는 법」** — 스콜·투척 3회(조준 교란)·간격을 셈에
  넣은 접근·**여름 첫 격파**(가시 부러뜨리기 → 내려치기)·수아 대조
  결론(`가시만 나중에 바뀐 거예요`)·**앵커 필요성 2단**
- **EP46 「기록의 온도」** — 하부 점검(영진 동행)·군 기재 전환
  (`접촉 시도`→`원거리 공격 확인`)·**외신 한 줄**(센티널 1단)·
  소문의 결 = 무서움 → 걱정
- **EP47 「집게」** — 주간·갯벌 출격(수몰역 → 갯벌 도보)·**불리한
  지형**(이족은 박히고 다족은 뜬다)·집게의 치기/막기/밀기·중계차
- **EP48 「꺾이지 않는 방향」** ★ — **첫 육탄전.** 큰 집게가 물고
  작은 집게가 관절을 비틂 → 눈자루를 꺾음 → 작은 집게 역꺾기 →
  큰 집게 → **박치기.** 유년 몸싸움의 재현(놀이터·이름 모를 남자애)
- **EP49 「여름의 셈」** — 공업 규모 세척·발바닥 이물 처리·**`네
  덕분이야`(값의 비대칭)**·**방송 축 재가동**(영상이 돈다·해석의
  분열)·훅 = 간격이 봄보다 짧다
- **EP50 「간격」** — 망각의 속도(`일상이 소문보다 빨랐다`)·군의
  **공세 전환 판단 한 줄**·**조달 목록 개시 + `기태.`**·기록 체계
  4분할·버티는 시간(10→8→6)·**외해의 크고 느린 질량**

## 3. 확정 정본 (S9가 물려받는 것)

- **전투:** 원거리(무기 없는 쪽의 무력) → 육탄전(주고받기)의 2단.
  **전장 구조 선확정 절차**가 집필 규약으로 승격(수심·엄폐물 내구·
  시야·기동 제약·적 노출·**높이/질량 정합**). 엄폐 자원은 소모품 —
  EP45 전장은 재사용 시 엄폐 0
- **몸:** 관통 0 유지. 새로 얻은 것 = **구속의 두 종류**(가두기 ↔
  망가뜨리기)·**관절에는 방향이 있다**·**쇳소리 = 저쪽이 곤란하다는
  신호**·흘리기(비스듬히 받으면 옆으로 간다)
- **무기 공백:** 팔보다 긴 것 + 손에서 놓지 않아도 되는 것 →
  **조달 목록으로 물질화**(명명 0). **S9 = 개발 아크**
- **기록:** 수아 = 점검표 넉 장 + 빈 칸 예약 / 영진 = 여름 장부
  앞쪽(관측)·뒤쪽(조달), **동그라미 = 먼저 할 것**
- **도시:** 여론 4단계 완주 — 소문 → 걱정 → 해석의 분열 → **소진.**
  **방송 축 상시화**(주간·개활지 교전은 찍힌다·기체만·조종석 0)
- **군:** 관측에서 판단으로. `대응 방침 재검토 요함` — 다만 대상란은
  넉 달째 공란(**명명 게이트 불변**)
- **가족:** 침묵의 질이 공포에서 신뢰로 바뀜(**빚 해소는 0**).
  `안 물어보는 집` 성립
- **시계:** 방학식 = **2050년 7월 22일(금).** EP50 = 6월 중순 →
  S9 전량 + S10 전반이 남은 4주 안
