## 1. ★★★★★ 소급 작업

### 1-1. 괴수 체액 밑밥 보강

| 항목 | 내용 |
| --- | --- |
| **문제** | 절단·관통 등 **내부에 확실히 피해를 준 장면**에 검붉은 액체 묘사가 빠진 곳이 있다 |
| **이유** | 8/31 관통상의 붉은 액체로 **생체성을 드러내는** 것이 원래 계획 · **괴수와의 연결성**을 위해 계속 깔았어야 한다 |
| **상태** | **★★★ 소급 1차 완료(2026-08-23)** — 사용자 첨삭 **20건 / 16개 화** 적용 |
| **적용 화** | EP016·023·031·035·039·040·045·048(2)·053·064·068·070·073·085·095(2)·102(3) |
| **밀도** | **4화 → 16화.** 봄·여름 교전 화의 절반 이상이 내부 피해에 체액을 갖는다 |
| **★★★★ 용해와 체액은 다른 것이다** | 2026-08-23 사용자 정정. **용해** = 개체가 물·비에 닿아 풀어지는 것(EP016 후반 `붉은 물이 빗물에 섞여`) — **사후 처리이고 밑밥이 아니다.** **체액** = **격파 순간에 내부에서 튀어나오는 것.** 이번 소급은 **후자의 신설**이다. 같은 회차 안에 둘이 다 있어도 서로 다른 사건이다 |
| **★★ 매질 규칙** | **수중**(잠긴 상태) = **안개처럼 피어오른다·번진다**(EP031·035) / **지상·수면 위** = **쏟아진다·솟구친다·분수**(EP040·070·073). **★ 수면 위로 몸통이 나온 개체는 지상 취급**(EP073 — 은신이 풀리는 자리가 물 가운데일 뿐 몸은 물 밖) |
| **★ 잔여 0** | **EP103~114에는 직접 전투 묘사가 없다**(2026-08-23 사용자 확인). 봄·여름 교전 화는 전수 완료 |
| **앞으로** | **★★★ 신규 전투에서 내부 피해 장면에는 반드시 넣는다**(상시 가드 §5) |
| **★★★★ 회수처** | **8/31 관통상.** 괴수가 흘리던 것과 **타이탄이 흘리는 것이 같은 색**이라는 게 이 밑밥의 값이다. EP009의 `닦아도 다시 검붉었다`(걸레)가 타이탄 쪽 선행 밑밥 |

### 1-2. ★★★★ 연구단지 = 괴수의 목표

| 항목 | 내용 |
| --- | --- |
| **원래 설계** | 연구단지는 **첫 괴수의 목표**였고, 인간 측 전원이 **「괴수가 이유는 모르지만 연구단지를 노린다」**고 오해하게 만드는 장치 |
| **목적** | **★★★★ 괴수가 청해로 오는 진짜 이유**(마지막 단계 비밀)를 **은폐**하는 것 |
| **문제** | **어물쩍 넘어가 버렸다** — 봄편 이후 연구단지가 전투 목표로 안 나온다 |
| **현황** | 연구단지 언급은 **EP001~018에만** · EP019 이후 **0** |
| **필요** | ① 봄편에 **그 오해를 명시**하는 서술 보강 ② 이후 회차에서 **오해가 유지되고 있음**을 주기적으로 확인 ③ 마지막 단계에서 **뒤집기** |
| **시점** | **미정 — 별도 회차로 잡을지 소급으로 갈지 결정 필요** |
