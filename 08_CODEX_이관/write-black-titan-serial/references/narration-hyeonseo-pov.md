## 2. ★★★★★★ 서술 문법 — 원인 추적

### 2-1. 세 박자

| # | |
| --- | --- |
| ① | **★★★ 관찰** — 본 것을 정확히 |
| ② | **가설** — 그러면 무엇인가 |
| ③ | **★★★★★ 검증 또는 보류** — **모르면 모른다고 적는다** |

**★★★★★★ ③에서 안 끝내는 것이 이 인물의 정직함이다.**
**★★★ 답이 없으면 답이 없다고 두고 다음으로 간다.**

### 2-2. ★★★★★★ 자기 자신도 대상이다

**★★★ 죄책감이 후회의 형태로 안 온다. 인과 추적의 형태로 온다.**

| 안 쓴다 | **★★★ 쓴다** |
| --- | --- |
| 「후회한다」 | **「그때 그렇게 했고 그래서 지금 이렇다」** |
| 「미안하다」 | **★★★★★ 사실을 하나 더 준다** |
| 「어쩔 수 없었다」 | **★★ 조건을 적는다** |

> **[말투 카드 §2]** **사과를 못 한다. 죄책감이 너무 커서 문장이 안 만들어진다. 대신 정보를 준다.**

**★★★★★★ 서술에서도 같다.** 미안하다는 생각이 오면 **그 자리에 사실이 온다.**

### 2-3. ★★★★★ 용어를 안 만든다

> **[G0-028 §2-2]** **현서는 관찰자다. 본 것을 적고 추론을 붙일 뿐 체계 이름을 안 만든다.**

| 쓴다 | 안 쓴다 |
| --- | --- |
| **★★★ 「저것」 · 「그것」 · 형태 · 크기** | **★★★★★★ 「엑소포밍」·「가지」·「허브」·「인큐베이터」 = 영구 0** |
| **★★ 「고래상어 같았다」** | 분류명 · 학명 · 코드 |
| **관측 결과** | **★★★ 자기가 붙인 이름** |

**★★★★★ 이름은 나중에 남이 붙인다.**

## 3. ★★★★★★ 과거 현서 (EP142)

### 3-1. 문장

**★★★ 길다. 그리고 끝까지 간다.**
**★★ 관찰 → 가설 → 결론이 한 문단 안에서 완결된다.**

### 3-2. ★★★★★★ 공포를 쓰는 법

**★★★ 이 인물이 처음으로 원인을 못 찾는 자리다.**

| 층 | |
| --- | --- |
| **★★★ 본다** | 물 너머 · 창 하나 두고 · 육안 |
| **★★★★★ 몸이 먼저 반응한다** | 손 · 호흡 · 시간 감각 |
| **★★★★★★ 그리고 그것을 관찰한다** | **자기 반응까지 기록한다** |
| **★★ 이름은 안 붙인다** | 「무서웠다」를 안 쓴다 |

**★★★★★★ 자기가 무서워하는 것을 관찰하는 사람이다.**
**★★★ 그게 이 인물의 무서움이다.**

### 3-3. ★★★★★ 변화 곡선 (G0-028 §8)

| 단계 | 시기 | 서술 |
| --- | --- | --- |
| **① 절박 · 반쯤 광기** | 2036~37 | **★★★ 문장이 빨라진다** · 조건이 안 붙는다 |
| **② 자기 몸까지** | | **★★ 담담하게 적는다** — 그게 더 이상하다 |
| **③ 도구에서 아이로** | 2038~40 | **★★★★★ 「관찰」이 「보기」로 바뀐다** |
| **④ 엄마 노릇** | 2040~41 | **★★★ 그런데 그것도 관찰한다** |

**★★★★★★ ③이 서술에서 보이는 방식** — **적는 항목이 바뀐다.**
체중 · 반응 속도 · 수면 시간을 적다가, **어느 날부터 다른 것을 적는다.**

**★★ 그게 이 인물이 사랑을 표현하는 유일한 형태다.**

## 4. ★★★★★★ 현재 현서 (EP144·145·6-10)

### 4-1. 끊는다

> **[말투 카드 §2]** **정확하고 긴 문장을 시작했다가 중간에 끊는다. 끊은 자리를 다시 안 잇는다.**

**★★★ 서술도 같다.**

| | |
| --- | --- |
| **★★★ 문장이 중간에 선다** | 마침표가 이르게 온다 |
| **★★★★★ 안 이은 자리** | **다시 안 돌아간다** |
| **★★ 그 대신** | **다음 사실로 간다** |

### 4-2. ★★★★★ 손끝으로 두 번 두드린다

**★★★ 말을 멈출 때 나온다.** 책상 · 유리 · 차트.
**★★★★★★ 본인은 그것을 모른다** — 서술에서 자기 손을 안 본다.

**★★ 그래서 이 디테일은 타인 시점에서 더 잘 보인다.**
**★★★ 현서 시점에서는 「손이 무언가에 닿아 있었다」 정도까지만.**

### 4-3. ★★★★★★ 아이들을 볼 때

| | |
| --- | --- |
| **★★★ 관찰을 멈추지 못한다** | 얼굴색 · 손 · 앉은 자세 |
| **★★★★★ 그리고 그것을 부끄러워한다** | **부끄럽다는 말은 안 쓴다** |
| **★★ 호칭** | **`단아` · `수아`** — 「우리 딸」 계열 **0** |
| **★★★★★★ 자칭** | **「엄마가」 = 금지**(말투 카드 §2) |
