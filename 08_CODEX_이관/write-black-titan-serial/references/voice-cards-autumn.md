## 0. ★★★ 루시의 한국어 — 확정 (2026-08-21)

> 작전지역이 청해 인근이 될 거라는 건 알고 있었을 테니 한국어 교육을
> 받았을 거라 추측은 할 수 있는데, **그게 불완전한 느낌으로 가면
> 좋겠네**

**확정: 배웠다. 다만 배운 만큼만 안다.**

### 왜 배웠는가

**작전지역이 이미 청해 인근으로 정해져 있었다.** 그래서 훈련 과정에
한국어가 들어갔다. 생활을 위해서가 아니라 **임무를 위해서** 배웠다.

**★★★ 그래서 배운 것과 안 배운 것의 경계가 뚜렷하다.**

| 완벽한 영역 | 공백인 영역 |
| --- | --- |
| 군사·절차·보고 용어 | **생활어 · 시장 말** |
| 표준 문형 · 기본 회화 | **축약 · 구어 · 반문** |
| 문어체 존댓말 | **관용구 · 속담 · 비유** |
| 지명 · 행정 어휘 | **아이들 말 · 유행어** |
| 인쇄된 글자 | **손글씨 · 간판 흘림체** |
| 규칙으로서의 경어 | **상황으로서의 경어** |

### ★★ 불완전함이 드러나는 방식

1. **교재 문형을 그대로 쓴다** — `이것은 얼마입니까?`
   → 미란: `얼마긴 얼마여, 삼천 원이지` → **못 알아듣는다**
2. **관용구를 문자 그대로 받는다** — `발이 넓다` → 신발 치수를 묻는다
3. **존댓말과 반말이 문장마다 튄다** — 규칙표에서 고르기 때문
4. **모르면 모른다고 한다** — `그 표현은 이해하지 못했습니다`
   (이것만은 완벽하게 배웠다)

**★★★ 이것이 설정집의 「효율과 규칙만으로 반응해 갈등을 만든다」와
정확히 맞물린다.** 관용구를 모른다 = 문화를 모른다.
존댓말을 규칙으로 안다 = **관계를 규칙으로 안다.**

### ★★★ 모르면 영어로 말한다 (2026-08-21 추가 확정)

> 자기가 표현을 모르겠으면 그냥 영어로 말하는 것도 좋겠다.
> **통역이 그래서 필요한 거고**

**한국어로 할 수 있는 것은 한국어로, 안 되면 즉시 영어로 전환한다.**

- **망설이지 않는다.** 단어를 찾느라 멈추는 것보다 영어가 **효율적**
- **무례하다고 생각하지 않는다** — 상대가 못 알아들으면 통역이 있다
- **★★ 통역이 없으면 그냥 안 통한 채로 둔다.** 다시 설명하지 않는다

### ★★★ 지면 처리 — 시점에 따라 갈린다

| 시점 | 영어 발화의 처리 |
| --- | --- |
| **단아·타인 시점** | **내용이 안 나온다.** `영어로 뭐라고 했다` · 짧은 단어는 그대로(`Efficient.`) · **못 알아듣는 것이 곧 정보** |
| **루시 시점** | **한국어로 서술한다.** 자기 말이므로 독자에게는 다 보인다 |
| **백가온이 있을 때** | 옮겨진 말만 지면에 나온다 · **★ 가온이 한 단어를 고쳐 옮긴다** |

**★★★ 이 비대칭이 6-3의 어긋난 대화를 만든다.**
단아와 단둘일 때는 통역이 없다. **루시는 중요한 말을 영어로 했고,
단아는 그걸 못 들었다.** 독자만 나중에 안다.

### ★ 영어로 새는 지점 (전형)

| --- | --- |

| 관용구를 되받아칠 때 | 대응하는 표현을 모른다 |

**★★ 후반부의 신호:** 화가 났는데도 **한국어로 말하려고 애쓴다.**
그게 관계가 생겼다는 증거다.

## 2. ★★★ 도현서 — 설명하려다 멈추는 사람

| 항목 | 내용 |
| --- | --- |
| **기본 리듬** | **정확하고 긴 문장을 시작했다가 중간에 끊는다.** 끊은 자리를 다시 안 잇는다 |
| **어휘** | 학술어와 생활어가 **한 문장에 섞인다.** 딸에게 말하다 **연구자 어투가 새어 나온다** |
| **★★ 영어 혼입** | 단어 단위로만. `케이스` `데이터` `프로토콜`. **문장째 영어는 안 쓴다** |
| **관심사** | 정확성 · 원인 · **자기가 무엇을 했는지** |
| **★★★ 감정 우회** | **사과를 못 한다.** 죄책감이 너무 커서 문장이 안 만들어진다. 대신 **정보를 준다** |
| **호칭 기본값** | 단아 → `단아` · 수아 → `수아` · 영진 → **`아버지`**(존댓말) · 루시 → `루시` |
| **★ 고유 긴장 디테일** | **손끝으로 표면을 두 번 두드린다**(책상·유리·차트). 말을 멈출 때 나온다 |
| **금지 표현** | `미안해`(후반까지) · `엄마가` 자칭 · 변명 · 눈물 섞인 발화 |

### ★★ 딸에게 말할 때의 실패 구조

1. 다정하게 시작한다
2. **정확하게 말하려다 설명이 된다**
3. 그게 상처인 걸 알아채고 멈춘다
4. **멈춘 자리를 안 메운다**

> "많이…… 컸네. 키가."
> "……"
> "재 본 적 있니. 언제."
