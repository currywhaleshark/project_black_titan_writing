## 0. ★★★★★★ 한 줄

**★★★ 수아는 센다. 세서 순서를 만들고, 순서가 있으면 뭘 할지 안 정해도 된다.**

> **[EP119]** **`순서라는 게 원래 좋은 거라고 수아는 생각했다.`**
> `집에서도 순서가 있었다. 일어나서 세수하고, 언니 깨우고, 밥 먹고, 가방 들고 나갔다.`
> **`순서가 있으면 뭘 할지 안 정해도 된다.`**

## 1. ★★★★★★ 세 자매의 인지 분담 (상시 정본)

| | |
| --- | --- |
| **단아** | **몸으로 깨닫는다** — 몸이 먼저, 말이 나중 |
| **★★★★★★ 수아** | **머리로 그린다** — 세고, 배치하고, 순서를 만든다 |
| **루시** | **훈련으로 안다** — 절차와 서식 |

**★★★ 단아 시점의 「자기 분석 금지」가 수아에게는 적용되지 않는다.**
**★★★★★ 수아는 자기가 뭘 하고 있는지 안다.** 다만 **감정에는 이름을 잘 안 붙인다.**

---

## 2. ★★★★★★ 숫자가 서술의 뼈대다

### 2-1. 무엇을 세나

| 대상 | 예 |
| --- | --- |
| **공간** | **★★★ 천장 판 스물넷**(세로 여섯 · 가로 넷) · 얼룩의 위치 |
| **시간** | **열이레째** · **서른한 날** |
| **횟수** | **미는 거 열 번** · 가방 두 개 |
| **★★ 사람** | 아침에 한 번 바뀌고 저녁에 한 번 바뀐다 |

### 2-2. ★★★★★★ 세다가 그만두는 것으로 변화를 표시한다

> **[EP119]** `이제는 안 세도 어디 있는지 알았다. 그런데도 아침에 한 번씩 셌다. 세는 게 순서에 들어가서 그렇다.`
> **[EP134]** **`천장은 안 센다.`** (…) **`셀 게 있으면 세는데 세고 나서 달라지는 게 없으면 안 세게 된다.`**
> **[EP138]** **`세는 건 오늘로 끝난다. 여기 있는 날을 세는 거였으니까 여기서 나가면 셀 게 없어진다.`**

**★★★★★★ 이것이 이 인물의 성장 문법이다.**
**「나아졌다」를 안 쓰고 「안 세게 됐다」를 쓴다.**

---

## 3. ★★★★★★ 남의 말을 옮기고 한 겹 더 푼다

> **[EP138]** 「미는 거 열 번에서 시작해요. 줄이지 말고.」
> **`줄이지 말라는 건 다음 주에 여덟 번을 하면 안 된다는 뜻이고,`**
> **`안 하면 줄어든다는 걸 이 사람이 알고 있다는 뜻이었다.`**

| 단계 | |
| --- | --- |
| ① | **말을 그대로 옮긴다** |
| ② | **★★★ 그 말의 뜻을 푼다** |
| ③ | **★★★★★ 그 말을 한 사람이 무엇을 아는지까지 푼다** |

**★★★★★★ ③이 수아 시점의 고유 동작이다.** 단아는 ①에서 멈추고 루시는 ②까지 간다.

### 3-1. ★★ 사람을 분류한다

> **[EP138]** **`이 사람은 정확하게 말하는 사람이라 이상하다고 하면 진짜 이상한 걸 말하는 거였다.`**
> **[EP138]** `그러고 갔다. 잘 가라는 말은 안 했다.` / **`수아는 그게 편했다.`**

**★★★ 판단은 하되 평가는 안 한다.** 「좋은 사람」·「나쁜 사람」이 안 나온다.

---

## 4. ★★★★★ 감각의 비대칭 — 직접 쓴다

> **[EP119]** `다리가 있었다. 이불 밑에 있고, 모양대로 솟아 있고, 두 개였다. 손으로 만지면 만져졌다.`
> **`손 쪽에서는 만졌다는 게 오는데 다리 쪽에서는 안 왔다.`**

| 쓴다 | 안 쓴다 |
| --- | --- |
| **★★★ 어디서 오고 어디서 안 오는지** | **「하반신」 · 「마비」 · 「걷지 못한다」**(어휘 봉인) |
| **휠체어** · **미는 거** · 옮기는 것 | 「장애」 · 「불구」 |
| **★★ 슬픔 없이 관찰로** | 자기연민 · 원망 |

**★★★★★★ 수아는 이것을 사건으로 안 다룬다. 조건으로 다룬다.**

---

## 5. ★★★★★ 간접 정보로 세계를 안다

> **[EP134]** `여기는 방 안에서는 아무 소리도 안 나고 복도 소리만 들어온다.`
> **`그래서 몇 시쯤인지를 복도로 안다. 카트가 지나가면 아침이고, 발소리가 많아지면 면회 시간이다.`**
> **[EP134]** `문 밖에는 사람이 서 있다. 유리창으로 어깨쯤이 보인다.`

**★★★ 못 보는 데를 소리와 그림자로 채운다.**
**★★★★★ 루시가 「값으로 안다」면 수아는 「배치로 안다」.**

## 7. ★★★★★★ 관계 — 한 발짝 뒤, 타인 먼저 (상시 가드)

| | |
| --- | --- |

| **영진에게** | **★★★★★ 존댓말** |
