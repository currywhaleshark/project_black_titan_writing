## 2. 회차 전체 리듬

```text
대피선: 손이 먼저 가는 선생 → 둘러대기 → 지나친 마지막 한 컷
→ 여덟 팔: 부수지 않고 짚고 오르는 것 → 방향이 꺾이는 순간
→ 포박: 감기 넷, 붙는 넷 → 당기는 힘이 어디로 가는가
→ 계단: 진동 — 휘청 — 밀어내는 손 — 잘못 디딘 발
→ 소등: 하나씩, 그리고 한꺼번에
```

- 문체 축은 **전달**이다 — 힘이 손에서 옹벽으로, 옹벽에서 계단으로,
  계단에서 발목으로 옮겨 가는 인과를 해설 없이 물리로만 잇는다.
- 시점: S1·S3·S5 단아 / S2 단아+군 교차 / **S4 성호 밀착 외부**(§6-8 —
  `검은 거인`, 내부 고유명 0).
- 씬 밴드: S1 1,200~1,500 / S2 1,400~1,700 / S3 1,400~1,700 /
  S4 800~1,100 / S5 500~800 (목표 5,800)
- 리듬: S1 급박 중문 → S2 관측 보고 리듬 → S3 감기는 단문 누적 →
  S4 최단문 수렴(사슬의 종점) → S5 소등의 느린 정지.

## 3. 장면별 문단 비트 잠금

### Scene 1 — 대피와 이탈 (1,200~1,500자)

1. 학년별 대피선 가동 — 훈련 문장·실전 속도(EP19 회수, 문장 0).
   **김주호 잠금:** 걷은 소매, 울거나 멈춘 저학년을 앞쪽 교사에게
   손으로 넘기는 반복 — 외침 0, 동작만.
2. **둘러대기(잠금 문면):** `수아네 줄에 가 볼게. 할아버지랑 만나기로
   했어.` → 혜정 수신 1문장 상한(`조심해. 이따 대피소에서 봐` 계열 —
   동행 제안 0). 예진 0~1비트.
3. **마지막 목격(잠금):** 모퉁이 직전 뒤돌아본 한 컷 — 성호가 주호와
   같은 동작으로 저학년 하나를 앞으로 보내며 후미에 서는 모습. 단아의
   반응 서술 0(지나침 자체가 비트 — EP24 회수 예약).
4. 이탈 실행 — 골목·모퉁이(EP19 셈의 집행). 수리점 도착·탑승 압축
   (2~3문단 상한 — 절차 나열 금지, EP15 문장 0). 영진 한 줄:
   `보이는 대로 불러라` 계열(정보 부족 상태의 출격).

### Scene 2 — 첫 노출: 여덟 개의 팔 (1,400~1,700자)

1. 해안 진출 — 역류의 근원 방향. **첫 노출(잠금):** 침수구역에서
   여덟 팔이 구조물을 **짚으며** 올라오는 것 — 부수지 않는 접근
   (버리고 짚고 넘는 결, 파괴음 부재의 물성). 초록 점등 1컷(G0-009).
   개체 소리: 젖은 흡착음 계열 허용(G0-010 — 위협·이동시).
2. **군 교차(§6-9 앵커):** `남해방위사령부`(고명준)·`전속부관 윤서진
   대위` 직책 어구 각 1회. **B2 잠금:** 학생 대피선·전투구역 분리,
   해안도로 소개. 공개주파수 = 피난행렬 위치·붕괴 위험구역만.
   교전 명령 0. 기록명 입안: `다완 흡착체`(서진 1비트).
3. **우선순위 전환(잠금):** 타이탄이 시야에 들어서는 순간 — 구조물을
   짚던 팔들의 방향이 일제히 꺾인다. 서술은 방향 전환의 물리만
   (`찾았다`·`노렸다` 0). 단아의 체감 한 줄: `저건 도시를 보러 온 게
   아니다` 계열 상한(추정 — 이유 0).

### Scene 3 — 포박 (1,400~1,700자)

1. **감기 넷(잠금 순서):** 머리(카메라부터 — 화면 가장자리 잠식 개시)
   → 팔꿈치 → 무릎 → 허리. **감김·조임·압박 계열 어휘만**(관통·꿰뚫
   0). 조이되 부수지 않는 결 — 장갑이 우는 소리는 있되 균열 서술 0.
2. **붙는 넷:** 옹벽·방재벽에 차례로 흡착 — 흡착면의 물성(빨판 계열
   직유는 1회 상한, `문어` 단어 0). 바다 방향 견인 개시 — 발바닥이
   노면을 긁는 §5 물성(EP1 콜드오픈 문장 재사용 0).
3. **첫 저항(잠금 — 사슬의 기점):** 허리의 팔 하나를 **양손으로 잡고
   힘으로 뒤로 당긴다.** 팔은 늘어나되 풀리지 않고 — **당기는 힘이
   옹벽의 견인 팔로 옮겨 가 옹벽 쪽이 크게 당겨진다**(전달의 물리
   1~2문장 — 해설 0. S4의 다리).
4. 시야 잠식 — 카메라가 하나씩 덮인다. 남은 화면으로 보는 세계가
   좁아지는 결. 단아의 판단 한 줄: `힘으로 하나씩 풀면 된다` 계열
   (EP21에서 깨질 오답의 심기 — 확신형).

### Scene 4 — 계단 (800~1,100자) ※ 성호 밀착 외부 시점

1. 젖은 대피계단 — 후미: 주호, 성호, 겁먹은 저학년 하나. 성호 시점
   호칭: `김주호 선생님`·`검은 거인`. 내부 고유명 0.
2. 성호가 보는 전장 반 컷 — 여덟 팔에 감긴 검은 거인의 원경.
   응원 반 문장(`저래도 진 적 없다` 계열 — 발화 또는 속말 1회 상한).
3. **충격 도착(잠금):** 옹벽 쪽에서 오는 큰 진동 — 계단 손잡이가
   울고, 고인 물이 튄다. 아이가 휘청 —
4. **발목(잠금):** 성호가 아이를 난간 안쪽으로 밀어내고, 빈 자리를
   디딘 자기 발이 젖은 모서리를 잘못 딛는다. 접질림 — 주저앉음.
   비명 최소(`억` 한 음절 상한). 골절 아님의 물성: 짚고 일어서려다
   도로 앉는 정도.
5. 혜정·주호 부축 — 혜정 실무(부축·가방), 주호 판단(`업는다` 계열
   1문장). **성호의 마지막 컷(잠금):** 계단 아래 전장을 한 번 더
   본다 — 원망 없는 눈(발화 0, EP24 씨앗).

### Scene 5 — 훅: 꺼지는 화면 (500~800자) ※ 조종석 밀착

1. **미인지 보장:** 이 씬에 학교·계단·성호 정보 0. 단아의 세계는
   좁아지는 화면뿐.
2. **소등 2단(잠금):** 남은 카메라가 구역별로 하나씩 죽는다 —
   하나 꺼질 때마다 세계가 조각으로 줄고 — 마지막, 머리 센서가
   완전히 덮이며 **한꺼번에 검어진다.** 동시에 다른 팔이 두 무릎을
   한데 묶는다(감각으로 전달 — 보이지 않으므로).
3. 조종석 — 비상등의 낮은 주황만. 보이지 않는 채로 감겨 있는 최초의
   상태(EP2의 어둠 인용 0 — 새 문장). 끝.
