### ★ 6번이 유발한 소급 정정

남방사(사령부급)의 대외 협조 상대는 **경찰청**이고 경찰서·파출소는
그 아래다. EP89 승인본이 「시청하고 경찰서에」로 한 단 낮게 쓰여
있어 **3곳을 소급 정정**했다(별도 기록:
`Black_Titan_소급정정_2026-08-19_협조공문_수신기관_v1.0.md`).

```
남방사(고명준) ─ 협조 요청 ─┬─ 시청 (도로 통제)
                            └─ 경찰청 (순찰·검문)
                                 └─ 경찰서 └─ 구래파출소
```

**씬 3의 「구래파출소」는 정정하지 않았다** — 집행 단위로 정확하며,
오히려 **계층 3단 거리**가 이 화를 강화한다. 마당에 온 사람이 이유를
모르는 게 구조적으로 당연해진다.

### 168·176번의 효과

- `나한테는 말하랬지` — 배타 조건(걔한테 말고)이 아니라 **수용형**이
  되어 예진이 다그치지 않고 받아 주는 쪽이 된다
- `그것 때문일까` — 혜정이 날짜를 들이대는 대신 **불안을 그대로
  내놓는** 형태. 뒤따르는 `네가 물어본 거랑 순찰차랑 무슨 상관이야`가
  정확히 받는다

## 4. 설계 잠금 완수 확인

| 잠금 | 지면 구현 |
| --- | --- |
| **거짓말 0** | 부정 발화 0 · 장부 전부 사실 · 화제 이동만 |
| **간신히 = 운** | 궤짝 앞 두 걸음 → **손목시계**가 부름 |
| **부르지 않는다** | `부르면 저기 볼 게 있다는 뜻이 된다` |
| **확증 실패 + 유지** | 특이사항 없음 · **기간 미정** |
| **자책 근거 = 시점만** | 인과 확증 0 · 두 생각 동시 |
| **예진 = 판정 대행** | `대답 못 하면 네 잘못 아닌 거야` |
| **단아 = 아무것도 모름** | `요즘 세상이 하도 험하니까` |

## 5. 이 화가 남긴 것

- **★★★ 아무도 거짓말을 하지 않았다.** 서진은 안 적었을 뿐이고,
  경찰은 시킨 대로 왔을 뿐이고, 영진은 사실만 말했고, 혜정은 친구를
  걱정했을 뿐이다. **그런데 넷의 자리가 전부 조금씩 나빠졌다**
- **★★★ 오늘은 안 진 것이지 이긴 게 아니다.** 영진 본인이 그걸
  안다 — `계속되면 언젠가 찾는다`
- **★★ 그물은 사람의 악의가 아니라 절차로 커진다.** 안 적은 칸이
  이번엔 넓히는 쪽으로 작동했다(반경 없는 기준 3연째)
- **★ 확증 실패가 확신을 못 깎는다** — 검문선이 상수가 된다
