## 2. ★★★★★★ 백가온 — 카드 실독 (이 회차의 축)

### 2-1. 카드

> **[말투카드 가을 §백가온(28)]** 실무체 + 또래 어투 **혼용** · 호칭 **`루시 씨`** ·
> 고유 긴장 **한 단어를 고쳐 옮긴다** · 금지 **사견 노출 · 감정 이입 표시**
> 예시: **`그건 여기선 그렇게 안 해요. 이유는…… 저도 몰라요.`** /
> **`……라고 하시는데, 조금 부드럽게 옮겼습니다.`**

> **[§70]** **백가온이 있을 때 — 옮겨진 말만 지면에 나온다.**

### 2-2. ★★★★★ 지면 실측 인장

| 인장 | 근거 |
| --- | --- |
| **이름을 말해 준다** | EP121 — 봉투에서 하나씩 꺼내서 |
| **반 걸음 뒤** | EP122 — 끼어들지 않고 값을 대신 묻지 않는다 |
| **근거를 말하지 않는다** | EP122 — `말하지 않은 것인지 말할 것이 없는 것인지는 알 수 없었다` |
| **두 번 보지 않는다** | EP122 |
| **한 박자 쉰다** | EP121 |
| **8시 4분** | EP122 |

### 2-3. ★★★★★★ 금지 경계 — 사견과 사실을 가른다

**카드 금지: 사견 노출 · 감정 이입 표시.**

| 된다 | 안 된다 |
| --- | --- |
| **★★★ `그건 제가 알아본 거예요`** — 사실 진술 | `안타까워서요` · `그분들도 힘드시니까` |
| **★★ `그건 상황 봐서요`** | `제 생각에는` |
| **★★★★ `이유는…… 저도 몰라요`** | `저도 이해가 안 가요` |

**★★★★★ 가온은 무엇을 했는지는 말하고 왜 했는지는 안 말한다.**
**그것이 EP122의 인장이고 이 회차 내내 유지된다.**

### 2-4. ★★★★★★ 「루시 씨」 초출 — 자리를 정한다

**지면 실측 0회.** 루시는 「백가온 씨」로 두 번 불렀다(EP122).

| 자리 | 판정 |
| --- | --- |
| 주민 앞 | **★ 아니다** — 그 자리에서 루시는 바깥이다 |
| 시장 | 아니다 |
| **★★★★★★ 대문 앞에서 갈 때** | **★ 여기다** |

> **[EP122]** **백가온은 대문 앞에서 갔다.** 오후에 볼일이 있고 내일은 일요일이라
> 오지 않는다고 했다.

**★★★★★ 같은 자리 · 같은 동작 · 이번에는 이름이 붙는다.**
**★★★ 문장은 EP122와 다르게 쓴다**(축자 중복).
