## 2. 회차 전체 리듬

```text
첫 더위: 약속 위로 쌓이는 쪽지들 — 정오까지만
→ 대목: 나르는 언니, 그리는 동생, 고치는 할아버지
→ 정오: 셔터 — 장부를 되가져가지 않는 손
→ 그늘: 전장이 소풍 자리가 되는 방재벽 — 고쳐 둔 선물
→ 훅: 새 케이스 위의 두 줄
```

- 문체 축은 **온도**다 — 첫 더위의 물성(끈적임·그늘·찬물)과 가족
  온기(말싸움 포함)를 같은 감각 축에서. 전투 화의 셈 언어는 쉬고,
  생활의 손 언어로.
- 시점: 전편 단아 밀착. S5만 저녁 결.
- 씬 밴드: S1 900~1,200 / S2 1,300~1,600 / S3 900~1,200 /
  S4 1,200~1,500 / S5 400~700 (목표 5,500)
- 톤 가드(생활 버전): 단아 몸 먼저 2~3비트, 경보 공백 낯섦 1~2비트
  (이유 0). 삼분법 리듬 대비 = 이 화의 §6-① 핵심.

## 3. 장면별 문단 비트 잠금

### Scene 1 — 약속과 접수 (900~1,200자)

1. 첫 더위의 물성 — 선풍기 꺼내는 아침, 골목의 달라진 냄새, 5월의
   해가 4월과 다른 각도. **오후 휴업 약속 재확인**(영진이 먼저 한
   약속이라는 결 — 어린이날의 무게).
2. 쌓이는 것들(잠금): 노인의 선풍기, 식당의 냉장고, 문 앞에 놓인
   실외기와 쪽지들. 쪽지의 문면 1~2개(생활 언어 — `급해요` 계열).
3. **반나절 절충(잠금):** `정오까지만`. 급한 순서 — 노인 가구·작은
   식당 우선(정하는 주체 = 영진, 순서 셈 참여 = 수아 예고 비트).
4. **경보 공백 1비트(§6-②):** `사이렌 시간에 사이렌이 없다` 계열 —
   낯섦만, 추측 0.

### Scene 2 — 대목 (1,300~1,600자) ※ 삼분법의 생활 전시

1. **단아 = 몸(잠금):** 실외기를 무거운 쪽부터 잡는다 — 생각은 든
   다음에. 계단 오르내리기, 공구 가방. 두 달 단련의 생활 환산 유머
   1비트(`이 정도는 한 손` 계열 — 고유명 0, 출격 언급 0).
2. **수아 = 머리(잠금):** 접수표 — 순서·부품 유무·돌려줄 시간.
   **중복 주문 1건**(같은 집이 두 번 접수)과 **빠진 연락처 1건**을
   찾아내는 구체 비트. 그리는 셈의 물성(표·화살표·줄 긋기).
3. **교차 1회(§6-① 잠금):** 같은 접수 하나를 두 사람이 다르게 —
   단아는 들어 보고 무게로 판단, 수아는 표를 보고 순서로 판단.
   결론이 같아서 웃기는 결(해설 0).
4. **미란 1컷(잠금 — 리마인드 필수):** 수산시장 좌판·냉장 앵커
   문면(`좌판 얼음이 버티는 시간` 계열) + 실무 대화 1~2행. 정호·
   기태 언급 상한 반 줄.
5. 답례의 결 — 미숫가루·오이 계열 1~2비트(과장 0, 동네의 문법).

### Scene 3 — 정오의 마감 (900~1,200자) ※ B3 핵심

1. 정오 도착 — 남은 쪽지들에 대한 처리(내일로·순서 적어 붙이기 —
   버리지 않는 결). 셔터 내리기.
2. **위임(잠금 — B3 첫 인정):** 영진이 접수표를 되가져가지 않는다.
   `마지막 확인은 네가 해라` 계열 1문장 + 표를 고쳐 쥐는 수아의
   손(놀람 서술 최소 — 손의 반 박자로만).
3. 단아의 목격 1비트 — 놀림으로 위장한 뿌듯함(`우리 반 반장보다
   낫네` 계열 상한 — 한결 소환은 반 줄만).

### Scene 4 — 방재벽 그늘 (1,200~1,500자) ※ 가족 온기 저장

1. 구래항 방재벽 그늘 — 늦은 점심(포장 국수 또는 김밥 결). **전장이
   소풍 자리가 되는 아이러니는 풍경으로만**(방재벽·바다·집게가
   걸렸던 자리 언급 0 — 그냥 평온한 바다).
2. **선물(잠금 — §6-④):** 손본 두 휴대폰. 설명 대사 0 — 물건의
   상태로만(새 배터리의 잔량 표시, 새 케이스의 색, 모서리의 손질
   자국). 영진의 문법 = 고쳐 두는 것.
3. **반응 대비(잠금):** 단아 `투박해` 놀림(좋아하는 게 다 보이는) /
   수아 일련번호 먼저 확인(그리는 셈의 마지막 비트 — 기록하는 아이).
4. 말싸움·잔소리 포함 온기 — 단아 속말 상한 1~2줄: `괴수를 안
   쓰러뜨려도 지키는 일` 계열(잠언화 금지 — 몸의 확인 언어로.
   `오늘 나른 실외기가 몇 집의 밤을 식힐지` 계열 셈 허용).

### Scene 5 — 훅: 메시지 (400~700자)

1. 저녁 결 — 새 케이스의 휴대폰이 **처음으로** 울린다(선물→약속
   연결).
2. **훅 문면(개요 고정 — 잠금):**
   `내일 열 시. 예진이랑 먼저 기다린다.`
   반 박자.
   `늦으면 늦는다고는 해.`
3. 두 번째 줄의 무게는 해설 0 — **답장을 쓰기 시작하는 손**에서 컷
   (내용 미공개 — EP26 창구). 끝.
