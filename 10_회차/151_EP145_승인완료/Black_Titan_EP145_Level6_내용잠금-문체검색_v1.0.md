## C. 문체 — 서술카드 v1.0 §0 · 수아 카드 v1.1

### C-1. 우선순위

**봉인 자리 말고는 명료성이 먼저.** 이 회차의 봉인 자리 — **둘 사이의 아홉 해** · **엄마의 시선** · **할아버지가 안 따라오는 이유** · 전화 저쪽 목소리.
**그 앞뒤는 사물과 숫자로 또렷하게** — 문고리 · 문턱 · 경사판 · 휠체어 손잡이 · 트렁크 · 운전대.

### C-2. 수아 시점 `[기본값]` (카드 §8)

| # | 이 회차 |
| --- | --- |
| **B1** | 현관·앞마당 문단은 **인물 셋** — 매 문단 주어(할아버지는 / 엄마가 / 수아는) |
| **B2** | 감정 자리 = **센 것**(세 마디 · 여덟 · 열 번 · 다섯 · 일곱) · **세다가 그만둔 것**(카드 §2-2) |
| **B3** | **머리로 그림은 한 번** — 엄마의 아버지가 할아버지라는 **계보를 처음 눈으로 본다**(비트 30). 나머지는 센다 |
| **B4** | 종이가 둘 — **여섯 줄 종이**(수아 것) · 그 밖엔 없음. 전화는 **「전화」**로 |
| **B7** | 할아버지가 **안 탄다**는 부재가 사건 — 부정문 OK |
| **B8** | 영진 = **「할아버지」** 고정 · 현서 = **「엄마」** 고정 · 단아 = **「언니」** |
| **B9** | 빈 곳은 **집 사물**(LOC-05) — 셔터 · 앞마당 콘크리트 · 트럭 · 크레인 붐 · 마루 · 낮은 상 · 받침 · 경사판 |

**인장:** 센다 · 순서를 만든다 · **남의 말을 한 겹 더 푼다**(`…데리고 가라.` → 들어오라는 게 아니라 나갈 길) · 한 발짝 뒤 · 뾰족함 0.

### C-3. `[잠금]` 화계 · 호칭

| | |
| --- | --- |
| **수아 → 영진** | **존댓말** — `누가 데려가요?` |
| **수아 → 현서** | **`엄마` + 해요체** — `할아버지랑 무슨 얘기 했어요?` (EP136 `목요일에 오세요?`) |
| **수아 → 단아** | **반말** — `언니.` (EP138 `안 가?`) |
| **현서 → 영진** | **`아버지` · 존댓말** — `저녁에 모셔다 드릴게요.` |
| **영진 → 현서** | **반말 · 최소** — `…데리고 가라.` `…그래.` |
| **영진 → 수아** | 반말 — `오늘 언니한테 간다.` `…네 엄마가 온다.` |
| **현서 → 수아** | 반말 — `혼자 할 수 있어?` `언니가 기다려.` |

### C-4. 영진 신체 · 목소리 (메모리 · 정본)

**왼팔 결손 — 모든 동작 한 손.** 문고리 · 반찬 뚜껑(받침) · 설거지 · 휠체어 손잡이 · 손 흔들기.
**역비례** — 대사가 짧을수록 감정이 크다. 이 회차 대사 **총 7개 이하.**

### C-5. 현서 목소리 (시점 카드 v1.1 §4 · 타인 시점)

끊는다 · **영진 앞에서 더 짧다** · 톡, 톡(운전대) — **타인 시점에서 잘 보이는 디테일**(카드 §4-2).

### C-6. 표기

시각 = 아라비아(`9시` `10시` · 종이의 `8시 50분` `6시 반` — **EP138 정본 `여섯 시 반`은 수아 머릿속 · 종이에 쓰는 글자는 `6시 반`**) · 세는 수 = 한글(`여덟` `다섯` `열 번`) · 날수 = 한글(`아흐레`).

## D. STYLE_ONLY 문체 검색 (리듬만 · 사건 차용 금지)

| 기능 | 원문 | 가져올 것 |
| --- | --- | --- |
| **옮겨 앉기** | EP119 `한 손은 침대, 한 손은 휠체어 팔걸이. 팔로 몸을 든다. 엉덩이를 돌린다. 내린다.` / `다리 얘기가 없었다.` | **순서를 짧은 현재형으로 나열** → 차 시트 버전(`한 손은 시트, 한 손은 팔걸이`) · **다리는 손으로 들여놓는다** |
| **차 두 대 · 갈라짐** | EP138 `밖에 차가 두 대 서 있었다. / 하나는 앞에 있고 하나는 그 뒤에 있었다. / 수아는 두 대인 걸 봤다.` | **한 줄 사실 → 수아가 본 것 한 줄** 연쇄 · 이번엔 차가 **한 대** · 할아버지 **안 탄다** |
| **손을 드는 높이** | EP138 `손을 조금 들었다가 내렸다. 흔든 건지 아닌지 애매한 높이였다.`(아주머니) | 할아버지 손 — **이번엔 애매하지 않게 다 보인다**(한 손이라서) |
| **마지막 대화** | EP138 `"…언니." / "응." / "안 가?"` | **마감 `언니.`와 짝** — 이번엔 수아가 **간다** |
| **돌아온 사람** | EP138 `문이 열렸다. / 할아버지였다. / 오십 날 만이었다.` | **문이 열린다 → 누구 → 수아의 셈** 리듬 — 이번엔 **안에서** 문을 본다 |
