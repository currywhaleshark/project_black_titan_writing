## 3. 첨삭 반영 (22건)

| 묶음 | 내용 |
| --- | --- |
| **수아 화계 3건** | `빠져요`·`이에요`·`예요` → **반말.** 단아에게 하는 말인데 **영진이 같이 있는 혼재 장면**이라 손이 존댓말로 갔다 — 등재된 유출 지점 |
| **영진 화계 3건** | `괜찮아?` → **`괜찮냐.`** / `아직 멀어` → `아직 멀다` / `하면 되지` → `하면 된다` |
| **★ 통증 어휘** | `아팠고`·`아프다` → **`느낌이 왔다`.** EP70 전까지 미해금 — **상시 가드 신설** |
| 영진 지원 범위 | `그건 나도 모르지` → **`뭔가 기능이 있을거다. 뭔지는 모르겠구나.`** 기술·경험 층위 안에서 한 걸음 더 |
| 안광 | **`항상 녹색 불은 들어와 있는데 그게 눈인지, 어딜 보고 있는지는 알기 어려웠다`** — 보고 있는데 어딜 보는지 모른다가 「잘 보이는데 못 피한다」와 겹친다 |
| 전장 | `저쪽도 걸어 나올` → **`걸어 들어올`** / 앵커 발사 전 **`창고 그늘에서 나와`** |
| **★ 결말부** | `내려와` → **`잘 했다`** + **드문 칭찬에 대한 의외** / 세면대·거울 → **`깨끗하게 이겼다. 그 사실이 기분 좋았다`** + 수아의 수건 |
| **★ 마지막** | **`마지막의 부서지는 감촉이 아직 남아 있었다. 하지만 손등에는 아무것도 없었다.`** |
| 격투 | `밀어 넣었다` → **`던져 넣었다`** / **`팔을 두어 바퀴 더 돌려 단단히 감아 버렸다`** |

**★ 사슬을 두어 바퀴 더 감는 한 줄이 물리를 완성했다.** 우연히 낀 게
아니라 **작정하고 감은** 것이 되고, 그래야 뒤의 「깔끔하게 감기지 않았다」와
**왼팔이 끝까지 묶여 있는 이유**가 선다.

## 4. 상시 가드 신설

**통증 어휘도 EP70까지 미해금.** `저림`·`흐림`·`마비`만이 아니라
**`아프다`·`아팠다` 계열도** 전투 회고에서 쓰지 않는다 —
**`느낌이 왔다`** 쪽으로. 통증이 이름을 얻는 것은 **EP70(공작갯가재전)**
부터이고, 그 전에 「아프다」를 써 버리면 그 화의 값이 깎인다.
