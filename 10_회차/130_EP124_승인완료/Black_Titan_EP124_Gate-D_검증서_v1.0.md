## 3. ★★★★★★ 스윕·설계 정정 5건

### 3-1. 「첫 단독전」이 아니다

> **[EP113 · 9/13]** **"흰 쪽입니다. 부표에서 종료까지 사십이 분입니다."**

**개요의 「42분」은 EP113 것이었다.** 루시는 이미 여러 번 혼자 나갔다.
**EP124는 「지면이 처음 안에서 보는 단독전」**이고, 오늘 값은 **31분**이다.

### 3-2. 민간 피해 4 → 0

**먼바다 통제 구역 밖이면 사람이 없다**(사용자 지적).
**★ 항목은 남기고 0을 적는다.** **4는 EP126으로 옮겼다** —
**같은 서식 · 같은 절차 · 다른 숫자**가 EP126을 아프게 만든다.

### 3-3. ★★★★★★ 수중전 봉인 (사용자 확정)

**센티널도 타이탄과 마찬가지로 수중 무장이 없다.**
→ **전장이 얕아야 한다**(허리높이 수심 · 원래 언덕이던 자리).
→ **가을 후반 어뢰 개발 사유**가 여기서 생긴다. **지면 0 · 예고 0.**

### 3-4. ★★★★★★ 적의 상성 (사용자 확정)

**개체는 근접 설계이고 센티널은 안 붙는다.** 그래서 오늘은 쉽다.
**★★★ 루시는 그것을 상성으로 안 읽고 자기 성능으로 읽는다.**

### 3-5. 함포 5인치 → 8인치

**55m 기체에 5인치면 사람이 공기총 든 크기**(31배 환산 = 4mm).
Mk.45 실물 포신이 7.9m다. **8인치로 상향**하고 G0로 설정집을 덮었다.
