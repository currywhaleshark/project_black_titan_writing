## 2. ★★★★★★ 이 회차 고유 위험 — 전투 서술이 사양 설명이 된다

**★★★★★★ 무장이 처음 열리는 회차라 필자가 설명하고 싶어진다.**

| 안 된다 | 된다 |
| --- | --- |
| `어깨의 함포는 5인치 2문으로` | **`포탑이 돌았다`** |
| `전완에 수납된 20밀리 근접요격체계가` | **`전완이 열렸다`** |
| `역장 동종성을 유지하기 위해 유선으로` | **`선이 살아 있는 동안만 듣는다`** |
| 위력·사거리·발수 나열 | **★ 쓰는 순서** |

**★★★★★ 판정 기준 하나:**
**「이 문장을 루시가 왜 지금 떠올리는가」에 답이 없으면 뺀다.**

**★★★ 사람은 싸우면서 자기 팔 길이를 떠올리지 않는다.**

### 2-1. ★★★★★★ 다만 동작은 뭉개지 않는다 (2026-08-24 사용자 지적)

**★★★★★ 초고가 이 규칙을 과적용해서 두루뭉술해졌다.**

| 뭉갠 것 | **고친 것** |
| --- | --- |
| `포탑이 돌았다` | **`포탑을 돌리고 포신을 내려 각을 맞추었다`** |
| `함포가 두 번 갔다` | **`양쪽 함포를 한 번씩, 총 2회 발포했다`** |
| `등이 열렸다` | **`등 뒤의 발사관에 사격제원을 입력했다`** |
| `나갔다` | **`압축 가스가 밀어 올리고, 잠시 후 엔진이 점화되었다`** |

**★★★★★★ 제원은 안 떠올리는데 절차는 손이 외우고 있다.**
**금지는 사양 나열이지 동작이 아니다.**

**★★ 서술 카드 §3-1B에 등재했다** — 다음 전투 회차에도 적용된다.

## 3. ★★★★★★ 문체검색 — 루시 시점 전투는 선례 0

### 3-1. 반례 — 단아 시점 전투 (STYLE_ONLY · ANTI)

> **[EP095]** 집게가 들어왔다. 위에서 아래로 내리찍는 동작이었고, 물이
> 갈라지면서 튀었다. **단아는 반보 물러났다가 옆으로 돌았다.**
>
> **[EP095]** 발목이었다. **감기는 게 아니라 걸리는 느낌이었는데, 걸린
> 다음에 감겼다.**

| 단아 전투 | **루시 전투** |
| --- | --- |
| **감각이 먼저** — 걸리는 느낌 | **★ 거리와 시각이 먼저** |
| 몸의 반응(물러나고 돈다) | **★ 절차의 순서** |
| **압력이 안으로 온다** | **★★ 오늘은 안 온다**(§4) |
| 판정 안 함 | **★ 판정한다** |

**★★★★ 단아는 당하면서 배우고, 루시는 처리하면서 안 배운다.**

### 3-2. ★★★ EP121·122에서 이어가는 것

**항목화 · 수치 우선 · 닫기.**
**★ 다만 전투라서 「닫히는 것」이 오늘은 잘 닫힌다.** 그 대비가 §5다.

### 3-3. ★★ 명준 문형 0
