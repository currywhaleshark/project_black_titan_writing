## 2. 회차 전체 리듬 — 정적 결착(단아 밀착)

```text
잔고: 움찔의 값 — 쌓이는 조류 — 남긴 한 번
→ 흘려보내기: 초조·불안·충동·소음 — 하나씩
→ 무늬: 밀어내는 건 가짜 — 그날의 당김은 진짜
→ 한 번: 벌어진 아가리 — 곧게 — 그리고 다시 멈춤
→ 걸린 무게: 조용한 물 — 둔했던 손끝 — 나란한 두 선
```

- **정적 전투 정서(2-5):** 긴장의 재료 = 탁한 시야·관망 진동·가짜
  접근·줄어드는 가동범위·움찔마다 붙는 파편. 타격 횟수 서술 금지.
- **결착 리듬(2-6):** `기다린다 → 한 번 밀어 넣는다 → 다시 멈춘다 →
  적의 돌진 관성이 스스로 내부를 파괴한다.`
- **균열 3 배치:** 잔고의 무서움(S1)·`차라리 와라`의 유혹(S2)·빼고
  싶다와의 싸움(S3 — 클라이맥스 균열).
- **승리 = 조용함(§6-④):** 팔에 걸린 무게·조용한 물·떨리는 숨.
  다섯 승 중 가장 조용한 승리(환호·선언·눈물 0).
- 씬 밴드: S1 1,100~1,400 / S2 1,000~1,300 / S3 1,500~1,800 /
  S4 900~1,200 / S5 500~800 (목표 5,800)

## 3. 장면별 문단 비트 잠금

### Scene 1 — 소모전 (1,100~1,400자) ※ 콜드 오픈

1. 시간 경과 0 — 가짜 접근의 반복(오른쪽·왼쪽·또 오른쪽 — 불규칙).
   움찔 = 파편 몇 개(잔고가 주는 셈의 물성).
2. 조류 침전 — 가만히 있어도 어깨·허리에 천천히(정지 ≠ 안전.
   **정지 = 오른손 한 번을 남기는 저축**의 재정의 1문장).
3. 반사와의 전쟁: 움찔은 의지가 아니라 반사 — 반사를 이기는 연습이
   실전에서 진행되는 구도.
4. 균열 비트 1: 잔고를 모르는 무서움(반 치가 몇 번 남았는지).

### Scene 2 — 흘려보내기 (1,000~1,300자) ※ A2·A3

1. **흘려보내는 목록(잠금 — 4종 순서):** ① 왼손의 초조(익숙한 손이
   있던 자리가 비어 있는 감각) ② 오른손의 불안(서툰 손으로 거대한
   아가리 안을 정확히 — `젓가락질도 서툰 손` 계보 회수 가능) ③
   부수고 싶은 충동(관구 하나라도 — 행동파의 본능) ④ 경보음·조종계
   진동. 각 항목 = 호흡 하나씩.
2. **관찰의 축적(잠금):** 가짜의 무늬 — 올 때마다 주변 잔해가
   **바깥으로 밀린다.** 세 번, 네 번, 같은 무늬 → `밀어내는 건
   가짜다.`
3. **EP30 회수(§6-① 잠금):** 그럼 진짜는 — 기억이 온다. 그날 여섯
   번째 관 앞에서, 물살이라고 오독하고 지나쳤던 **옆으로 당겨지던
   물.** 물리기 직전의 그 당김. `그건 물살이 아니었다.` — 오독이
   전조의 사전이 되는 회수(새 문장 — EP30 문면 재사용 0).
4. 균열 비트 2: `차라리 와라`가 목까지 오는 것(기다림의 유혹).

### Scene 3 — 한 번 (1,500~1,800자) ※ 결착 심장(2-6)

1. **전조(잠금):** 물이 당겨진다 — 관 안쪽으로 물과 가루가 빨려
   들어간다. 잔해가 밀리지 않고 **끌린다.** 몸이 먼저 안다(`이번
   건 다르다` — 머리 반 박자 뒤).
2. **개방·돌진(잠금):** 비뚤게 재생된 왼쪽 턱까지 양턱 완전 개방 —
   관구 밖으로 몸 전체를 쏘아 내듯. 시야 = 벌어진 아가리·밀려오는
   질량감(전신 상세 0 — 크다는 감각 위주).
3. **한 번(잠금):** 오른주먹, 곧게, 벌어진 턱 안으로 — **뻗은
   위치에서 정지.** 서툰 손의 한 번(조준의 불안이 손을 떠나는 반
   박자 — 예비동작·시험동작 0).
4. **관성(잠금):** 굳은 외피 = 지지대. 개체의 몸이 멈춘 주먹 위로
   더 깊이 미끄러져 들어옴 — 턱뿌리를 지나 안쪽으로. 둔한 파열의
   연쇄(공급낭·운동기관 = 물성 위주·명칭 최소).
5. **빼지 않는 시간(§6-② 잠금 — 클라이맥스):** 부서지는 동안 —
   `빼고 싶다`(본능)와 싸우는 인내. 균열 비트 3. 견인이 멎고, 새
   경화가 멎고, **무게가 오른팔에 걸린 채 멎는다.**
6. 결착 직후(§6-④): 환호 0 — 걸린 무게·조용해진 물·떨리는 숨.
   `이겼다`는 단어보다 `멎었다`의 사실.

### Scene 4 — 걸린 무게 (900~1,200자) ※ 귀환·C1·B3

1. **군 한 묶음 기록 톤 1문단(§6-⑤):** 첫 포획→자발 퇴각→광역
   개선→기능 정지 — 동일 개체 사건의 종결 기록. 후속 = 수몰지구
   안정·잔류 점액 제거 우선(추적·해부 계열 0). 마지막 줄 문법 재량.
2. 귀환 — 격납고(경화 외피 해체는 내일들의 일 — 규모 반 컷·EP33
   공사 계보 언급 이하).
3. **C1 창구(잠금 — 조건 전체):** 내려온 단아, 오른손을 쥐었다 펴고
   — **`할아버지. 오른손 검지랑 중지 끝이, 아까 수십 초쯤 둔했어요.
   지금은 괜찮아요.`**(담담한 신고 — `저림` 어휘는 이 국면 1회만
   허용). 속말 반 박자: 아프면 아프다고 — 말해 놓길 잘했다는 정도
   (약속 명시 대사 0). 영진 = 확대 없이 수신·기록(원인 추정 발화 0).
4. **B3(잠금):** 수아 — 손 감각 항목·점액 잔류 수치 받아 적기.
   질문 0(적는 손이 반 박자 느린 것까지만 — 수아 톤).

### Scene 5 — 훅: 두 개의 선 (500~800자) ※ 영진 단독

1. 밤 — 장부의 손 감각 기록 옆에 **시간을 적는 영진**(기록하는
   사람의 방식 — 해설 0).
2. **훅(개요 고정 문면):** 외해 화면 — 새 선 하나(EP29와 다른 방위)
   — 곧 반대편 수면에 두 번째 선 — **두 선은 서로 만나지 않은 채
   청해 쪽으로 나란히 움직인다.** 끝(해설·추정·아이들 인지 0).
