## 1. 전장 구조 — **최종 잠금**

전투 화는 여기가 먼저다. 구조가 서야 전술·긴장·소진 시계가 따라온다.

| # | 항목 | **잠금** |
| --- | --- | --- |
| ① | 수심 | **기체 무릎 아래.** 상반신 완전 노출. 물의 저항은 거의 없다 — **EP44~45의 허벅지 수심보다 얕다**(저항이 변명이 되지 않는 자리) |
| ② | 엄폐물 | **0.** 간척지는 평평하다. 수문 관리동·배수펌프장 등 **저층 구조물 몇 채**는 기체 허리 높이 — 엄폐가 아니라 **장애물**이고 밟으면 부서진다 |
| ②-B | **배수 암거** | 물 빼는 수로가 격자로 깔려 있다. 대부분 **열린 수로**, **일부 구간만 상판을 덮었다** — 덮인 데 아래는 **빈 통로**. 지상에서는 **수로가 갑자기 끊긴 것처럼** 보인다. **EP53 격파의 지형 — 이 화에서는 설명 0** |
| ③ | 시야·조명 | **밤.** 전조등 + 방조제 상단 작업등. **낮고 넓은 상대는 어두우면 바닥과 구분이 안 된다** → 윤곽이 아니라 **물이 밀리는 선**으로 읽는다 |
| ④ | 기동 제약 | **콘크리트 슬래브 + 물이끼.** 발이 **안 빠지는 대신 안 걸린다.** ※ EP47(갯벌 = 빠져서 못 피함)의 **역상** |
| ⑤ | 적 노출 | **완전 노출.** 숨지 않는다. 다만 밤이라 **보이는 것과 아는 것이 다르다** |
| ⑥ | 높이·질량 | 기체 52m / 개체 **높이 = 허리께, 폭 = 기체 두 배** / 수문 = 어깨 높이 / 방조제 = 가슴 높이. **구르기·몸 날리기·잽싼 회피 금지** |
| ⑦ | **소진 시계** | **밀린 거리.** 시작 지점에서 수문까지가 남은 자원이고, 그게 줄어드는 것이 이 화의 시계다. 체력·탄약이 아니라 **자리**가 준다 |

  **원리만** 승계한다. **구판의 문장·장면 전개·대사는 참조 0**
  (`source-firewall.md` — 구판은 STYLE_ONLY)

### ⚠ 가드 ①(적 — 표적이 바뀐다 · 기교 0)

**두 가지를 동시에 지켜야 한다.**

1. **도착 시에는 이쪽을 안 보고 있다.** 수문 쪽으로 가고 있다 —
   들어가려는 걸음이다
2. **막아서면 그 자리에서 돈다.** 몸 전체가 돌고, 도는 데 시간이
   걸리고, **그 시간이 다 보인다.** 여기서부터 목표가 바뀐다
3. 그 뒤의 문법 = **밀어붙이고, 자세가 무너지면 올라타 덮는다**
4. **기교 0.** 꼬리를 박거나 하는 잔재주를 주지 않는다.
   **크고 무거운 것이 크고 무거운 대로** 온다 — 그래서 더 안 풀린다

- **지면에서는 해석하지 않는다.** 방향이 바뀌는 것이 보일 뿐이고,
  단아의 감각은 **`방금까지 나를 보고 있지 않았는데`**까지다
- EP44 `저건 나를 부수려고 왔다`의 확장이되 **문장 재사용 0**

### ⚠ 가드 ②(2연타 — 밀리는 원인은 힘이 아니라 발)

| | 저것 | 이쪽 |
| --- | --- | --- |
| 자세 | **넓고 낮게 깔림** | **두 발로 좁고 높게** |
| 무게 | 바닥에 고르게 눌림 | 두 발에 집중 |
| 무게중심 | 낮다 | 높다 |

- **같은 힘이어도 좁게 딛는 쪽이 밀린다.** 이게 눈에 보여야 한다
- EP47 `이족 하중은 두 발에 박히고 다족은 뜬다`의 **다른 면**
  — 갯벌에서는 **박히는** 이유였고, 여기서는 **접지가 모자라는** 이유다
- **물리량 전달 필수(상시 가드):** 피해 0이어도 **밀림·자세 붕괴·
  조종석 진동.** `끄떡없다`·`소용없`·`무효` 계열 **금지**

### ⚠ 가드 ③(씨앗 — 심되 자각시키지 않는다)

**EP53 격파는 이 화에서 답이 되면 안 된다.**

| 심을 것 | 어떻게 |
| --- | --- |
| **빈 소리** | 버티다 발밑이 깨질 때 **그 자리 소리가 다르다** |
| 저층 구조물 파손 | 밟아서 하나 부순다 |
| 바닥 균열 | 힘을 줄 때 금이 간다 |
| **수아의 종이** | 출격 전에 받았고 **다 기억하지 못한다** |

- **단아는 성가셔할 뿐이다.** 부순 게 미안하고 발이 걸리적거릴 뿐,
  **소리에 이름을 붙이지 않는다.** 종이와 연결하지도 않는다
- ⚠ **여기서 자각시키면 EP53이 죽는다**
- 소리 읽기는 EP48 정본(`쇳소리 = 저쪽이 곤란하다는 신호`)의
  계보이되 **이번엔 적이 아니라 땅의 소리**다 — **문장 재사용 0**

### ⚠ 가드 ④(삼분법 배치 — 수아는 재료만 준다)

- **수아 = 출격 전, 종이 한 장.** 간척지 지형 — 얕은 데·단단한 데·
  **물 빠지는 자리.** **전투용이 아니라 실무 기록**이고
  **쓰임을 모른다.** 암거는 그중 한 줄일 뿐이다
- **전투 교신 0.** EP38 예외(`언니, 큰 건 눈이 없어. 꽃이 눈이야.`)는
  **단 한 번이어야 값이 남는다** — 두 번째 예외를 만들지 않는다
- **전술 제안 0.** 수아는 그리고, 조립은 단아가 한다(EP53)
- 단아는 그 종이를 **대충 본다** — EP53에서 `어? 이 줄` 하고 걸리게
  만드는 장치

### ⚠ 가드 ⑤(승계)

- **화계:** 단아→영진 **반말**(교신 포함) / 수아→단아 반말 /
  수아→영진 존댓말
- **시점 지칭:** 서술문에서 영진은 **`할아버지`**
- **영진 = 전투 교신 단독 창구**(물때·지형·경고). **해설 0·한 손**
- **전투 톤:** 침착함은 셈으로 벌어 낸 것. **균열 2~3회**(몸의
  반응·유치한 속말·참기의 실패)
- **전투 화 리듬:** 혼잣말·소리 묘사를 **초고 단계부터**.
  대화 **13% 이상**. 긴 서술 문단 분할
- **밤 = 형체 목격 0**(불빛·소리까지 — 방송 축 최고치는 EP55)

- **금지:** 앵커·로켓·추진·클로 / 반입구 / 센티널·루시 / 새 증상 /
  **격파**(EP53) / **전도·피깔림**(EP53·EP47 중복) / `개수`·`화` /
  `초여름`·`교복`·`인터넷` / EP44·EP47·EP48 문장 재사용

## 4. 장면별 잠금

### Scene 1 — 월요일

- **고정:** 학교 한 컷(짧게) / **앞마당의 고철이 그대로** 있다
  (조달 라인 진행 0) / 저녁에 신호가 **5번보다 더 안쪽으로** /
  통제 경보 절차(봄에 익힌 대로 — **재현 0**)
- **균열 ①:** 어제까지 고철을 실었는데 오늘 나간다는 **속도 차이**
- **금지:** 신호 해석·불안의 언어화 / 목요일 트럭 진행

### Scene 2 — 나가는 길

- **고정:** 출격 동선 정본(격납고 → 옛 노선 → 수몰역 → 수밀격벽 →
  **거기서 간척지까지 이동**) / **얕은 물의 감각**(몸이 거의 다
  나와 있다) / 영진 교신 개시 / **밤**
- **가드 ④ 집행:** **수아의 종이 한 장.** 실무 기록이고 쓰임을
  모른다. 단아는 대충 본다
- **금지:** 수아의 전술 제안 / 종이의 내용을 다 나열하기
  (**한 줄만 눈에 걸리게** 두고 나머지는 뭉갠다)

### Scene 3 — 돈다 ※ **가드 ① 집행**

- **고정:** **물이 밀리는 선이 먼저** 온다 → 전조등에 들어온다 →
  **낮고 넓다**(봄의 것들은 크기가 무서웠고 이건 **폭**이 무섭다) →
  **이쪽을 안 보고 수문 쪽으로 가고 있다** → **막아선다** →
  **몸 전체가 돈다**
- **§6-6 첫 노출:** 투구게형(높이 허리께·폭 기체 두 배·매끄러운
  곡면) / **간척지 전장**(평평함·저층 구조물·끊긴 수로)
- **균열 ②:** `방금까지 나를 보고 있지 않았는데`
- **금지:** 명명 / 목적 해설 / 지능 서술

### Scene 4 — 받는다 ※ **가드 ② 집행**

- **고정:** 정면으로 받는다 → **밀린다** → **원인은 발**(슬래브·
  물이끼) → **대비가 눈에 보인다**(깔린 쪽 대 선 쪽) →
  **찍어누르기의 첫 맛**(앞쪽을 들어 올려 얹으려 든다)
- **물리량:** 밀림·자세 붕괴·조종석 진동. 피해 표시는 0
- **소리·혼잣말 촘촘히**(여기서부터)
- **균열 ③:** 힘은 남았는데 자리가 없다는 당혹
- **금지:** **전도·피깔림**(EP53 몫) / 반격 성공 / 매끈한 전술 산문

### Scene 5 — 안 걸린다 ※ **가드 ③ 집행**

- **고정:** **EP48 흘리기 시도** → **각이 안 나온다**(폭이 두 배라
  비스듬히 받아도 다른 쪽이 여전히 앞) → 곡면이라 **잡을 데도 없다**
  (3연타 예고·감각까지만) → **발밑이 깨지고 빈 소리가 난다**
- **단아 = 성가셔할 뿐.** 자각 0·종이와 연결 0
- **금지:** 깨달음 / 소리에 이름 붙이기 / 암거 설명

### Scene 6 — 뒤

- **고정:** 밀린 거리 확인 → **뒤에 수문** → 영진의 경고 한 줄
  (짧게·해설 0)
- **끝:** **`두 걸음 밀렸다. 버틸 데가 없다`**(개요 고정 결)
- **금지:** 다음 수의 예고 / 결의 선언
