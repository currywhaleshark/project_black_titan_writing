## 1. 이 화의 형태

**전투 0 · 출격 0.** 기체가 안 나간다. 시리즈에서 몇 안 되는 화다.

대신 **도시가 일한다.** 사다리를 걸고, 두들기고, 재고, 서류를 쓴다. 그리고 **밝혀진다.**

그 순서가 이 화의 뼈대다 — **모른다 → 조사한다 → 알게 된다 → 성격이 바뀐다.**

## 2. 개체 노출 잠금

이 화에서 독자가 보는 것은 **바깥면과 한 번의 동작**까지다.

| 요소 | 노출 |
| --- | --- |
| 판 | **크고 납작하다.** 하나가 버스만 하고 **두께는 얇다.** 벽에 가장자리까지 밀착. 4~5개 |
| 표면 | 세로 결 + 가로 테. 물때로 아래쪽이 짙다 |
| 삭은 자리 | 우묵하고 색이 변했고 **긁으면 가루가 떨어진다** |
| **뚜껑** | 꼭대기가 **갈라지듯 벌어진다.** Scene 5까지 노출 0 |
| **갈퀴** | 뚜껑 안에서 나온다. **물을 한 번 훑고 들어간다.** 리듬이 있고 **소리가 없다** |
| 지면 지칭 | `붙은 것들`·`껍데기`·`판`·`뚜껑`·`갈퀴` |
| **금지** | 분류어(갑각류 등)·작가용 명칭·`당기면 감긴다`·먹는 원리 해설 |

### ⚠ 작가용 봉인(지면 0)

**조용한 굴착이다.** 요란하게 움직이면 방해받으므로 조용히 넘는 쪽을 본다. 이 화에서 저것은 **아직 타이탄을 안 만났다** — 그래서 사람은 건드려도 대응 수준에 그친다(붙잡을 뿐 쫓지 않는다).

- **금지 어휘:** 목적·학습·시험·의도
- **지면에 놓는 재료 셋:** ① 소리가 안 났다 ② 언제부터인지 모른다 ③ 하필 벽이다

## 3. 가드

### ⚠ ①(괴수라고 부르지 않는다 — 독자도 모른다)

- **판명 전까지 `괴수`라는 단어 지면 0.** 시청 사람들은 `부착물`·`구조 안전`·`삭은 깊이`라는 말을 쓴다
- **독자에게 먼저 알려 주지 않는다.** 서술이 아는 척하는 순간 조사 국면이 죽는다 — 단아가 아는 만큼만 쓴다
- 판명 이후에도 그 단어는 **한두 번**이면 족하다

### ⚠ ②(수소문에 걸린다 — 영진 지목 0)

- 시청은 **최근 일을 알 만한 사람을 찾아 동네를 훑는다.** 앞집·건너 가게에 들렀다가 여기도 들른다
- 질문은 짧고 형식적이다. 기록을 열어 보이고 없다고 하면 **한 줄 적고 다음 집으로 간다**
- **아무 일도 아닌 것처럼 지나간다.** 소문이 여기서 **절차**가 된다 — 일정이 있고 담당이 있고 서류가 있다
- **금지:** 영진을 대접하는 연출 / 저쪽이 사태를 알아보는 반응 / `관측이 놓쳤다`류 정리 문장 / **자책**(가드 ②-B)

### ⚠ ②-B(자책은 판명 뒤에만 — 신설 2026-08-14)

- **낮에는 뭐가 잡혔어야 하는지도 모른다.** 안 잡힌 걸 탓할 수 없다.
  Scene 2의 빈칸은 **아직 아무 의미가 없다** — 할아버지는 담담하고
  수아는 **`이상하네요`까지만** 한다
- **저녁, 판명 뒤에 같은 줄이 다시 나온다.** 그제서야 그건
  **살아 있는 것이 붙어 있던 동안의 기록**이 된다
- **같은 사실이 화 하나 안에서 두 번 다르게 읽히는 것**이 이 화의 구조다.
  장부 앞의 침묵도 수아의 자책도 **전부 Scene 6으로 모은다**
- **금지:** Scene 1~5의 자책·무거움 / Scene 6의 신파(두세 마디로 끊는다)

### ⚠ ③(단아는 못 한다 — `나갈 이유가 아직 없다`)

- 긴장은 `나가야 하는데 못 나간다`가 **아니다.** 저건 아직 괴수가 아니고, 어른들이 하고 있고, 단아는 학생이다
- **판명이 그 이유를 만든다.** 그 전까지 단아는 듣고 보기만 한다
- **금지:** 조바심의 언어화 / 어른들에 대한 판단 / 조사 개입

### ⚠ ④(판명은 사고로 일어난다)

- 누가 알아내는 게 **아니다.** 저것이 움직여서 알려진다
- 순서: 뚜껑이 열린다 → 갈퀴 → 난간 위가 조용해진다 → 한 박자 뒤 소리 → **사람이 딸려 들어간다**
- **금지:** 관찰의 승리 / 추리 / 누군가의 경고가 맞아떨어지는 구도

### ⚠ ⑤(사람은 죽지 않는다)

- 크게 다치되 살아 나온다. **들것이 나온다**까지
- 죽음은 이 시점 톤에서 다른 무게를 갖고 여론을 **비난**으로 튀게 한다(S10 보존)

### ⚠ ⑥(`당기면 더 감긴다` 0 — 독자에게도)

- 사람들이 몰려서 **가린다.** 단아가 아는 건 **오래 걸렸다**는 것뿐
- **금지:** 빼내는 과정 묘사 / 어른들이 나중에 그 얘기를 하는 장면 / 밧줄·지렛대 방향에 대한 설명
- EP56에서 단아가 **몸으로** 처음 안다

### ⚠ ⑦(EP56 몫 — 이 화에 0)

출격 · 전투 · 3연타 · **목격 3단(사람들이 형체를 본다)** · 여론 `불안` · 격파 · 밀물 속 작업

- 이 화에서 도시가 보는 것은 **저것**이지 기체가 아니다
- 여론은 **모른다는 불안**까지. 구경 → 판명 → **조용해짐**

### ⚠ ⑧(승계)

- **화계:** 단아→영진 반말 / 수아→영진 존댓말 / 시청 사람들→영진 존댓말(형식적)
- **시점 지칭:** 서술문에서 영진은 **`할아버지`**
- **영진의 지원 범위**(§2-B): 이 화에서는 **기록**과 **수아를 막는 두세 마디**로만 나온다. 한 손·답 없음
- **수아:** 전반부는 조위 기록 대조 **`이상하네요`까지**, 후반부(Scene 6)에서 **자기 탓 두세 마디**. 신파 금지·단독 작업 0
- **혜정:** 교실 국면. 수다는 하되 **어디·왜는 안 묻는다**
- **정비 척도:** 조사도 **공업 규모**로. 사다리·밧줄·안전모·지렛대·여럿이 매달림
- **균열 2~3회** / **새 증상 0** / **작가용 개체 명칭 0** / **분류어 0**
- **방재벽 = 기어올라야 하는 높이**(가슴 높이는 방조제)
- **금지:** 앵커·클로·로켓 / 반입구 / 센티널·우편물(EP57) / `개수`·`화`·`논`

## 5. 장면별 잠금

### Scene 1 — 세 갈래

- **고정:** 소문 세 갈래 / **아무도 괴수라고 안 한다** / 부표 기록 없음(어제·그제·그 전) / **항만 기록에 배는 잡혀 있다**
- **균열 ①:** 나가라고 하는 게 늘 저것이었는데 오늘은 안 울렸다
- **금지:** 정리 문장 / 불안의 언어화

### Scene 2 — 들렀다 가는 사람들 ※ 가드 ②·②-B 집행

- **고정:** 골목을 훑는다 → 여기도 들른다 → 짧은 질문 → 기록을 열어 보인다 → **한 줄 적고 다음 집** → 차 문 닫히는 소리
- **소문이 절차가 된다** — 일정·담당·서류. `부착물`·`구조 안전`·`삭은 깊이`
- 수아: 조위 기록 대조 → **`이상하네요`까지**
- **금지:** 영진을 대접하는 연출 / **자책·무거움** / 저쪽의 각성

### Scene 3 — 통제가 없다

- **고정:** 셔터가 안 내려왔다(봄에 두 번 내려왔다) / 교실에서 갈라지는 소문 / 혜정의 수다 / 창밖에 벽 쪽으로 가는 사람들
- **균열 ②:** **아무도 자기한테 뭘 시키지 않는 게 이상했다**
- **금지:** 조퇴·이탈 / 조바심 대사

### Scene 4 — 사람 손으로 ※ 첫 대면(구경 거리에서)

- **고정:** 구래동 큰길 난간 / 썰물에 드러난 밑동 / **판이 크다**(사람이 옆에 서면 사람이 작다) / 두들기고 재고 지렛대 넣고 **여럿이 매달려도 안 뜯긴다** / 삭은 자리는 **서류에 적히는 일**
- **§6-6 첫 노출:** 판의 생김새 + 삭은 자리의 물성 + **조사 현장의 공업 규모**
- **균열 ③:** 저건 자기가 하면 될 것 같은데 지금 나갈 수는 없다. **아무것도 못 하는 자리에 서 있는 게 처음이다**
- **금지:** 뚜껑·갈퀴 / 적의 반응 / 목적 추론

### Scene 5 — 열린다 ※ 가드 ④⑤⑥ 집행

- **고정:** 예고 없이 **뚜껑** → **갈퀴**(훑고 들어감·무음) → 난간의 정적 → 한 박자 뒤의 소리 → **딸려 들어감** → **사람들이 몰려 가린다** → **오래 걸린다** → 들것 → **다른 판들도 몇 번 더 열렸다 닫혔다**
- 마지막 한 줄의 성질: **아까부터 계속 그러고 있었던 것처럼**
- **금지:** 빼내는 과정 / 사망 / 단아의 개입 / 명명

### Scene 6 — 성격이 바뀐다 ※ 가드 ②-B 집행

- **고정:** 저녁 / **이제야 통제됐다** / 시청 일이 아니게 됨 → 넘길 데로 넘기는데 **시간이 걸린다** / **밀물**
- **★ 아침의 빈칸이 다시 나온다.** 같은 줄인데 이제 **살아 있는 것이 붙어 있던 동안의 기록**이다
- 할아버지가 장부를 펴 놓고 **아무것도 안 쓴다** / **수아가 자기 표를 다시 펴고** 자기 탓 → 두세 마디로 끊김
- **끝:** **`언제부터 붙어 있었는지 아무도 몰랐다`** 결
- **금지:** 출격 예고 / 결의 / 해석
