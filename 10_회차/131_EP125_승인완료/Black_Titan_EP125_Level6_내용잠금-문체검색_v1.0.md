## 3. ★★★★★★ 문체검색 — 반례가 둘이다

### 3-1. ★★★★★★ 단아식 (EP119 전례 — 실패한 적이 있다)

**EP119 초고에서 수아 대사가 단아식으로 나와 전면 재작성했다.**

| 단아식(금지) | **수아** |
| --- | --- |
| `뭘요` · `어떻게 달라요` · `그게 뭔데요` | **★★★ 되묻지 않는다** |
| 반문형 불평 | 한 박자 침묵 후 결론만 |
| 감탄사 선행 | 관찰 진술 |
| **몸이 먼저** | **★ 눈이 먼저** |

**★★★★★ 판정 기준:** 수아의 대사에 **물음표가 붙으면 한 번 의심한다.**
**되묻는 것과 진짜 묻는 것은 다르다.** 진짜 묻는 것은 **답이 필요할 때만.**

### 3-2. ★★★★ 루시식 (직전 회차)

**EP124가 루시 시점이었다.**

| 루시 | **수아** |
| --- | --- |
| **항목화** · 목록 · 닫기 | **★ 항목 0.** 세지만 항목이 아니다 |
| 수치가 형용사보다 먼저 | **★ 관찰이 먼저** |
| **판정한다** | **★★ 판정을 미룬다** |
| 감정에 이름이 없다 | **★ 이름은 있는데 안 말한다** |

**★★★★★★ 둘 다 세는 인물인데 세는 이유가 다르다.**

| | 루시 | **수아** |
| --- | --- | --- |
| 왜 세나 | **처리하려고** | **★ 남기려고** |
| 세고 나면 | **닫는다** | **★★ 다음 것을 정한다** |

**★★★ 지면에서 비교하지 않는다.** 형식만 나란히 선다.

### 3-3. ★★★ 수아 정본 문형 (STYLE_ONLY)

> **[EP119]** 이 선생님은 모르는 건 모른다고 한다. **그게 좋을 때도 있고
> 아닐 때도 있는데 오늘은 잘 모르겠다.**
>
> **[EP119]** 수아는 그 생각을 오래 안 했다. **오래 하면 다른 게 따라오는
> 걸 알았다.**

**★★★★ 관찰 → 판단 보류 → 그만두기.** 이게 이 인물의 삼단이다.
