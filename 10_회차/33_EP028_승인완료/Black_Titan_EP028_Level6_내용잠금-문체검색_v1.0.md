## 2. 회차 전체 리듬 — 수아 밀착 문체(화자 교대)

```text
교실: 남의 칸부터 가는 손 — 네 것부터 끝냈어? — 비어 있던 내 칸
→ 보면대: 쉼표를 세는 아이 — 나란히 맞는 진입
→ 정비실: 베껴 적다 걸리는 반복 — 화살표 하나 — 바뀐 순서
→ 위임: 조건 셋이 달린 승낙 — 글씨가 작아졌다 — 부탁
→ 훅: 확인자 칸의 작은 이름 — 옆에 그어지는 한 줄
```

- **화자 교대 문체(§6-① 집행):** 세상을 열과 칸으로 읽는 눈 —
  단아의 문체(몸 먼저·짧은 가속)와 구분: 수아의 문장은 **순서·간격·
  대칭**을 본다. 관찰이 먼저 오고 행동이 조용히 따라온다. 속말은
  적고, 본 것의 배열이 속말을 대신한다.
- 언니·할아버지 호칭: `언니`·`할아버지`(수아 시점). 기체 = `타이탄`
  가족 호칭 상한 1~2회(정비실 국면만).
- 씬 밴드: S1 1,100~1,400 / S2 900~1,200 / S3 1,400~1,700 /
  S4 1,000~1,300 / S5 500~800 (목표 5,800)
- 수아 톤 가드 = 이 화의 본체: 주도성조차 나서기가 아니라 **자기
  칸을 채우기**. 아이다운 균열 2~3(수아 버전 — 칭찬에 간지러운 귀,
  연필을 고쳐 쥐는 손, 작은 글씨).

## 3. 장면별 문단 비트 잠금

### Scene 1 — 네 것부터 (1,100~1,400자) ※ 3학년 교실·초출 3인

1. 아침 교실 — 수아의 눈에 들어오는 것들의 순서(비뚤어진 역할표,
   빠진 준비물 — **남의 칸부터 보이는 눈**). 손이 먼저 감(수아식
   몸 먼저 = 남을 위한 손).
2. **유림·재호 초출(§6-6):** 배유림 — 역할표 담당(글씨가 큰 아이
   계열 생활 특징 1개). 문재호 — 준비물을 자주 잊는 아이(특징 1개).
   G0-005 외형 반영 최소(과장 0).
3. **임유정 초출(§6-6 잠금 문면):** 칭찬으로 일을 얹지 않는 담임 —
   **`수아야, 네 것부터 끝냈어?`** 유림·재호에게 각자 몫 돌려주기
   (꾸중 아닌 재배분 — 목소리 온도 평이).
4. **자기 칸의 발견(잠금):** 수아의 칸이 비어 있었다는 것 —
   부끄러움이 아니라 **낯섦**(생각해 본 적 없는 방향). 자기 칸을
   채우는 손의 반 박자.

### Scene 2 — 쉼표와 진입 (900~1,200자) ※ 방과후 바이올린

1. **하랑 재등장(앵커 필수):** 방과후 친구·다른 반·같은 보면대
   (EP13~17 계보 1어구). 비밀 무관 생활 한정.
2. **순서 읽기(잠금):** 같은 악보 — 하랑이 반 박자 빨리 들어가면
   수아가 쉼표를 짚어 주는 결(가르침 아닌 나란히 맞추기). 쉼표를
   세는 일이 소리만큼 중요하다는 수아의 감각 1비트.
3. 씬 기능 상한: `꼼꼼한 아이` 표면 유지 — 재능 특별시·적합성 단서 0.
   하랑의 발화는 밝은 생활어 1~2(비밀 인접 0).

### Scene 3 — 반복을 찾다 (1,400~1,700자) ※ 정비실 — 심장

1. 저녁 — 방폭문 너머 정비실(LOC-02 결: 국부 조명·녹과 기름 냄새·
   노란 안전선 밖의 원경 기체). 현재 역할의 물성(걸레·물품 상자)
   반 컷 → 영진의 전사 부탁(베껴 적기 — 기존 역할의 연장).
2. **발견(잠금):** 옮겨 적다 걸리는 반복 — 냉각계 확인이 매번 외장
   밀봉 **뒤**, 그때마다 재검 표시. **매번**이라는 것을 확인하러
   앞 장들을 거슬러 넘기는 손(그리는 셈의 물성 — 페이지를 세는).
3. **제안 = 표(§6-③ 잠금):** 말 대신 빈 종이에 순서를 다시 그림 —
   화살표 하나. 내밀며 한 문장: **`냉각 확인을 밀봉 전으로 옮기면
   두 번 열지 않아도 된다.`**(요체 — `~돼요` 계열 변환 허용, 문면
   기능 유지. 진단·전투법 0.)
4. **영진의 반응(잠금):** 반사 — 위험하다는 말부터(`여기 일은 네가—`
   계열 반 문장). 그러나 표를 본 손이 멈추고 — **다음 점검에서
   순서를 바꿔 본다.** 누락 표시가 줄어드는 것의 확인(맞은 수정은
   지워지지 않는다 — 해설 0, 결과만).
5. **FS-003 1비트(잠금 — §6-⑤):** 기록 너머, 기체 쪽 어딘가 덜
   닦인 얼룩이 수아의 눈에 한 번 걸림 — **관찰 1문장, 해석·명명·
   재언급 0.** (수아의 눈이라 걸리는 것 자체가 기능 — 공책 기록
   여부도 서술 0.)

### Scene 4 — 위임과 합의 (1,000~1,300자)

1. **위임(잠금):** 영진 — 귀환 뒤 수치 전사·누락 확인을 수아 몫으로.
   **조건 셋 명시: 혼자서는 안 한다·전원은 안 올린다·조종석에는 안
   간다**(위험 말부터 하는 사람의 승낙 문법 — 조건이 곧 승낙.
   수아의 수신 = 고개 끄덕임+조건을 그대로 되받아 적는 손).
2. **단아의 합의(잠금):** 새 점검표를 본 언니 — `글씨가 작아졌다`
   놀림 → 누락 항목 훑기 → **`다음에 돌아오면, 네가 먼저 봐 줘`**
   계열 부탁(내려주기 구도 0 — 부탁의 문법. 단아 시점이 아니라
   수아의 눈에 비친 언니로).
3. 수아의 수신 — 놀람 서술 최소(표를 고쳐 쥐는 손 계보 — EP25 문장
   재사용 0).

### Scene 5 — 훅: 확인자 (500~800자)

1. 새 점검표 — 맨 아래 비어 있던 칸: **확인자.** 지금까지 누구의
   이름도 없던 칸(칸의 내력 1문장 상한).
2. **훅(개요 고정):** 수아가 **작은 글씨로** 자기 이름을 쓴다(칸
   구석 — 크게 쓰지 않는 아이. 이름 석 자의 물성). 영진은 보고,
   지우지 않는다. 대신 옆에 한 줄 — **`전원 차단 후 확인.`**
3. **컷:** 두 필적이 나란한 종이(해설 0 — 작은 이름과 조건 한 줄이
   같은 칸에 사는 그림). 끝.
