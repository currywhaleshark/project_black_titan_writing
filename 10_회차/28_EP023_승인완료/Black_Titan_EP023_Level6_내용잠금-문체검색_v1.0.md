## 2. 회차 전체 리듬

```text
다시 감긴 허리 — 잡으려던 손이 멈춘다: 떼지 않는다
→ 교각의 숲: 각을 바꾼다 — 성실한 교대가 그물을 짠다
→ 교차: 선과 선이 걸린다 — 처음으로 저쪽이 움직여지지 않는다
→ 파고들기: 탈출의 길이 이번엔 도달의 길 — 기부를 잡는다
→ 닻을 놓는 습관: 잡히자, 교각을 놓고 잡으러 온다 — 몸이 풀린 반 박자
→ 사면: 감기기 전에 뒤집는다 — 뒤집힌 채로도 감으러 오는 팔 — 멎었다
→ 이름: 싸우러 온 게 아니었다 — 다쳤다는 애는 — 이성호
```

- 문체 축은 **기하**다 — 조종·유인의 심리 대신 각도·순서·선의
  서술로만 덫이 짜인다. 개체는 끝까지 성실하게(의도 서술 0).
- 시점: S1~S4 단아 밀착(시야 회복 상태 — 시각 서술 재개) / S2 군
  반 컷 / S5 조종석 → 귀환(정비실 또는 집 — 휴대폰).
- 씬 밴드: S1 900~1,200 / S2 1,300~1,600 / S3 1,300~1,600 /
  S4 1,200~1,500 / S5 700~1,000 (목표 5,800)
- 리듬: S1 정지→선택의 단문 → S2 항행의 반복 리듬(교대 1회 = 1비트)
  → S3 잠김의 정적 1박 → S4 최단문 수렴(`멎었다`) → S5 문구 정지.

## 3. 장면별 문단 비트 잠금

### Scene 1 — 떼지 않는다 (900~1,200자)

1. 재포박 직후 연속 — 허리의 감김. **반사적으로 잡으려던 손이
   멈춘다(잠금):** 떼 봤자 옮겨 감긴다는 것은 이미 배운 것. 대신
   깨달음 — 감김은 **연결된 줄**이다. 저쪽이 힘을 옮기는 것이 이쪽
   허리에 먼저 읽힌다(EP20 몸넷땅넷의 역이용 — 해설 1문장 상한).
2. 무전 복구 — 미뤄 둔 대답부터. `늦었다` 계열 짧은 사과 없는 복귀
   (영진도 묻지 않음). 무게 처리 1비트: 치우지 않고 미뤄 둔다
   (죄책감 장문 0).
3. **목적지(잠금):** 띠의 목록 — 비어 있는 곳, 교각군. 끌리는 방향과
   교각군 사이의 **비스듬한 길** 선택. 씬 마감: 첫 진행각 변경 —
   `길은 저쪽이 정했다. 각도는 이쪽이 정한다` 계열 1줄 상한.

### Scene 2 — 교각의 숲 (1,300~1,600자)

1. 교각군 진입 — 상판 걷힌 기둥의 열(EP22 기억의 실물화 — 버스로
   지나던 시절 1비트 허용). 기둥 사이의 물, 항행의 물성.
2. **유인의 기하(잠금):** 단아는 팔에 손대지 않는다. 각만 바꾼다.
   개체의 습관(앞 팔 새 지지점 → 뒤 팔 갈아붙기)은 그대로인데,
   지지점이 **매번 다른 교각**이 되도록 — 교대 1회 = 서술 1비트의
   반복 리듬(세 번 이상 쌓기). 그물이 짜이는 것을 독자가 기하로
   먼저 보게(단아의 계획 해설 0 — 각도 선택의 서술만).
3. **군 반 컷(B2 잠금):** 붕괴 반경 유지·구조대 대기(승리 확인 뒤).
   고명준 관찰 기록: `저건 빈 데를 골라서 가고 있다` 계열 1행 +
   기록 지시(신원 추적 작전 0). 직책 앵커 1회.
4. 씬 마감(잠금): 세 번째 교대 어디쯤 — **선과 선이 처음으로
   스친다.** 스치는 감각이 허리의 줄로 읽힌다.

### Scene 3 — 교차 (1,300~1,600자)

1. **잠김(잠금):** 서로 다른 교각에 걸린 견인선들이 당길수록 서로를
   묶는다. 몸통의 진행 방향이 잠긴다 — **처음으로 저쪽이 움직여지지
   않는 차례**(입장 역전 — 해설 0, `당기는 힘이 당기는 힘을 잡고
   있었다` 계열 물성 1줄).
2. **파고들기(잠금):** 방향이 잠긴 사이 당김을 따라 안쪽으로 —
   이번엔 탈출이 아니라 도달(EP22 문장 재사용 0, 대구 1비트 허용).
   사면의 위치는 파고들기 전에 확인해 둔다(방향 결정 선행).
   **기부 모아 잡기:** 여덟이 모이는 곳을 한 손아귀의 일로(§5 —
   무게 대 무게).
3. **닻을 놓는 습관(잠금 — 사용자 물리 정정 반영):** 기부가 잡히자
   개체의 대응은 싸움이 아니라 잡기 — **교각을 잡고 있던 견인
   팔들을 스스로 놓고, 단아를 다시 감으러 온다.** 놓는 소리들이
   연달아 도착(EP22 소리 문법의 마지막 회수 — 문장 0). 이로써
   몸통은 어디에도 붙어 있지 않다.
4. 씬 마감(잠금): 감으러 오는 팔들이 자리를 잡기 전 — **반 박자.**
   감기기 전에 뒤집어야 한다(최단문 수렴 개시).

### Scene 4 — 사면 (1,200~1,500자) ※ 종결 씬

1. **뒤집기(잠금):** 어디에도 붙어 있지 않은 몸통 — 기부를 잡은 채
   체중을 실어, 감기러 오는 팔들보다 먼저 마른 사면 위로 넘긴다.
   물을 잃은 것의 무게와 소리(젖은 것이 마른 콘크리트에서 내는
   소리 — G0-010 개체음).
2. **마지막 관찰(잠금 — FS-004 특별 경계):** 뒤집힌 채로도, 풀린
   팔이 허리와 무릎을 **다시 감으러 온다.** 행동 서술만 — 부정형
   문장(`해치지 않았다`·`찌르지 않았다`) 금지. 잡으려는 동작의
   반복만 쌓아 독자가 스스로 읽게.
3. **기능 정지(잠금·§6-②):** 중앙 운동기관 — 몸통 아래쪽, 움직임이
   모이는 곳. 맨손과 체중으로 누른다. **초록 점 소등: 손바닥
   아래에서부터 바깥으로**(EP16 역순 소등 문장 0). 종결 1어 종지:
   `멎었다.`
4. 정적 — 환호 0. **감김의 역순 해제(잠금):** 허리, 무릎, 팔꿈치 —
   EP20부터 쌓인 감김 목록이 하나씩 풀려 내리는 감각(짧게, 목록
   재사용 0). 사체·용해 서술 0 — 멎은 것에서 컷.

### Scene 5 — 이름 (700~1,000자)

1. **추정 도달(잠금 문면·§6-③):** 영진 반 문장 — `……죽이려는
   동작이 한 번도 없었다.` → 단아 완성 — **`싸우러 온 게 아니라,
   나를 끌고 가려 했다.`** 왜·어디로는 묻는 문장으로만 남김(답 0).
2. **첫 물음(잠금):** 승리 보고보다 먼저 — `학교에서 다쳤다는 애는.`
   영진의 침묵(모른다 — 반 박자). 무전이 조용한 채 씬 전환.
3. **훅(개요 고정·§6-④):** 귀환 뒤 — 휴대폰의 학교 단체연락망.
   늦게 올라와 있는 문장, 문면 그대로 1회: **`이성호 학생 보호자
   인계 완료.`** 단아의 반응 = 읽는 동작까지(이름을 두 번 읽는
   것 허용 — 해설·죄책감 문장 0). 끝.
