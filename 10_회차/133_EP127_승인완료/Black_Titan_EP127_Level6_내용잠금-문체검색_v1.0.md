## 2. ★★★★★★ 카드 §2-3 실독 — 이 회차의 심장

> **[narration-lucy-pov §2-3]** 루시는 자기 감정에 이름을 못 붙인다.
> **그러므로 서술자도 붙이면 안 된다.**

| 금지 | 카드가 준 대체 |
| --- | --- |
| 부러웠다 | **`왜 저쪽은`** — 질문으로만 남는다 |
| 외로웠다 | `방이 조용했다. 조용한 것이 익숙하지 않았다` |
| 화가 났다 | **`반응이 늦었다. 0.4초.`** |
| 서운했다 | `집중이 떨어졌다` |

### 2-1. ★★★★★★ 그런데 이 회차는 한 단계 더 간다

**★★★ 카드의 대체어는 전부 「성능 저하」다.** 반응 지연 · 집중 저하 · 오류.

**★★★★★★ 오늘은 그것도 안 나온다.**
반응은 정상이고 오류도 없고 절차는 다 지켜졌다.

| 층 | EP126 | **EP127** |
| --- | --- | --- |
| 감정의 이름 | **0** | **0** |
| 성능 저하 기록 | **★ `왼팔 반응이 0.4초 늦다`** | **★★★★★ 없다** |
| 남는 것 | 이름 없는 하나 | **★★★ 이름 없는 것이 둘** |

**★★★★★ 유일한 흔적은 「세 번 잰 것」이다.** 그리고 **기록에 안 적는다.**
**★★★ 서술자도 그것을 흔적이라고 안 부른다.** 세 번 쟀고 세 번째에 맞았다까지다.

## 3. ★★★★★★ 문체검색 — 최대 위험이 EP126보다 크다

### 3-1. ★★★★★★ 같은 장소를 다시 본다

**EP126과 EP127은 같은 골목, 같은 집 넷이다.**
**축자 중복 조건이 EP126 때보다 나쁘다.**

**★★★★★ 그런데 보는 각도가 다르다. 그것으로 문장을 가른다.**

| | **EP126** | **EP127** |
| --- | --- | --- |
| 상태 | **부수는 중** | **★★★ 부서진 뒤** |
| 자리 | 위에서 · 기체 안 | **★★ 옆에서 · 걸어서** |
| 대상 | **목표를 가리는 것** | **★★★★ 잔해** |
| 사람 | **없다** | **★★★★★★ 있다** |
| 시간 | 초 단위 | **★★ 하루 뒤** |

**★★★★★★ 「사람이 있다」가 모든 문장을 바꾼다.**
어제는 집이 좌표였고 오늘은 집이 **누가 앉아 있는 자리**다.

### 3-1B. ★★★★★ EP126에서 쓴 것 — 다시 쓰지 않는다

| EP126 문장 | EP127에서 |
| --- | --- |
| `옥상에 물통이 있었고 물통 옆에 접은 파라솔이 세워져 있었다` | **★★ 물통은 회수하되 문장을 바꾼다** — 골목 반대편에 그대로 있다 |
| `마당에 빨랫줄이 걸려 있었으며 줄에 아무것도 안 걸려 있었다` | **★★★ 한쪽만 남아 있다** |
| `벽 두 면이 날아갔고 뒤의 것은 지붕이 통째로 벗겨졌다` | **★★ 벗겨진 자리를 아래에서 본다** |
| `집이 하나 앉았다` | **★★★★ 「앉았다」를 다시 쓰지 않는다** |

**★★★★★★ `check_continuity.py` [4]가 잡는다.** 18자 이상 일치는 전부 재작성.
