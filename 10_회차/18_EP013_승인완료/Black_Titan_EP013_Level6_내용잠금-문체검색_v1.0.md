## 2. 회차 전체 리듬

```text
학교: 시각을 확인하는 손 → 혜정이 따로 묶는 준비물
→ 수리점: 규격이 안 맞는 상자들 → 세 무더기 분류
→ 저녁: 레일 아래 훈련 → 수첩의 세 칸
→ 방과후 교실: 마지막 음 — 세 번의 점멸
```

- 이 화의 문체 축은 **반복의 리듬**이다. 하루가 아니라 4월 첫 1~2주의
  여러 날을 압축하되, 같은 동선(학교→수리점→훈련)이 회차 안에서 두 번
  이상 겹쳐 보이게 해 `시간표`가 구조로 전달되게 한다.
- 전투 0, 위협 0 — 마지막 점멸 3회가 유일한 이상. 원인 추정 서술 0.
- 씬 밴드: S1 1,400~1,700 / S2 1,400~1,700 / S3 1,100~1,400 /
  S4 800~1,100 (목표 5,500)
- 시점: S1~S3 단아 / **S4 수아**(§6-8 호칭 전환 — 이 화 유일의 이동)

## 3. 장면별 문단 비트 잠금

### Scene 1 — 학교: 시간표의 첫 칸 (1,400~1,700자)

1. 4월 교실 — 체육대회 준비 배정 주간. 김주호의 담백한 배정 진행
   1~2문장(선택지 제시형 — 훈계·심문 0). 학급 파생값은 26명 기준.
2. 단아는 역할을 맡으면서 시각을 계속 확인한다 — 벽시계·손목을 보는
   동작 반복(해설 0). 방과후 연습에 남을 수 없는 날이 생긴다.
3. **B1(잠금):** 단아의 `집안일 때문에 먼저 가야 해` 한 줄. 혜정은
   이유를 캐묻지 않는다 — **직접 질문 0**(봄 예산 소진). 대신 단아 몫의
   준비물을 따로 묶어 자기 가방 옆에 둔다. 서운함은 동작의 온도로만
   (묶는 손의 매듭·시선 처리 — 대사 상한 1~2, 추궁 어휘 0).
4. **B4(잠금):** 성호가 응원 구호에 검은 거인을 넣자고 우긴다 —
   구호 시안 낭독 콩트 1비트(프로필 신화 연동 허용, 새 설정 발명 0).
   단아는 반박할 여유가 없다 — 시계를 보느라 놀림 타이밍을 놓치는
   비대칭(성호는 그것을 승리로 오독해도 좋다, 1문장 상한).
5. 예진 배경 0~1비트(완충 기능만).

### Scene 2 — 수리점: 되는 대로의 실물 (1,400~1,700자)

1. 하교 뒤 수리점 앞 — **기태 조달 1차 물량 도착(잠금: 몸 미등장).**
   상자 몇 개와 전표 한 장. 전표의 필체·물기 얼룩 같은 물성으로 기태를
   ○ 언급 처리(§6-8 단아 시점 — `기태 아저씨`).
2. 분류 노동: 쓸 수 있는 것 / 갈아야 맞는 것 / 못 쓰는 것 — 세 무더기.
   규격이 맞지 않는 산업부품의 물성(구멍 간격이 다른 판재, 한 치수 큰
   부속 계열 — 무장 연상 어휘 0). 외부에서 구한 부품도 바로 못 쓴다는
   사실을 단아가 손으로 배운다.
3. 영진의 지휘는 짧은 해라체 — 설명 대신 손. 위장 관련 신규 발화 0
   (C2 rest: 기존 `시제기 보수용` 설명을 반복하지 않는다 — 이미 성립한
   규칙은 침묵으로 굴러간다).
4. **B3 전반부(잠금):** 수아가 조용히 분류를 돕는다(발화 0~1).
   나가는 길 또는 돕는 중 — **격납고 쪽 조종석을 한 번 오래 바라본다.**
   해설 0, 시선의 길이만(1~2문장). 단아·영진이 그 시선을 알아차리는
   서술 0(독자 전용).

### Scene 3 — 저녁: 세 번째 칸 (1,100~1,400자)

1. 짧은 출격훈련 — 격납고→옛 노선→수몰역 라인 왕복 + 기본 기동 점검.
   **외부 수역 진출 0(사용자 확정 2026-08-04)** — 군 관측 기록을 만들지
   않는다. 루틴의 물성: 레일 대차, 수밀격벽 소리, 조명이 차례로 켜지는
   노선.
2. §5 거대중량 준수 — 속도·도약·민첩 0. 조종석 밀착 시점이므로 소리
   지연 0, 관성·감쇠 감각으로 무게 처리. 기본동작은 근전도·운동의도
   (조종간 직접조작 서술 0).
3. 왼손 위주 기본동작 점검 — EP11 `왼손으로 살기` 연속성(문장 재사용 0).
   이상 징후 0, 탐색·괴수 관련 서술 0.
4. 귀가 — 단아가 하루를 셈한다: 학교 칸, 수리점 칸, 훈련 칸.
   **수첩 1컷(브리프 §6-①):** 세 칸을 직접 적는 손 — 이중생활이 글자로
   남는 첫 순간. 자신감의 잠금 문면 계열: `시간표만 지키면 다 지킬 수
   있다`(속말 1회 상한 — 이 화의 유일한 속말. 소아크 실패의 전제이므로
   확신형으로 닫는다).

### Scene 4 — 방과후 교실: 마지막 음 (800~1,100자) ※ 수아 시점

1. 다른 날 방과후 — 3학년 바이올린 방과후수업. §6-8 수아 시점 호칭:
   `언니`(언급 시)·`선생님`. 내부 고유명 0. 방과후 강사는 무명 기능
   처리(신규 인물 카드 생성 0 — `방과후 선생님`까지만).
2. **이하랑 초출(§6-6 잠금):** 행동 앵커식 — G0-005 앵커 사용:
   단정한 천 머리띠 / 수아보다 반 걸음 큰 보폭 / 악기 케이스 손잡이를
   고쳐 잡는 손 중 2개 이내. 이름은 호명 또는 수아의 인지로 자연 노출.
   **하랑은 수아와 다른 반(사용자 확정 2026-08-04)** — 접점은 바이올린
   방과후수업뿐. 소개 어구는 `다른 반` 계열로(같은 반 오독 방지).
3. 가까워지는 결(브리프 §6-③): **같이 틀리는 아이** — 같은 마디에서
   같이 틀리고, 같이 다시 하는 작은 상호작용. 하랑 발화 1~2(밝고 평범한
   9세 어휘 — 조숙한 관찰·의미심장 0). 수아의 반응은 한 박자 침묵 뒤
   짧은 문장(말투카드). 전투·비밀·언니 화제 0.
4. **훅(개요 고정 문면):** 마지막 음이 이어지는 동안 — 교실 조명과
   창밖 연구단지 항공등이 **같은 간격으로 세 번** 꺼졌다 켜진다.
   아이들의 반응은 짧은 웅성거림까지. 원인 추정·불안 해설·괴수 연상 0.
   수아의 반응도 관찰 1문장 상한(분석 0 — 조숙 금지). 여기서 끝.
