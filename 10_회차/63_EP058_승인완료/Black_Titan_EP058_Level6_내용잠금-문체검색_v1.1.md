## 1. 이 화의 형태

**전투 0.** 물건이 나오는데 **이름이 없고**, 시험해 보는데 **안 맞는다.**

그리고 **왜 안 맞는지를 아무도 말로 만들지 않는다.** 셋 다 어렴풋이 아는 채로 하루가 끝난다. 그 답은 EP60에서 **문장 하나**로 온다.

## 2. 물건 잠금 (BT-01A v0.2)

## 3. 가드

### ⚠ ①(명명 게이트 — `닻`은 되고 `앵커`는 안 된다)

- **허용:** `그것`·`쇳덩이`·**`닻`**·`사슬`·`통`·`감개`
- **금지:** `앵커`(EP61 가족 내부 명명)·`클로`·`로켓`·`추진`·`사출기`
- **`닻`은 생김새를 부르는 말이고 이름이 아니다.** 안 부르면 오히려 부자연스럽다
- **금지:** 별명 붙이기 / 고정 지칭이 굳는 반복 / 이름을 묻는 대사

### ⚠ ②(결과만 놓는다)

- 학교 갔다 오니 **놓여 있다.** 만드는 과정·설계·재료 **전부 생략**
- EP57에서 철문 너머를 안 보여 준 것과 같은 문법이다
- 영진의 말은 **절차뿐** — 어디에 붙이고, 어떻게 걸고, 뭘 조심하는지
- **금지:** 주말 작업 회상 / 도면 / 부품 내력 / 반입구·크레인의 지하 용도

### ⚠ ③(안 맞는 이유를 지면에서 정리하지 않는다)

- `조준이 아니라 감각의 문제`는 **브리프의 말이지 지면의 말이 아니다**
- 셋 다 어렴풋이 아는 채로 **아무도 문장으로 만들지 않는다**
- **금지:** 원인 진단 대사 / `그러니까 이건 ~때문이야` 류 / 다음 수 제안
- 그래야 EP60의 **`왼팔이 길어진다고 생각해`**가 산다

### ⚠ ④(수아의 그림은 틀리지 않았다)

- 궤도는 **정확히** 그려진다. **두 마디로 꺾인 그림**(떨어지는 선 + 살아나는 선)
- **계산으로 되는 문제가 아니어서** 안 된다 — 불이 붙는 시점과 그때의 각도가 **손에 달려 있고 그건 종이에 못 그린다**
- 수아가 먼저 알아채되 **결론은 안 낸다**: `제 그림이 틀린 게 아니라…`에서 끊는다
- **금지:** 결정적 한마디 / 수아가 답을 아는 연출 / 자책

### ⚠ ⑤(성호 — 세 번째 청구)

- 계보: 티볼 54대 54 → **100미터 청구**(EP49) → **언덕**(EP50 · 성호가 혼자 이긴 걸로 침) → **아직 정식으로 안 했다**
- 이번엔 **날짜를 잡자**고 한다
- **★ 미룬 이유를 말할 수가 없다.** 성호는 그걸 **겁이나 회피로 읽는다.** 이 오해는 이 화에서 안 푼다(S10 자산)
- **성호의 성질:** 못 이긴 걸 계속 다시 하자고 하는 애. **동점을 못 견딘다**
- **★ 연결 금지:** 성호는 안 되는 걸 계속 다시 하자고 하고 단아는 그날 안 되는 걸 붙들고 있다. **같은 자리에 놓기만 하고 서술이 잇지 않는다**
- **금지:** 성호가 시제품·사정을 눈치채기 / 오해가 풀리기 / 단아의 변명

### ⚠ ⑤-B(하예진 — 틀린 근거로 편들어 주기 · 신설 v1.1)

- **간격 8 회수.** 카드 정본: **완충재** — 상대 이름을 부르고 시작, **믿음의 단정**, 질문을 부드러운 평서로 바꿔 주기, **갈등에서 문장이 길어지는 유일한 인물**(길이가 곧 완충이다)
- **고유 디테일:** 소매·가방끈을 살짝 잡는 손 / **웃으며 화제를 반 발짝 옮기는 기술**
- **역할:** 성호가 몰아붙이고 단아가 대답 못 할 때 **단아 대신 말해 준다.** 성호는 예진에게는 못 이겨서 물러난다
- **★ 그런데 그 근거가 사실이 아니다.** 예진은 `단아가 그럴 애가 아니다`라는 믿음으로 편을 드는데, 진짜 이유는 그게 아니다. **성호의 오해도 틀렸고 예진의 신뢰도 틀렸는데 둘 다 정정할 수 없다**
- **★ 이게 이 화의 두 번째 `말할 수 없음`이다.** Scene 4의 `말로 만들 수 없음`과 나란히 놓이되 **서술이 잇지 않는다**
- **금지:** 예진이 눈치채기 / 화내기 / 추궁 / 빈정거림 / 단아의 고백 충동 언어화 / **말투카드 예문 문장 그대로 쓰기**

### ⚠ ⑥(EP50 회수 — 소용없어 보이는 것)

- 봄부터 언덕에서 해 온 것: **오래 버티는 것 · 팔을 들고 있는 것 · 무거운 걸 붙잡고 안 놓는 것**
- **오늘은 그게 아무 소용이 없다.** 버티는 건 되는데 **보내는 게 안 된다**
- **금지:** 자기 비하 / 포기 선언 / 위로 대사 / `그래도 헛되지 않았다` 류 봉합

### ⚠ ⑦(영진이 멈춘다)

- 격려도 위로도 아니고 **판단**이다. 더 하면 물건이 상하거나 사람이 다친다
- **`오늘은 여기까지`** 수준으로 짧게. 이유를 길게 말하지 않는다
- **단아가 매달리지 않는다** — 자기도 알기 때문이다
- **금지:** 설명 / 다독임 / 내일의 계획

### ⚠ ⑧(승계)

- **화계:** 단아→영진 반말 / 수아→영진 존댓말 / **수아→단아 반말** / 단아↔성호 반말
- **시점 지칭:** 서술문에서 영진은 **`할아버지`**
- **영진**(§2-B): 절차·기술적 조언·멈추는 판단. **답 0**, 한 손, **안경 0**
- **정비 척도:** 회수·정리도 **공업 규모**
- **균열 2~3회** / 새 증상 0 / 작가용 개체 명칭 0
- **금지:** 반입구 / 배양·소재 / **현서·우편물** / 센티널 / `개수`·`논`·`목적`·`학습`·`시험`

## 5. 장면별 잠금

### Scene 1 — 세 번째 ※ 가드 ⑤·⑤-B 집행

- **고정:** 월요일 등교 → **성호가 온다** → 계보 요약(청구·언덕) → **날짜를 잡자** → 단아가 대답을 못 한다 → 성호가 밀어붙인다 → **예진이 들어와 단아 대신 말한다**(문장이 길어진다) → 성호가 물러난다 → **가방끈을 잡는 손** → **화제를 반 발짝 옮긴다**
- **★ 그리고 그게 아프다:** 편들어 준 근거가 사실이 아니다. 고맙고 동시에 걸린다 — **한 줄로 끊는다**
- **균열 ①:** 봄이었으면 그 자리에서 하자고 했을 것이다
- **금지:** 변명 / 오해 해소 / 시제품 연상 / 예진이 눈치채기 / 고백 충동 언어화

### Scene 2 — 놓여 있다 ※ 가드 ①② 집행

- **고정:** 하교 → 마당의 고철이 또 줄어 있다 → 격납고 작업장 자리 → **세 덩어리**(통·닻·백팩) → **손으로 만든 티** → 영진의 절차 → **몸이 달라진다**(등이 무겁고 왼팔이 처지고 사슬이 늘어져 소리가 난다)
- **§6-6 첫 노출:** 형태와 착용감까지. **원리 0**
- **`닻`이라고는 부른다.** 이름은 안 붙는다
- **금지:** 만드는 과정 / 설계 / 재료 / 이름을 묻는 대사

### Scene 3 — 안 맞는다 ※ 가드 ③ 집행

- **고정:** 밖으로 나간다(밤·앞바다 쪽 빈 자리) → 손으로 만든 표적 → **첫 발의 3박자**(`푸슉` · 정적 · 불) → **나가면서 빨라진다** → 못 맞힌다 → 둘째·셋째(못 미침·넘어감·스치고 떨어짐) → **회수**(감개 소리·그동안 그 팔을 못 쓴다)
- **★ 핵심 한 줄:** **던진 것은 나가면서 느려지는데 이건 반대다**
- **균열 ②:** 힘이 문제였으면 차라리 나았다
- **금지:** 원인 진단 / 요령 습득 / 성공 근접

### Scene 4 — 종이 위의 궤도 ※ 가드 ④ 집행

- **고정:** 수아가 본다 → **그린다**(두 마디로 꺾인 선) → 그대로 해 본다 → **그래도 안 된다** → **불이 붙는 시점이 손에 달렸다는 것** → `제 그림이 틀린 게 아니라…` → 결론 0
- **금지:** 결정적 한마디 / 답 / 자책 / 셋이 원인을 합의하는 것

### Scene 5 — 소용없어 보이는 것 ※ 가드 ⑥ 집행

- **고정:** 쉬는 사이 → 팔이 뻐근하다 → **EP50 회수**(오래 버티기·팔 들기·안 놓기) → **오늘은 소용이 없었다** → **버티는 건 되는데 보내는 게 안 된다**
- **균열 ③:** 잘하게 된 게 쓸모없어 보이는 자리
- **금지:** 자기 비하 / 포기 / 위로 / 봉합

### Scene 6 — 내일 다시 한다 ※ 훅

- **고정:** 영진이 **멈춘다** → **`오늘은 여기까지`** → 정리(감아 들이고·내려놓고·올라간다) → **단아가 매달리지 않는다**
- **끝:** **`내일 다시 한다`** 결
- **금지:** 계획 / 결의 / 위로 / 다음 화 예고
