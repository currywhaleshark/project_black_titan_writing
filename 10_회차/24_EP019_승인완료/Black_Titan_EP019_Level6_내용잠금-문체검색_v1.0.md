## 2. 회차 전체 리듬

```text
개회: 석회 선, 완성된 응원 도구, 명단의 이름
→ 피구: 패스 없는 협력 → 튕긴 공의 임자 → 동점.
→ 이어달리기: 넘겨주는 순번 / 메워지는 빈자리 → 괜히 멋있는 척
→ 결승 직전: 보지 않는 시계, 나란한 출발선
→ 총성 대신: 사이렌 — 거꾸로 흐르는 물
```

- 문체 축은 **선(線)**이다 — 석회 라인, 아웃 집계의 정(正)자 선,
  출발선, 그리고 넘어오면 안 되는 것이 넘어오는 배수로의 선.
- 시점: 전편 단아(§6-8 — `선생님`·친구 이름). 군·격납고 미등장.
- 씬 밴드: S1 1,000~1,300 / S2 1,300~1,600 / S3 1,200~1,500 /
  S4 800~1,100 / S5 400~700 (목표 5,500)
- 리듬: 행사 중문 기조, 경기 국면 단문 혼합. 단문 수렴 두 곳 —
  `동점.`(S2), 사이렌의 반 박자(S5).

## 3. 장면별 문단 비트 잠금

### Scene 1 — 개회: 4월 27일 (1,000~1,300자)

1. 수요일 아침 — 만국기, 반별 천막, **석회 라인**(트랙·코트 — `선`
   물성 ①). 라인기가 지나간 자리의 흰 가루 결.
2. 응원 도구 완성품 — 혜정이 묶었던 재료들의 현재형(EP13 회수, 문장 0).
   응원 구호 실전 1회(`검은 거인처럼` — EP13 회수, 문장 0).
3. **B1(잠금):** 혜정 `새 렌즈 어지럽지 않아?` 계열 1문항 — 답 들으면
   끝. 단아 `오늘은 끝까지 있어` → 혜정의 응답은 **말이 아니라 명단**:
   다음 경기 명단에 단아 이름을 그대로 남기는 동작 1컷.
4. 개회 진행 — 김주호 담백 1~2문장. 26명 파생(청군백군/반별 인원 계열
   수치는 26 기준).

### Scene 2 — 피구: 같은 팀의 대결 (1,300~1,600자)

1. 반 대항 — 단아·성호 **같은 팀.** 규칙 정합: **잡은 공은 아웃 아님**
   (EP11 사용자 확정 — 문장 재사용 0).
2. **아웃 수 경쟁(잠금):** 협력 대신 각자 집계 — 패스를 안 주고 각자
   잡아 각자 던지는데 그게 다 맞아서 **팀이 이기는 아이러니.** 상대
   반이 아니라 옆의 아군을 흘겨보는 시선 구도.
3. 단아 기량 상한: 학교 에이스 수준 — 빠른 공, 정확한 코스까지.
   초인·전국구 서술 0. 힘 숨김의 흔적 1컷 허용(마지막 순간 손목을
   푸는 계열 — 해설 0).
4. **집계 시비(잠금):** 튕긴 공의 귀속 —
   `그건 내 공에 맞고 튕긴 거니까 내 거다` ↔ `맞힌 사람이 임자지`.
   선 밟기 곁시비 + `도릴라` 1회.
5. **강한결 초출(잠금 — §6-6):** 소개 어구 `반장 강한결` + 카드 앵커
   (필요한 것을 말없이 먼저 옮기는 손, 규칙·기록의 아이). **아웃
   집계표를 들고 와 해당 칸을 짚는다** — 정자(正字) 표기의 물성.
   발화 상한 1: `동점.` 계열 한 단어.
6. 씬 마감: 승복의 말 없는 승복 — 승부는 계주로(이월 리듬).

### Scene 3 — 이어달리기: 닮은 챙김 (1,200~1,500자)

1. 오후 예선 — **성호 비트(잠금):** 느린 친구 속도에 맞춰 자기 순번을
   양보/조정. 생색 0 — 들키면 `작전이다` 계열 우김.
2. **단아 거울 비트(잠금):** 같은 구조 — 빠진 친구 몫을 대신 뛰고,
   들키면 같은 방식으로 부인. **거울 배치**(문장 구조까지 평행하게 —
   단, 동일 문장 반복은 금지, 리듬만 평행).
3. **으르렁(잠금):** 서로만 알아보고 서로에게만 —
   `괜히 멋있는 척한다` 쌍방 시비. 연애 코드 0, 동족혐오 문면화.
4. B4 콩트: `검은 거인이면 한 바퀴가 몇 걸음이냐` 계산(오답 수치의
   자신감 — 새 프로필 발명 0). 단아 기록 트집 1문장.
5. **장우진(선택 사용 시 잠금):** §6-9 리마인드 필수 — `같은 반` +
   반응 크고 말 많은 앵커(응원석에서 제일 시끄러운 기능). 미사용도 가능.

### Scene 4 — 결승 직전: 보지 않는 시계 (800~1,100자)

1. 마지막 계주 — 명단 회수: 3주자 성호, 마지막 주자 단아(EP17 확정).
   성호의 작전표 최종의 최종판 1비트 허용(화살표 굵기 — EP18 회수,
   문장 0).
2. **시계 대비(잠금):** 결승선을 앞두고 단아는 **시계를 보지 않는다.**
   서술은 부재로 — `보지 않았다`를 직접 쓰기보다, 온전히 트랙과
   바통에만 있는 감각으로(EP13 `1교시부터 세 번째`의 반전 — 문장
   재사용 0, 직접 대비 해설 0~1문장 상한).
3. 출발선 정렬 — 석회 선(물성 ③), 신경전 반 문장씩(`먼저 가 있어라`
   계열 쌍방).
4. 씬 마감: 출발총을 기다리는 정적 — 화약 냄새 직전의 반 박자.

### Scene 5 — 훅: 총성 대신 (400~700자)

1. **훅(고정):** 출발총 대신 **해안 대피 사이렌.** 총성을 기다리던
   몸들이 사이렌에 반 박자 늦게 반응하는 결 — 즐거운 긴장이 다른
   긴장으로 바뀌는 소리의 교체.
2. **역류(고정):** 운동장 바깥 배수로 — 물이 바다 쪽이 아니라 **학교
   쪽으로** 흐른다. 관찰 1~2문장, 원인 추정 0, 개체 형체 0.
3. 마감: 대피 방송 개시 + 단아의 다음 동기 접지 1문장(수리점으로
   빠져야 한다 — 실행 없이 판단까지). 끝.
