## 2. 회차 전체 리듬 — 전투 화(단아 밀착)

```text
저녁: 호출 — 다섯 번 이긴 몸으로
→ 부두: 크레인 위의 것이 펼쳐진다 — 꽃잎·눕기·도는 원반
→ 바닥: 바닥 전체가 따라온다 — 덮고, 누르고, 끌고
→ 탈출: 한 번 빠져나옴 — 그래도 눈앞의 넓은 놈 — 꽃이 먼저 돈다
→ 훅: 기둥 뒤 — 멈칫 — 원반과 기체 사이의 철골
```

- **전투 톤 가드 최우선:** 균열 3회 배치(S1 마른 입 / S2 공격 안
  해오는 것의 공포 / S3 참기 실패+`침착하자, 도단아`). 쿨내 0.
- **자신감 궤적(신규):** 진입 = 이긴 경험의 온도(`다 이겨 봤잖아`
  속말 1회 상한) → 오판 = 승수가 만든 직관 → 훅 = 자신감이 깎이는
  중(바닥은 안 침 — 꺾임은 여름 예약).
- **셈 삼분법:** 단아 = 몸으로 부딪히며 깨달음 — **이 화는 부딪히는
  화**(깨달음 상한 = `정면으로는 안 부서진다`류 몸의 결론까지.
  순서의 의미 파악 0).
- 씬 밴드: S1 900~1,200 / S2 1,100~1,400 / S3 1,200~1,500 /
  S4 1,100~1,400 / S5 700~1,000 (목표 5,800)
- 클리프행어 = 전투 지속(EP38 시간 경과 0 진입 — 위기 지속 3호).

## 3. 장면별 문단 비트 잠금

### Scene 1 — 저녁의 호출 (900~1,200자) ※ 집→격납고→진입

1. 화요일 저녁 — 영진의 알림(화물부두 쪽 재개 — 문면 최소). **B1
   반 박자(잠금):** 나가기 전 혜정에게 짧은 문자(`오늘도 늦어` 계열)
   — 보내면서 **규칙 3호를 떠올리는 속말 1문장**(`끝나면 끝났다고.
   그건 돌아와서 보내는 문자다` 계열 — 발신 없음·해설 없음).
2. 출격 노선(정본 물성 — 레일·수밀격벽 반 박자) → **수몰 화물부두
   진입:** 젖은 어둠, 소등된 관측 화면들의 방향, 멈춘 크레인들의
   실루엣 숲(수몰 구도심 계보 — 문장 재사용 0). **외피 = 해체 완료
   직후 맨몸**(반 박자 언급 상한).
3. **자신감의 결(잠금):** 다섯 번 이긴 몸 — 무섭지 않은 게 아니라
   무서워도 되는 걸 아는 상태(`다 이겨 봤잖아` 속말 1회). 균열 ①:
   둘이라는 걸 아는 채로 들어가는 등 뒤의 서늘함 — 마른 입(자신감
   위로 스치는 반 박자).

### Scene 2 — 꽃이 펼쳐진다 (1,100~1,400자) ※ A 개화

1. 크레인 꼭대기 — 고장 난 크레인 잔해로 보이던 것이 **움직인다.**
   개화 3박자(개요 고정): **꽃잎 같은 팔들의 잔떨림 → 한꺼번에
   이쪽으로 눕기 → 중앙 원반이 따라 도는 회전**(위장 해제의 공포 —
   EP30 관 계보의 고지 버전. 문장 재사용 0).
2. **광택 물성(잠금):** 젖은 장갑 한쪽에 **기름막 같은 광택이 잠깐
   번진다** — 스치듯 1회(원인·연결 서술 0, 몸 증상 0. `조명 탓인가`
   수준의 스침 상한).
3. 균열 ②: **공격해 오지 않는 것의 공포** — 내려오지도, 쏘지도,
   뻗지도 않고 그냥 이쪽으로 누워만 있는 것(`위에서 보는 놈`이라는
   명명 없는 몸의 감각 — 겨눠지고 있다는 실감).
4. 원반의 회전이 기체의 이동을 따라온다는 사실 확인(카메라처럼 —
   비유 상한 1회).

### Scene 3 — 바닥이 따라온다 (1,200~1,500자) ※ A 포박·끌기

1. 한 박자 뒤 — **바닥이 미끄러진다**(낮고 넓어 부두 바닥 자체가
   움직이는 착시 → 가장자리 들림으로 개체 식별). 같은 방향 선회.
2. 접근 → **중첩 갑판을 둥글게 말아 올림 → 운반막 폐합: 허리와 팔
   하나를 덮는다.** 절단 시도 0 — **몸 전체로 눌러 외해 쪽으로
   끌기 시작**(EP20~23 포박 계보와 대비: 조르지 않고 **덮어
   나른다** — 아프지 않은데 무겁고, 무거운데 어디로 가는지가 무섭다).
3. **오판 문면(개요 고정):** `저 납작한 걸 뒤집으면 끝이야.` —
   **승수가 만든 직관**(다섯 번 전부 눈앞의 큰 놈을 부수면 끝났다 —
   경험칙의 자연스러운 오작동. 성격 결함 아님).
4. 균열 ③: 끌리는 방향(외해)을 아는 순간의 **참기 실패 반 박자 →
   `침착하자, 도단아`**(EP31 계보 어구 — 문장 재사용 0).

### Scene 4 — 한 번의 탈출 (1,100~1,400자) ※ A 탈출·C4 첫 재지정

1. **이음매 공략 → 1회 탈출(개요 고정):** 중첩 갑판의 이음매를
   두들기고 운반막을 벌려 빠져나온다(힘 대 힘 — 정지 통찰 0.
   두들기면 겹겹이 눌리기만 하는 답답함 → **격파 실패, 탈출만 성공**).
2. 눈앞의 넓은 몸에만 집중 — 뒤집기 시도(가장자리 잡기 → 너무
   넓다 → 다시 두들김. 자신감의 관성 = 안 먹혀도 계속 같은 방법).
3. **첫 재지정(개요 고정 — 순서 잠금):** 방향을 바꾸는 순간 —
   **높은 꽃이 먼저 돈다 → 젖은 갑판에 짧은 광택 → 군부형이
   뒤늦게 진로를 고친다.** 단아는 순서를 **본다**(두 번째 방향
   전환에서 같은 순서 반복 — 목격 2회 상한. 의미 서술 0 — `왜
   쟤가 먼저 돌지` 수준의 스침 1회 상한).
4. **B2 기록 톤 반 컷(잠금 — 4~6문장):** 남방사 기록 — 한 개체 =
   크레인 꼭대기 거의 부동 / 다른 개체 = 미식별 검은 거인 추적
   선회. 전술지휘 0 — 화물부두·인접 항로 소개만.

### Scene 5 — 훅: 기둥 뒤 (700~1,000자) ※ 개요 고정 문면

1. 소모전의 호흡 — 두들겨도 안 부서지는 상대라는 **몸의 결론**
   (`정면으로는 안 부서진다` 상한 — 다음 수 없이 일단 거리). 크레인
   숲 쪽으로 물러나는 선택(도망 아님 — 숨 고르기).
2. **훅(개요 고정 문면):** 크레인 기둥 뒤로 몸을 숨기는 순간 —
   **군부형이 멈칫한다.** 높은 꽃은 접힌 팔을 다시 펼치지만,
   **이번에는 중앙 원반과 블랙 타이탄 사이에 굵은 철골이 걸려
   있다.** 끝(시야선 단서 1호 — **깨달음 0·해설 0·연결 서술 0.**
   단아는 멈칫을 보지만 이유를 모름·전투 미종료).
