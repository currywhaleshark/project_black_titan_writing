## 2. ★★★★★★ 사용자 첨삭 · 지적 반영

### 2-1. 첨삭 3건 — 「가 볼게」 → **「와 볼게」**

**화자 기준이 맞다.** 현서가 수아에게 오는 것이므로 「오다」다.
**★★ 「해 볼게 / 와 볼게」 대비가 더 선명해졌다** — 어디로 오는지가 나오는 말이 된다.

### 2-2. ★★★★★★ 「…말했어」 = 창작 — 지적 적중

| | |
| --- | --- |
| **지적** | **「말한적 없지않나?」** |
| **확인** | **맞다.** EP109에서 현서가 단아에게 옮긴 것은 **수아의 상태**(밥·다리)뿐 |
| 근거 | EP131 `수아 이야기는 엄마라는 사람에게 들었다` — **거기까지다** |
| **위반 유형** | **①** 새 사건 창작 — **A항 봉인 대조에서 잡았어야 했다** |

**★★★★★ 「…아니.」로 뒤집으니 회차가 좋아졌다.**

> **`그러니까 이 사람은 한쪽씩 만난다. 만나서 저쪽 얘기를 이쪽에 옮긴다.`**
> **`그런데 이쪽 얘기는 저쪽으로 안 갔다.`**

**★★★ 그리고 수아는 왜 안 갔는지 안 묻는다**(뾰족함 0) — `물어 봐야 안 갔다는 게 갔던 걸로 바뀌지 않는다`.
**대신 부탁한다** — 「말해 주세요.」 / **「언니한테 괜찮냐고는 묻지 마세요.」** / **「밥 먹었냐고 물어보세요. 그건 그냥 대답해요.」**

**「괜찮대」에 붙어 있던 여름 회상(밥 반쯤 · 열두 걸음)이 그대로 살았고,
언니를 아는 사람이 언니를 어떻게 다뤄야 하는지까지 말하게 됐다.**

### 2-3. ★★★★★★ 「말투가 공격적으로 느껴진다」 — 지적 적중

**세어 보니 수아 대사가 물음 열 개였고, 씬3에서 넷이 연달아 붙어 있었다.**

| | 초고 | v0.2 |
| --- | --- | --- |
| 물음 | **10** | **7** |
| 씬3 연타 | **4연속** | **끊음** |

| 조치 | |
| --- | --- |
| 「어디로 오세요」 **삭제** | **현서가 먼저 준다**(`…이번 주. 집으로 가시고.`) · 수아는 **「…네.」**로 받는다 |
| 「…목요일이요?」 · 「몇 시에요?」 **삭제** | 현서가 이어 말하고 **`수아는 그것도 받아 놨다`** |
| 씬4 성격 전환 | **캐묻기 → 부탁하기.** 대사 열 중 여섯이 이제 물음이 아니다 |

**★★★★★ 수아 인장이 「먼저 알고 나중에 느낀다」다.**
**물어서 아는 게 아니라 듣고 맞춰서 아는 쪽이 맞다. 물음을 줄이니 인장이 산다.**
