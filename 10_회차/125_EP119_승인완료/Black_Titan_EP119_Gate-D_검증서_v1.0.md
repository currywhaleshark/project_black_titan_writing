## 2. ★★★★★ 인물 정정 — 수아 대사가 단아식이었다

> 「뭘요」 「어떻게 달라요」 「그게 뭔데요」 이런 이번 말투들이
> **뭔가 수아보다는 단아 같은데**

**★★★★★ 두 아이 카드를 섞었다.**

| | 카드 |
| --- | --- |
| **단아** | **반문형 불평**(`왜 내가 ~인데?`) · 짧고 직선적 |
| **수아** | **한 박자 침묵 후 완성된 문장** · **「왜」를 속으로 묻고 답이 나오면 그때 입을 연다** |

**★★★ 수아는 되묻지 않는다.** 전면 재작성했다.

| 이전 | 이후 |
| --- | --- |
| `뭘요.` | **기다린다** — `안 물어도 알려 줄 것 같아서 기다렸다` |
| `안 나왔는데 왜 해요.` | `검사에서는 아직 없죠.` **(진술)** |
| `어떻게 달라요.` | **속으로 굴린다** — 상대가 먼저 이어 말한다 |
| `그게 뭔데요.` | **기다린다** |
| `저기는 매트가 깔려 있는데요.` | `저쪽은 매트가 깔려 있네요.` **(관찰)** |
| `내일은 몇 번이요.` | `내일도 세 번이에요?` — **확인하는 쪽** |
| `어디요.` | **안 묻는다** |

**★★★★ 카드의 「부러움은 질문의 형태로 샌다」는 한 자리만 남겼다** — 평행봉.
**그리고 그 자리에서도 관찰이 먼저 온다:**

> 서 있는 게 힘들려면 **서 있을 수는 있어야 했다.**
> **`저는 저거 언제 해요.`**
> **묻고 나서 수아는 자기가 물은 걸 알았다.**

## 3. ★★★★ 문형 오염 — 「받아 놨다」 4건

**첨삭(`그 말이 마음에 들었다`)이 짚어 준 것.**

**명준 시점 문형**(EP110·113·114)이 **직전 네 회차의 관성**으로 수아 회차에 새어 들어왔다.
**넷 중 둘은 같은 대사에 대한 반응 중복이었다.**

| 처리 | |
| --- | --- |
| 중복 1건 | **삭제** |
| 1건 | **`대답하고 나서 수아는 아까 그 말을 한 번 더 놓아 봤다`** |
| 2건 | **반응 문장 없이 바로 뜻으로** — `~라는 뜻이었다` |

**★★★ 수아는 받아 놓는 게 아니라 놓아 보는 쪽이다.**

## 4. ★★★★★ 신규 정본 — LOC-07B 재활실

> 재활실 미리 정해 놓자 공간

**★★★★★ 거울이 회차를 만들었다.** 신경과 1인실에는 거울이 없다.

> 병실에는 거울이 없었다. (…) **없다는 걸 오늘까지 몰랐다.**
> **없는 걸 찾은 적이 없어서 없는 줄도 몰랐던 거였다.**

**★★★ 그리고 셋이 나왔다:**

| | |
| --- | --- |
| ① | **`기억보다 말라 보였다`** · **`오랜만에 보니 이렇게 작은 줄은 몰랐다`** |
| ② | **`저 큰 것 안에 있을 때는 커 보였다`** |
| ③ | **`안 움직이는 걸 마주 보는 건 처음이었다`** — 이불 밑과 거울은 다른 일이다 |

**★★ 평행봉** — 보이되 **안 간다.** 「첫 걸음 0」을 시각으로 처리했다.
**★ 아이는 수아 하나** · **★ 병실이 조용했다는 걸 여기 와서 안다.**
