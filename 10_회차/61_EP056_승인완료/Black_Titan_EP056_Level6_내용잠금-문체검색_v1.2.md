## 2. 가드

### ⚠ ①(확인이 먼저다 — 삼분법으로 갈라 쓴다)

| 누가 | 무엇으로 |
| --- | --- |
| 단아 | 어제 본 **녹색.** 확실하지 않아서 말을 안 했던 것 |
| 영진 | **봄부터 쓴 장부** — 함몰부 안쪽의 녹색, 밝아지지도 어두워지지도 않는 빛 |
| 수아 | **★ 개체 표**(EP50 정본 — 수아가 만든 넉 장 중 한 장·생김새와 행동 칸). **지금까지 전부 녹색이었다**를 표와 기억으로 확인해 준다. 적어 둔 것은 4월 이후이고 그 앞은 만들 때 기억나는 대로 채운 것이다 |
| 군 | **공개망 분류 통지**(EP30 채널) — 공적인 문장 두 개 |

- **금지:** 한 사람이 다 하는 것 / 수아의 결정적 한마디 / 추리극
- 군 통지는 **분류·통제·철수**까지. 정체 규명·지원 제안 0

### ⚠ ②(이름이 바뀐다 = 아무도 안 온다)

- 어제까지 `부착물`, 오늘부터 **`괴수`**
- **분류가 끝났다는 건 치우러 올 사람이 생겼다는 뜻이 아니라 없다는 뜻이다** — 군은 `지원하되 관여하지 않는다`(EP30 정본)
- **부착물은 시청 일이고 괴수는 이쪽 일이다**
- **금지:** 원망·억울함 / 제도 비판 / `우리밖에 없다`류 결의

### ⚠ ③(갈퀴는 미약하다 — 위협과 난이도의 분리)

- **사람에게는 위협적이고 블랙 타이탄에게는 미약하다.** 어제 사람 하나를 실어 보낸 것이 오늘 기체 팔에는 **감기는 느낌** 정도다
- **그런데 붙은 힘은 세다.** 무서운 것은 **사람 기준**이고, 어려운 것은 **떼는 일 자체**다
- → `싸움이 아니라 일이다`가 설명이 아니라 **몸으로 증명된다**
- 여기서 나오는 감정: **저건 사람을 죽일 수 있고 나는 안 죽는다.** 그래서 내가 나온 거다 — **한 줄로 끊고 결의로 만들지 않는다**
- **금지:** 위기 연출 / 부상 / 경보음 / 루시식 경고

### ⚠ ④(갈퀴의 성질은 이해로 온다)

- 저항이 미약하므로 단아는 **위험해서 푸는 게 아니라 어떻게 되나 보다가** 안다
- **당기면 조이고 밀고 들어가면 풀린다.** 팔이 먼저 안 것이다(삼분법)
- 그리고 **어제 그 사람들이 왜 오래 걸렸는지**가 풀린다 — EP55에서 방법을 안 보여 준 이유
- **아는 사람은 단아뿐이고 말할 데가 없다** — **한 줄.** 넋두리로 늘리지 않는다
- **금지:** 영진이 알려 주기 / 시청에 알리자는 대화 / 자책

### ⚠ ⑤(3연타 = 걸 데가 없다)

| 단 | 없는 것 | 몸의 감각 |
| --- | --- | --- |
| 1연타(**6월 첫머리**·기성립) | **거리** | 던진 것이 안 닿았다 |
| 2연타(EP52~53) | **지지** | 발이 밀렸다 |
| **3연타(여기)** | **걸 데** | **손이 미끄러진다** |

- **금지:** `힘이 모자랐다`·`더 세게`
- 순서: 손가락이 안 들어간다 → 잡아당기면 미끄러진다(판이라 걸릴 데가 없다) → 두들기면 **벽이 먼저 깨진다**
- **저쪽은 걸고 당기는 것을 갖고 있고 이쪽은 없다** — 이 대비로만 쓴다

### ⚠ ⑥(병따개 — 이 아크의 문법)

- **영진의 한마디**(§2-B): 맞는 공구가 없으면 **뜯어낸 걸 쓴다.** 전술이 아니라 **정비공의 사고방식**이고, 답이 아니라 **손에 있는 걸 다시 보게 하는 말**
- 얇고 단단하다 → 가장자리에 밀어 넣고 비튼다 → **걸린다** → **벽을 안 깨고 떨어진다**
- **★ 사다리는 안 무너진다:** 병따개는 **미는 도구**지 당기는 도구가 아니고 **하나씩**이다. 요령이 생겨도 **반나절이 걸리고 밀물이 온다**
- **★ 수거 절차(신설 2026-08-14 사용자):** **떼어낸 판을 물에 빠뜨리면 안 된다** — 떠내려가면 딴 데 붙고 가라앉으면 밑에서 붙는다. 영진이 그걸 지적하고, **물 안 닿는 마른 바닥에 한 군데로 모은다.**
  → **떼는 것보다 옮기는 게 길어진다.** 한 장마다 왕복이 붙고 밀물 시계가 더 빡빡해진다. 위쪽에서 뗀 것은 **아래에서 받아야** 한다
  → **★ 수거로 안 끝난다(v1.2 사용자):** 살아 있으면 안 녹는다. 그래서 **부숴야 한다** — 하나씩 손 위에 올려놓고 **무른 아래쪽을 눌러** 부순다. **뗄 때와 달리 저항이 없다.** 부서진 것은 바닷물에 떨어지며 **검붉게 녹아내린다**
  - **★ EP5 정본과 일치:** `잔해 전량이 용해 소실로 기록됐습니다. 헬기 관측 기준, **사체는 착수 후 붉게 풀려 확산·소실.** 회수 시도 전에 끝났습니다.` → 봄부터 그랬다. 단아는 그때 **멀리서 물이 변하는 것만** 봤고, 오늘은 **손 위에서** 본다
  - **감각:** 불쾌하되 **마무리까지 해 줘야 하는 일**이다. 분노도 통쾌함도 아니다
  - **무더기는 안 남는다.** 다 하고 나면 그 자리에 아무것도 없다 — 그래서 벽의 자국만 남는다
- **금지:** `걸어서 한 번에 당기면` 류 문장(**앵커 선점 0**) / 요령의 언어화·명명 / 단아가 스스로 착안(영진 몫이다)

### ⚠ ⑦(목격 3단 · 여론 = 불안)

- EP9 사진 → EP49 영상 → **오늘 눈으로, 낮에**
- 벽은 통제됐지만 **난간·옥상·먼 데서 본다.** **통제해도 본다**는 게 이 단의 성질
- 여론: `저 벽이 삭고 있다` — 파도와 다른 종류의 공포
- **조종석·조종자 인지 0** / **비난·항의 0**(S10 몫) / 환호 0

### ⚠ ⑧(다 뗐는데 — 훅)

- 물이 차기 전에 **겨우 다 뗀다.** 그런데 뗀 자리마다 자국이고 첫 놈 자리는 크게 뜯겨 있다
- **처음으로 `이겼다`가 안 붙는 전투.** 균열 = 분함이 아니라 **허탈**

#### ★ 장부 — 세 줄 (정본 정정 2026-08-14)

**확인 결과 옆 칸에는 한 줄뿐이다.** EP53에서 `아직 아무것도 없는 칸`에 처음 적었고(`버틸 것이 없다.`), EP54의 `발에 뭐라도.`는 **목록 쪽** 줄이다. 그대로 두면 두 줄이므로 다음과 같이 잠근다.

1. 영진이 옆 칸에 **`떼어낼 것이 없다.`** 를 적는다
2. 그리고 **위에 한 줄을 끼워 넣는다** — **6월 첫머리** 것이다. **`닿을 것이 없다.`**
3. 세 줄이 나란히 놓인다
4. 여백에 한 줄 더 — **`이건 관측에 안 걸렸다.`**

- **왜 소급해서 적나:** 세 개가 **같은 종류**라는 걸 이제 알아봤기 때문이다. 나란히 놓는 사람이 영진이라는 게 EP61의 씨앗이다
- **금지:** 그 인식의 언어화 / 앵커 착상 / 단아가 그 줄을 읽고 뭘 깨닫는 것(`안 물어보는 집` 계보 유지)

## 4. 장면별 잠금

### Scene 1 — 같은 것 ※ 가드 ①② 집행

- **고정:** 공개망 통지(문장 두 개 · **어딘가의 거인에게 보라는 듯 정보만 뿌린다**) → 단아의 녹색 → 영진의 장부(앞 권) → **수아의 개체 표 — 전부 녹색이었다** → **이름이 바뀐다** → **아무도 안 온다** → 물때 → 수아는 여기까지 → 낮에 나간다
- **⚠ 물때 시각은 확정된 정사가 없다.** 시계 수치를 지면에 만들지 않는다 — `오늘은 낮에 제일 많이 빠져`·`물 보면서 해`·`무릎 넘으면 아래쪽은 접어` 수준으로만 쓴다. 수아가 적어 주는 것도 **무릎·허벅지·허리** 세 줄이다
- **균열 ①:** 확인은 끝났는데 **부른 사람은 아무도 없다**
- **금지:** 결의 / 제도 비판 / 출격 동선 재설명

### Scene 2 — 미약한 것 ※ 가드 ③④ 집행

- **고정:** 어제 사람이 서 있던 자리 → **이번엔 저게 작다** → 뚜껑의 리듬(무음) → 삭은 자리가 어제 본 것보다 **깊다** → 손을 대면 **닫힌다** → 비집으면 **갈퀴** → **아무렇지도 않다** → 당기면 조이고 밀면 풀린다 → **어제 그 사람들** (한 줄) → **저건 사람을 죽일 수 있고 나는 안 죽는다** (한 줄)
- **금지:** 위기 / 부상 / 넋두리 / 명명

### Scene 3 — 그런데 안 떨어진다 ※ 가드 ⑤ 집행

- **고정:** 무서운 건 없어졌는데 일은 그대로 → 틈 0 → 미끄러짐 → **벽이 먼저 깨짐** → 3연타 → 영진의 절차(삭은 겉·손끝 느낌) → **한 바퀴**(자동차 한 대를 둘러싸고 도는 일·아래는 감으로) → **겨우 하나** → **벽이 같이 뜯긴다**
- **금지:** 힘 부족 서술 / 요령 선취

### Scene 4 — 병따개 ※ 가드 ⑥ 집행

- **고정:** 손바닥의 판(콘크리트 한 겹) → 남은 것들을 본다 → **영진의 한마디** → 밀어 넣고 비튼다 → **걸린다** → **벽을 안 깨고 떨어진다** → **건져서 마른 바닥에 모은다**(가드 ⑥ 수거 절차) → 두 번째가 훨씬 빨랐다
- **금지:** 앵커 선점 문장 / 명명 / 단아 착안

### Scene 5 — 반나절 ※ 가드 ⑦ 집행

- **고정:** 하나씩(밀어 넣고·비틀고·**받고·옮겨다 놓고·다시 온다**) — **떼는 것보다 옮기는 게 길다** → 아래를 다 하면 위 → **붙으면 한 손** → 통제선 밖의 사람들(난간·옥상·먼 데) → **형체를 본다** → 여론 **불안** → 물이 오기 시작한다
- **금지:** 비난 / 환호 / 조종자 추정 / 요령의 언어화

### Scene 6 — 다 뗐는데 ※ 가드 ⑧ 집행

- **고정:** 겨우 다 뗀다 → **벽을 본다**(자국·삭은 데·크게 뜯긴 첫 자리) → **마른 바닥의 무더기** → **이긴 것 같지가 않다** → 균열 ③ **허탈** → 저녁 장부 → **세 줄 + 여백 한 줄**
