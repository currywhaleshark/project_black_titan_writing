## 2. 회차 전체 리듬

```text
며칠의 결: 빈 책상 — 소문의 신화 — 창백하다는 소리
→ 개선: 목발이 교실 문을 두드린다 — 무대 체질의 귀환
→ 그래도 우리를 지켰다: 칭찬 앞에서 웃지 못하는 반 박자
→ 가방: 몰래 치우는 손 — 들키는 반 박자 — 억울함이 죄책감보다 빠른 입
→ 창백함과 표: 묻지 않는 친구 — 나란히 적힌 두 이름
→ 훅: 깁스 풀리면 다시 붙자 — 목발부터 떼고 큰소리쳐
```

- 문체 축은 **자리**다 — 미안하다는 말이 들어갈 자리가 없어서, 말
  대신 들어가는 것들(가방을 치우는 손, 맞받는 입, 명단의 이름)의 화.
- 시점: 전편 단아 밀착(교실). S1 등굣길 도입, S5 종지 = 대사 컷.
- 씬 밴드: S1 800~1,100 / S2 1,200~1,500 / S3 1,300~1,600 /
  S4 1,000~1,300 / S5 600~900 (목표 5,800)
- 리듬: S1 낮은 요약 → S2 소동(무대) → S3 정지-반사-티키타카(완급) →
  S4 조용한 문장들 → S5 문답 컷. 톤 가드: 죄책감 국면에도 균열
  2~3(웃으려다 만 얼굴·빨라진 입·아차의 반 박자).

## 3. 장면별 문단 비트 잠금

### Scene 1 — 며칠의 결 (800~1,100자)

1. **사이 며칠 압축(§6-②):** 목·금의 빈 책상 하나(이름 언급은 자연
   결로), 소문 시장 — **네 번째 승리의 교실 신화**(끌려가다 돌아와
   이긴 검은 거인 — 목격담 과장 1~2비트, 단아는 정정 0 — EP17 소문
   문법 계승·문장 0).
2. 군 배경 상한: 라디오/어른들 결로 `수거물 없음` 계열 1비트(용해·
   사체 어휘 0 — 사실 문면만).
3. **등굣길(잠금):** 오늘 나온다는 것을 연락망으로 아는 단아 —
   걸음이 세어지는 결(죄책감 해설 0). 창백하다는 소리를 며칠 들었다는
   1비트(B1 준비).

### Scene 2 — 목발의 개선 (1,200~1,500자)

1. **등장(잠금):** 목발 소리가 먼저 오고, 문이 열리고 — 과장된 환영.
   교실이 무대가 되는 결(성호는 무대를 마다하지 않는 아이 — 목발
   회전·깁스 전시 계열 1~2비트). **예진 완충 1~2발화, 우진 목청 앵커
   1발화**(§6-9. `사귀냐` 0).
2. **`그래도 우리를 지켰다`(잠금 문면):** 검은 거인 때문에 다친 것
   아니냐는 물음(발화자 = 반 아이 무명 처리) → `괴수가 그대로였으면
   대피 줄 전체가 더 위험했다` 계열 + **잠금 문면.** 영웅-대가 병렬의
   첫 발화 — 성인 에이스 신화 유지(정체 단서 0).
3. **단아의 반 박자(잠금):** 칭찬받는 검은 거인 앞에서 웃으려다 만
   얼굴 1비트. 박수에 반 박자 늦게 합류하는 손(해설 0).
4. **동선 정비(잠금):** 주호 — 자리 재배치로 통로 넓히기(담백 실무
   발화 1). **한결 — 말없이 의자·가방 위치 정리**(무언 정리 앵커 —
   `말 대신 종이` 기능의 물건 버전, 간격 5 리마인드 겸용).

### Scene 3 — 가방 (1,300~1,600자) ※ 이 화의 심장

1. **마지막 가방(잠금):** 정비된 통로에 하나 남은 가방 — 한결의
   정리가 놓친 하나(자연 결). 단아가 **우연인 척** 치운다 — 발끝으로
   밀거나 제 자리 지나며 슬쩍. 속말 상한 1줄(§6-③ 질문형):
   `미안하다는 말은 어디다 넣는 걸까` 계열(직접형 `미안` 발화 0).
2. **들킴(잠금 — 정정 문면):** 성호가 그 움직임 자체를 잡는다 —
   `음험하게 몰래몰래 움직이는 거 봐라. 너 그때 마지막 주자 시합
   때도 뭔가 했지.` 계열(고마움 인지 0·가방-시비 인과 연결 0 —
   수상한 라이벌 취급. **소급 의심 대상 = EP17 마지막 주자 결정전**
   — 자기가 진 달리기라서 `느렸다` 응수가 정확히 꽂히는 과녁.
   당시엔 `가을 운동회 때 정식으로`로 쿨하게 받았던 시합을 이제 와서
   수작 의혹으로 재소환하는 뻔뻔함이 맛).
3. **즉시 맞받기(잠금 — 이중성):** 억울함이 죄책감보다 빠른 입 —
   `뭘 해, 걸리적거리니까 치웠지` + `뭔가 한 건 네 다리가 느렸던
   거고` 계열. **반사가 나가고 아차가 반 박자 뒤에 오는 순서** —
   시합 건은 완전히 억울하고 몰래 움직인 건 진짜라는 이중성(해설 0,
   반 박자의 배치로만).
4. 도릴라·재대결 담론 재개 — 교실의 익숙한 소음으로 복귀(주변 반응
   1비트: 예진 `오늘 첫 번째예요` 계열 변주 허용 — 문장 0).

### Scene 4 — 창백함과 표 (1,000~1,300자)

1. **B1 창백함(잠금):** 혜정 — 어디 있었는지 **묻는 대신** `얼굴이
   아직 창백하다`. 단아 `괜찮아` → 더 캐묻지 않음. (커버·오독 유지 —
   부재 프레임 = 가족 사정·피로.)
2. **재편성표(잠금):** 중단된 체육대회 재편성표 게시 — 혜정이 **단아와
   성호의 이름을 함께 남긴다**(명단 문법의 재현 — 문장 0. 지우지도
   옮기지도 않는 손의 계보).
3. **C1 휴지 명시(잠금 1비트):** 새 이상 없음 — 칠판 글씨가 잘 보인다
   계열 생활 문장 반 문장 상한(그날의 안 보임 = 물리 포박 정리 반
   문장 허용, 신경 어휘 0).
4. **영웅관 전환의 착지(잠금 — §6-③):** 재편성표의 두 이름을 보는
   단아. 속말 1~2줄 상한 — `이기면 되는 줄 알았다` → `누가 안 다쳤는지
   끝까지 세는 것까지가 싸움` 계열(문장은 초고에서 — 잠언화 금지,
   단아의 셈 언어로).

### Scene 5 — 훅: 재대결 예고 (600~900자)

1. 하교 무렵 결 — 깁스 다리를 **의자 위에 올린** 성호(전시의 연장).
2. **훅 문답(개요 고정 문면 — 잠금):** 재편성표를 가리키며 —
   `깁스 풀리면 다시 붙자. 이번엔 도망가지 마, 도릴라.`
3. **`목발부터 떼고 큰소리쳐.` — 컷(§6-④).** 뒤에 서술 0~1문장
   상한(아크 마감 해설 0 — 교실 소음으로 끝나는 결 허용). 끝.
