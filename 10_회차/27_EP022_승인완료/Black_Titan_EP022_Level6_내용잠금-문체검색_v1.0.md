## 2. 회차 전체 리듬

```text
순서의 셈: 놓는 소리가 있다는 것의 의미
→ 틈: 넷이 동시였던 적이 없다 — 두 번, 세 번
→ 결심: 버티기를 버리는 반 박자
→ 돌진: 저항이 없는 방향 — 파고들기 — 들이받기 — 일어서기
→ 빛: 두 화 만의 첫 시각
→ 문구: 돌아온 눈이 제일 먼저 읽는 것
→ 훅: 대답을 잊은 사이, 다시 허리
```

- 문체 축은 **전환**이다 — 힘의 셈에서 순서의 셈으로, 버티기에서
  따라가기로, 어둠에서 빛으로. 그리고 마지막 전환: 안도에서 대가로.
- 시점: S1·S2·S3 단아 밀착(시각 0 → S3 말 빛부터) / S4 단아+정비실
  1컷 / S5 단아 밀착.
- 씬 밴드: S1 900~1,200 / S2 1,300~1,600 / S3 1,400~1,700 /
  S4 1,000~1,300 / S5 400~700 (목표 5,800)
- 리듬: S1 느린 청음 → S2 확증의 반복·결심 → S3 가속(짧아지는 문장)
  → 돌파 순간 긴 문장 1회(빛) → S4 정지(문구) → S5 최단문.

## 3. 장면별 문단 비트 잠금

### Scene 1 — 순서의 셈 (900~1,200자)

1. 수중 운반 지속 — 수심·부유·질문의 잔향(EP21 문장 재사용 0).
2. **단서 회수(잠금):** 놓는 소리만 늦게 도착한다는 것(EP21 등재) —
   그 소리의 의미를 처음 읽는다. **놓는 소리가 있다 = 놓는 순간이
   있다.** 깨달음은 사건이 아니라 셈의 부산물로(번뜩임 서술 0 —
   세다 보니 걸리는 결).
3. **셈의 교체(잠금):** 힘의 크기 대신 순서를. 몸에 걸리는 장력이
   어느 방향부터 죽고 살아나는지를 시간으로 세는 서술 2~3비트.

### Scene 2 — 틈 (1,300~1,600자)

1. **확증(잠금):** 네 장력이 한 번에 유지된 적이 없다 — 앞 팔이
   놓고 옮겨 붙는 사이 전체 당김이 한 박자 얕아진다. **두 번, 세 번
   반복 확인**(단독 발견 — 수아·군·영진 조언 0).
2. 영진 무전(잠금 문면 계열): `버티는 거 그만할 거야` 통보 1~2문장.
   영진의 대답은 만류가 아니라 실무(`시점 부르면 맞춰 주마` 계열
   짧은 수용 — 침묵 반 박자 허용).
3. **결심의 물성(§6-②):** 두 달 내내 버티기로 싸운 몸이 힘을 빼는
   쪽을 더 어려워하는 결 — 관성을 거스르는 반 박자. 공포 장문 0.
4. 씬 마감: 다음 놓는 소리를 기다린다 — 기다림 자체가 공격 준비라는
   전도(짧게).

### Scene 3 — 당김 안으로 (1,400~1,700자) ※ 전투 정점

1. **돌진(잠금):** 놓는 소리 — 지금. 버티기를 풀고 당기는 방향으로
   전력. **저항이 없다**(두 달 만에 처음, 개체의 힘과 내 힘이 같은
   쪽 — 이 낯섦 1비트).
2. **느슨해지는 감김(잠금):** 당김보다 빨리 가자 감긴 것들이 팽팽함을
   잃는다 — 묶여 도는 것에서 파고드는 것으로. 팔 기부 안쪽까지.
3. **들이받기(잠금):** 맨손·몸통박치기만. §5 물성 — 무게 대 무게,
   수중 완충(타격감 과장 0).
4. **기립(잠금 — 물리 확정):** 부력·떠오름 서술 0. 충격에 견인
   자세(눕혀 끌기)가 깨지고 → 발이 바닥을 되찾고 → **일어선다.**
   수로는 깊어도 쉰두 미터보다 깊지 않다 — **키로 이기는 생환.**
5. **수면 돌파 — 빛(잠금·§6-①):** 머리와 한쪽 팔이 물 밖. 두 화
   만의 첫 시각은 화면이 아니라 **빛부터**(감각 순서: 빛 → 소리
   갈라짐(물 안/밖) → 화면 복귀는 S4로 이월). 공기 반, 물 반.
6. 씬 마감(잠금): 탈출이지 승리가 아님 — 다리·허리 잔존 포박 +
   발밑 진흙(디딜 수는 있되 고정 안 됨 — EP23 재료, 서술 1비트).

### Scene 4 — 돌아온 화면 (1,000~1,300자)

1. **불규칙 복귀(§6-①):** 몇 개는 돌아오고 몇 개는 여전히 검게 —
   소등의 역순 아님. 수평계의 지면 금이 돌아와 있다(EP21 훅 되갚음 —
   문장 재사용 0).
2. **EP21 모순 회수(잠금 — 1문장 상한):** 기울기와 물소리가 어긋났던
   이유 = 눕혀져 끌리고 있었기 때문. 서고 나서야 읽히는 답.
3. **B2(잠금):** 공개 재난망 — 교각군·침수도로 사면 = 대피 완료 구역
   공개(구조물 상태·접근금지선만. 제안·유인 문면 0 — 정보의 나열
   까지).
4. **B4 문구(잠금 — 이 화의 심장):** 문면 그대로 1회 —
   **`청해남초 대피 중 학생 1명 이송.`** 이름 없음. 단아: 소리 내지
   않고 다시 읽는 동작 1회(§6-③). 인지 상한 = 자기 학교 + 자기
   전투 + 같은 오후 → **`겹쳤다` 한 단어 계열**(신원 추측 0, 옹벽·
   계단 연결 0 — 독자만 잇는다). 죄책감 장문 0(EP23~24 창구).
5. **정비실 1컷(§6-④):** 수아 — 화면 복귀 목격, 준비물 쪽으로 가는
   손(발화 0~1). 영진 — 같은 문구를 보고 **말하지 않는다**(무전
   공백으로 처리, 위로·해설 0).

### Scene 5 — 훅: 다시 허리 (400~700자)

1. 무전 — 영진의 상태 확인 호출. **단아의 대답 부재를 행동으로:**
   대답 대신 문구를 다시 읽고 있다(잊었다는 서술 0 — 보이는 것만).
2. **훅(개요 고정):** 그 사이 물속에서 팔이 올라와 **다시 허리를
   감는다.** 상황만, 다음 화 동기 해설 0. 끝.
