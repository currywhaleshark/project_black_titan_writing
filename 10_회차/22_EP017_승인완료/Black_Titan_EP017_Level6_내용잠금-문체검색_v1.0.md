## 2. 회차 전체 리듬

```text
월요일: 분필 수업 → 카레 적중 → 소문의 각색 → 계주 결정전
→ 교실: 성호의 첫 정답 → 단아의 이중 침묵 → 밀려온 필기 → 고마워
→ 수리점: 같은 계산대의 감사와 불평 → 편들 수 없는 접수 담당
→ 방과후: 전기 없는 바이올린 → 옮겨 적는 공책
→ 며칠 뒤: 켜진 칠판 → 밀어 올리는 안경 → 안내장
```

- 문체 축은 **정산**이다 — 승리가 생활의 언어(급식·필기·수리 접수·
  안내장)로 환전되는 며칠. 전투 어휘 0.
- 시점: S1~S3·S5 단아 / S4 수아(§6-8 전환 — EP13 구조 재사용, 문장 0).
- 씬 밴드: S1 1,300~1,600 / S2 1,300~1,600 / S3 1,100~1,400 /
  S4 800~1,100 / S5 500~800 (목표 5,500)
- 리듬: 생활 중문 기조. 단문 수렴은 두 곳만 — B1 수용의 순간(S2),
  훅의 안경(S5).

## 3. 장면별 문단 비트 잠금

### Scene 1 — 월요일: 정전표 수업 (1,300~1,600자)

1. 월요일 아침 — 분필 수업·손 필기 체계. 김주호의 전환 운용(기능 재사용,
   EP14 문장 0). 야외수업 배치 1비트.
2. **카레(§7-③ 잠금):** 급식 = 카레. 예진의 예언 적중 — 우쭐 1비트
   (`내가 뭐랬어` 계열 1~2문장). 상온 우유 계열 물성 1컷.
3. 소문의 각색(잠금): 주말 사이 도착한 밤 전투 목격담 — 맞는 것(탑을
   받쳤다)과 틀린 것(탑을 던졌다 계열)이 섞임. 나래 미등장 유지 —
   무명 아이들의 입으로. 단아는 정정하지 않는다(정정할수록 위험).
4. **계주(§7-④ 잠금):** 체육 시간 결정전 — 단아 승. `마지막 주자는
   도단아` 확정 + 성호 재경기 요구 한 문장. **톤 잠금(사용자 지시):
   장난·도발 한정 — 추하지 않게.** 패배 자체는 쿨하게 인정하고, 도발은
   과장 수사의 자기 인식형(`오늘은 내가 봐준 거고, 가을에 두고 보자`
   계열) — 억지·떼쓰기·심판 탓 금지. 단아의 맞받아치기 반 문장 허용
   (쌍방 리듬 복구 = 관계의 표지). 배경 1비트 상한 — 확대 금지.

### Scene 2 — 교실: 논쟁과 필기 (1,300~1,600자)

1. **B4(잠금):** 정전 책임 논쟁 — `거인이 탑을 부숴서 이렇게 됐다`에
   성호의 반박: `괴수가 그대로 있었으면 도시 전체가 멈췄을 거다` 계열
   열변. **첫 정답의 낙차** — 늘 틀리던 성호가 맞는 말을 하자 교실이
   잠깐 조용해지는 반 박자(B4 시그니처: 진지한 순간의 짧아지는 문장).
2. **단아의 이중 침묵(잠금):** 기쁘면서도 — 옹호에 고맙다고 할 수 없고,
   탑 손상 관여도 말할 수 없다. 내면 1~2문장 상한, 행동 지문 위주
   (지우개를 오래 쥐는 손 계열).
3. **B1(잠금 — 심장):** 어두운 교실, 창가 반사 속 칠판. 단아가 글씨를
   오래 찡그려 본다 — **정전 조건이 부인 가능성을 만든다**(어두워서
   안 보이는 것과 구분 불가). 혜정이 말없이 필기를 책상 가운데로.
   - 혜정: `병원 가 봐. 안경 바꿀 때 된 거 아니야?` 계열 1~2문장.
     심문 어조 0, EP6·EP11 질문 문면 재사용 0.
   - **단아의 수용:** 손을 빼지 않는다. 화제를 돌리지 않는다.
     `……고마워.` — 단문 수렴 지점 ①. 처음이라는 사실은 서술 1문장
     (`이번에는` 계열)으로만.
4. 씬 마감: 나눠 보는 필기의 물성 — 혜정 글씨의 결(색 테이프 매듭을
   두 번 감던 손의 글씨 — EP13 회수, 문장 0).

### Scene 3 — 수리점: 감사와 불평 (1,100~1,400자)

1. 하교 후 — 수리 대란: 냉장고·전열기·충전기 행렬. 접수 이름표가 다시
   열 개를 넘는 물성(EP14 회수, 문장 0). 영진은 지하·지상 왕복 —
   지하 정비는 밤으로 밀림.
2. **병치(§7-① 잠금):** 같은 계산대 앞 무명 손님 2인 —
   `그래도 검은 거인이 살렸지, 그게 어디야` /
   `살리긴 살렸는데, 며칠을 또 이러고 살아야 하나`.
   두 대사는 연달아, 서로에게 하는 말이 아니라 각자 하는 말로.
3. 단아의 접수(잠금): 듣기만 한다. 편들 수 없음 — 내면 1~2문장 상한
   (`둘 다 맞아서` 계열). 영웅 변호 시도 0.
4. 영진의 순서 1비트: 냉장고 먼저, 전열기 나중 — 말 대신 우선순위.
5. 씬 마감: 저녁 정전 시간 — 손전등 아래 숙제, 정전표 생활의 정착 1컷.

### Scene 4 — 방과후: 전기 없는 바이올린 (800~1,100자) ※ 수아 시점

1. 방과후 재개 — 전기 없는 음악실. **바이올린은 전기가 필요 없다** —
   수아·하랑의 작은 발견(하랑 발화 1~2: `피아노반은 오늘 쉰대` 계열
   우월 개그 가능).
2. 어두워서 악보 대신 외워서 — 자연광 창가의 물성. 같이 틀리던 세 번째
   줄의 근황 1비트(EP13 회수, 문장 0 — 이제 덜 틀린다 계열 성장 소묘).
3. 집 — EP15 시각 기록을 **새 면에 옮겨 적기.** 사유는 생활 1문장
   (`앞 장이 구겨져서` 계열). 전술 제시 0, 공개 0, 분석 0.
4. 씬 마감: 가방 옆의 공책 1컷 — 생활과 기록의 동거.

### Scene 5 — 훅: 켜진 칠판, 안경 (500~800자)

1. 며칠 뒤 — 복구 완료의 순간: 전등·전자칠판 일제 점등, 교실의 작은
   환호(꺼질 때 환호하던 아이들이 켜질 때도 환호하는 대칭 — EP14 회수,
   문장 0).
2. **훅(고정):** 켜진 칠판 앞 — 단아가 글씨를 보려고 안경을 밀어
   올린다. 단문 수렴 지점 ②. 해설 0 — 동작과 밝아진 교실의 대비만.
3. 김주호 — 지나가며 시력검사 안내장을 책상에. 대사 0~1
   (`가정통신문. 부모님께 갖다 드려라` 수준). 추리·개별 언급 0. 끝.
