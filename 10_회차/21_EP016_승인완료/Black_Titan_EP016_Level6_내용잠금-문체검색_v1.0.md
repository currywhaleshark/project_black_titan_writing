## 2. 회차 전체 리듬

```text
손을 떼다 → 되감은 화면: 피한다는 사실
→ 몰이: 하나씩 닫히는 길 → 남은 자리 하나
→ 넘어뜨리기: 버팀 — 기울기 — 긴 낙하
→ 수조 바닥: 얽힌 다리 → 뒤집기 → 꺼지는 초록
→ 새벽 비: 붉게 녹는 것 → 늦게 돌아오는 불 → 정전표의 지명
```

- 문체 축은 **소거**다 — 개체의 선택지가 줄고, 초록 점이 꺼지고, 사체가
  사라지고, 그 자리에 생활의 청구서(정전표)가 남는다.
- 조종석 밀착 기본. S5 용해·귀환은 반원경 허용(수조 가장자리 시점).
- 씬 밴드: S1 900~1,200 / S2 1,600~1,900 / S3 1,200~1,500 /
  S4 900~1,200 / S5 600~900 (목표 5,800)
- 리듬: S2 몰이 = 반복 중문(체스의 인내) → S3 밀기부터 단문 수렴 →
  S4 제압 최단문 → S5 비·불·방송의 느린 착지.

## 3. 장면별 문단 비트 잠금

### Scene 1 — 손을 떼다, 그리고 복기 (900~1,200자)

1. 원격 지지대 인계 완료 — 손을 떼는 순간의 잔류 부하 1~2문장(무게의
   기억 — 통증 아님).
2. **영상 복기(잠금):** 조종석 화면 되감기 + 영진 무전. 세 번의 회피 —
   확인은 사실만: 일정 거리, 접힘, 상승. 잠금 문면 계열:
   `왜 피하는지는 모른다.` → `피한다면, 피할 방향을 고를 수 있다.`
   원리 대사 0(영진 포함).
3. **남방사 방송(잠금):** 빈 비상 냉각수조 주변 대피 완료·폐쇄 정비탑
   가동망 분리 — 공개주파수 반복. 단아의 수신·암기(EP15 버릇 연속).
4. 작전 성립 — 지시 없이 맞물리는 각자의 일(협조 명시 0). 경보는 배경
   지속(시간 압박의 저음).

### Scene 2 — 몰이: 닫히는 길 (1,600~1,900자)

1. **몰이 1단:** 도시 방향 지지점 쪽에서 접근 — 개체는 접고, 반대편 더
   높은 곳으로. **쫓지 않고 민다** — 거리 유지, 방향만 부여.
2. **몰이의 셈(잠금 — EP15 문체 계승):** 남은 높은 지지점의 수를 센다.
   `셋. 둘.` 방송의 빈 구역·분리 구획과 대조 — 지도가 아니라 몸과 귀.
3. **2~3단:** 옮길 때마다 선택지가 주는 구조 — 남은 방향이 전부 낮거나
   전부 단아 쪽. 개체는 매번 더 높고 깨끗한 쪽(패턴 일관 = 몰이 근거).
   한 번쯤 예상 밖 방향 시도 → 그쪽도 닫혀 있음(방송 회수)으로 복귀.
4. §5: 타이탄 이동은 무겁게(딛는 자리·물보라·잔해 — 씬당 1~2회),
   개체는 `접힌다·건너간다·펴진다`. 서두르지 않는 밤 — 긴장은 줄어드는
   수로.
5. 씬 마감(잠금): 개체가 **폐쇄 정비탑** 꼭대기에 앉는다. 다리들이
   벌어지다가 — **갈 곳을 찾지 못하고 멈추는 반 박자.** 더 높은 곳이
   없는 자리.

### Scene 3 — 넘어뜨리기 (1,200~1,500자)

1. 정비탑 기부 — 가동망 분리 방송의 회수 1문장(밀어도 되는 탑).
2. 빈 수조 방향 확인 1컷 — 물 없는 콘크리트 바닥, 비워진 주변(군의
   일이 끝난 풍경). **비어 있음의 확인이 이 씬의 안전핀.**
3. **밀기(잠금 — 과정으로):** 버팀(탑이 저항하는 시간) → 기울기 시작
   (돌아오지 않는 각도의 순간 1문장) → 길게 넘어가는 과정. 낙하는
   순간 아님. 충격파·먼지·콘크리트 조각은 **여기 1회 집중**(§5-4).
4. **금지 재확인:** 어깨 측정대 0, 단아는 탑과 함께 가지 않는다(지면
   위에서 밀기 완결). 개체 낙하 — 수조 바닥.
5. 씬 마감: 높은 곳의 왕이 평지에 눕는 대비 1문장.

### Scene 4 — 평면전: 맨손 (900~1,200자)

1. 수조로 내려가는 단아 — `이번에는 내려가는 게 맞는 방향` 계열 1문장.
2. 평면의 무력함(잠금): 긴 다리가 미끄러지고 서로 얽힌다 — 일어서려는
   시도가 얽힘을 키우는 인과. 콘크리트에 긁히는 금속성 마찰음(G0-010 —
   개체 소리 허용).
3. **뒤집기:** 중심체를 굴려 뒤집는다 — EP10과 기능 구분(옮기기 아닌
   뒤집기), 문장 재사용 0. 드럼통 박자 계열 어휘 0.
4. **제압(잠금):** 배 쪽 — 딱딱한 판 아래 부드러운 부위(명칭 0, 물성만).
   맨손. 기능 정지 — `멎었다`·`멈췄다` 계열까지. 사망 어휘 0.
5. **초록 소등(잠금):** 초록 점들이 순서대로 꺼진다 — 마지막 하나까지.
   정적 1문단. 경보가 멎는다.

### Scene 5 — 새벽 비, 늦게 돌아오는 불 (600~900자)

1. **봄비(잠금 — 사용자 지시):** 동틀 무렵 비. 수조 바닥의 개체에
   빗물이 닿자 몸이 **붉게 녹기 시작한다.** 현상만 — 원인·해설·명명 0.
   붉은 물이 배수구 쪽으로. EP4 기시감은 독자 몫(서술 언급 0).
   남는 것 없음.
2. 군 기록 1비트(선택): `수거물 없음` — 기록체 1문장.
3. 귀환길 — 켜지는 불이 한 구역씩 늦다. 핵심 계통 유지·보조 구획
   손상·며칠 순환정전 안내(방송체).
4. **훅(고정):** 공개주파수 순환정전표 낭독 — 구역 이름들 사이에
   **청해남초등학교**와 **구래동**. 반응 해설 0. 끝.
