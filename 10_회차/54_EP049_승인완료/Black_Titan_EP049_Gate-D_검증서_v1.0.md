## 2. 잠금 이행

- [x] **귀환 = 역순의 물성:** 무릎→허리→가슴. `나올 때는 이걸
      잃으면서 나왔다. 들어갈 때는 되찾으면서 들어갔다` /
      `그렇게 오래 걸린 일인데 자리에는 아무것도 안 남는다`
- [x] **`네 덕분이야` 3요소:** 머리를 두어 번 두드림 + **수아의
      모름**(지형도는 어제 것·교신 미참여·물때는 표를 옮긴 것) +
      **묻지 않음**(`물어보면 언니가 대답해야 한다`)
- [x] **가드 ①: 놀이터가 말로 나오지 않음.** 회상 재현·요약·암시 0
- [x] **가드 ②: 수아가 캐묻지 않음.** 알아내려는 관찰 0.
      `언니는 아무 데나 고맙다고 하는 사람이 아니었다`까지
- [x] **가드 ③(촬영):** 내부망 게시판 영상 — 화질 나쁘고 소리 없음,
      `검은 덩어리 하나와 낮고 넓은 덩어리 하나가 회색 벌판에서
      붙었다 떨어졌다`. **조종석·조종자 0·추적 0.** EP9 계보 회수
      (드론·게시판 사진)와 EP47 `통제선 바깥` 회수(중계차)
- [x] **해석이 갈림:** 이겼다 / 죽는 줄 알았다 / 몸부림이다 /
      `안에 사람이 있긴 해?`. **다 같은 걸 봤는데 말이 다르다**
- [x] **균열 ③:** `할 수 있는 말이 없어서가 아니라, 하면 안 되는
      말밖에 없어서였다` / `화면 속의 그것은 느리고 둔하고 자주
      미끄러졌다. 안에서 겪을 때는 하나도 느리지 않았는데`
- [x] **발바닥 이물 처리**(EP46 미지불 회수) — 콘크리트 덩어리 셋 +
      철근. `디딜 때마다 어긋났을 거다`
- [x] **가드 ④:** 팔 이야기 = `아프지는 않은데 이상했어` 층위.
      증상 어휘 0·장부 기재 0. **`안 아픈 게 늘 좋은 건 아니다`**
- [x] **가드 ⑤: 혜정 평온** — 급식·발표 순서 수다, 눈금 추가 0
