## 3. ★★★★★★ 첨삭 — 정본 위반 4종

**오늘 한 회차에서 성격이 다른 위반이 네 번 나왔고, 검사기는 하나도 못 잡았다.**

### 3-1. 조종 원리 — **문체 카드 §2-9 위반**

| 초고(폐기) | 정정 |
| --- | --- |
| `자기 팔이 올라갔다. / 저쪽은 안 왔다.` | **`자기 팔을 올리려 생각하면 기계가 신호를 받아서 움직인다. 그렇게 알고 있었다.`** |
| — | **`팔을 직접 움직여 봤다.`** ← 별도 확인 행동 |
| `세 번 다 자기 팔만 올라갔다.` | **`세 번 다 안 올라갔다.`** |
| `오른팔을 올렸다. / 자기 팔이 올라갔다.` | **`오른팔을 올리기로 했다. / 신호가 갈 터였다.`** |

**★★★ 전신 모션 복제로 썼다.** 문체 카드 §2-9와 LOC-01 §4.4 정면 위반.
**Level 6에 §2-8·§2-9를 안 넣어서 아무도 못 잡았다.**

**★★★★★ 정정 효과:** 「직접 움직여 봤다」가 확인 행동이 되면서
**「몸은 멀쩡한데 신호만 안 간다」**가 정확해졌고, EP001의 「마음먹은 대로 움직인다더니」와 한 계보에 섰다.

### 3-2. ★★★★★★ LOC-01 미대조 — 최대 위반

**사용자 지적: 「조종석은 loc에 있음」**

| 정본(LOC-01 v0.1) | 초고(폐기) |
| --- | --- |
| 진입 해치 = **기체 좌측 · 둥근 · 안쪽으로 열림** | 등판 잘린 자리 |
| **어깨·허리 고정띠** · 착석등 노랑→초록 | 「맬 게 없어서 그냥 앉아 있었다」 |
| **덮개형 기동 스위치를 왼손으로** | 「앉으니까 켜졌다」 |
| **파노라마 화면 하나**(측면 연결) | 「화면이 하나 더 켜졌다」 |
| 쌍조종간 = 자세 안정용 | 없음 |

**★★★★★★ 「앉으니까 켜졌다」 → 「덮개를 젖히고 그 아래를 눌렀다」로 바뀌면서 더 좋아졌다.**
**스위치는 누구나 누를 수 있는데 이 아이가 눌러야 켜진다.**

> 왼손이 갔다. / 덮개를 젖히고 그 아래를 눌렀다.
> **눌러 본 지 마흔이틀이었는데 손이 자리를 안 찾았다. 처음부터 알고 갔다.**

**★★★ 그리고 등판 잘린 자리는 보기만 하고 지나가게 됐다** —
`두 번 봤는데 두 번 다 밖에서 봤다`가 그대로 서고, **오늘은 다른 데로 들어간다.**

### 3-3. ★★★★★ 통로 — **사용자가 정본을 정정했다**

> **「52m의 흉부 중심까지 들어가려면 거리가 좀 있는 묘사가 맞는것같아서」**

**LOC-01 §3.2의 「해치 안에는 한 사람이 간신히 지나는 짧은 통로」가 물리를 못 담는다.**

**★★★★★★ 확정 — 두 구간이다:**

| 구간 | 근거 |
| --- | --- |
| **좌측 해치 → 격벽 → 흉부 중심** | **★ 물리**(52미터 · 사용자 판정) |
| **짧은 금속 발판 두어 장 → 좌석** | **EP002 지면**(어깨를 움츠린 채 금속 발판을 건너) |

**★★ EP002 재독으로 정합점을 찾았다** — 「**통로 끝에** 작은 해치」(해치 바깥)와
「금속 발판을 건너 좌석까지」(해치 안쪽 마지막)는 **다른 구간**이었다.

**→ LOC-01 v0.2 개정 대상**(Gate E).

### 3-4. 수면학습 정합

> **「순서는 수면학습으로 주입시켜놓아서 종이는 필요없음」**

`할아버지가 붙인 순서 종이`를 만들었다 — **창작이다.** 대체:

> **배운 기억이 없는데 손이 아는 것들이 여기 많았다.** 이름을 아는 게 몇 개 안 되는데
> 손이 가는 데는 다 안다. / 봄에 처음 앉았을 때부터 그랬다. **그게 이상하다는 생각은 나중에 했다.**

### 3-5. 물리 2건

| 초고 | 정정 |
| --- | --- |
| 해치가 `저 혼자 조금 더 열려 있었다` | **`미는 데 힘이 들었다`** — 안쪽으로 여는 문이 기울면 중력이 닫는 쪽 |
| `등이 조금 뒤로 눌렸다` | **`몸이 조금 앞으로 쏠렸다`** — 무릎 꿇으면 상체가 앞으로 숙는다 |

### 3-6. ★★★★★★ 브리프 단계 정정 — 인식 도달점

> **「기계가 아니라는걸 알았다고 묘사한 적이 없어서 그대로 쓰기는 걸리네」**

브리프에 **인물의 도달점을 앞당겨** 넣었다. 전량 폐기하고 원인 둘로 재설계.

**★★★ 사용자 관측:** 「원래 계획대로라면 이 쯤에는 거기까지 도달했어야했는데 **계획보다 늦기는 했음**」
→ **도달 지점 미정 · 미결과제 등재.**
