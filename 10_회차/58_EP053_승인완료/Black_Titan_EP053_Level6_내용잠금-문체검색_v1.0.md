### ⚠ 가드 ①(이어 붙인다 — 요약 금지)

- **EP52 마지막 자세에서 그대로 시작한다.** 두 걸음 밀린 자리,
  같은 밤, 같은 상대
- **금지:** 상황 재설명 / 전장 재소개 / 개체 외형 재묘사 /
  `~였다` 회상 요약. 독자는 방금 읽었다
- 허용: 밀리는 중이라는 **현재 감각**만

### ⚠ 가드 ②(조립 — 확신은 나중에 온다)

**순서를 지킨다. 건너뛰면 단아가 아니라 수아가 된다.**

1. **또 그 소리가 난다** — 한 번은 넘겼는데 두 번은 안 넘어간다
2. **거슬리는 단계**(알아챈 게 아니다). `지금 그럴 때가 아닌데`
3. **뭔가 걸린다.** 뭐였는지 모르겠다
4. 더듬는다 — **한 번에 안 온다**
5. 온다: **어제 그 종이에 진하게 그어진 줄.** `물 빠지는 데.`
6. **확신 0.** 저 아래가 정말 비었는지도, 비었다고 빠질지도 모른다

- **영진에게는 반쯤만**(§6-②). `여기 아래가 이상해` 정도

### ⚠ 가드 ②-B(영진 — 답은 안 주되 도움은 준다 · 2026-08-13 사용자 지적)

**답을 모르는 것과 도움이 안 되는 것은 다르다.**
`교신은 시각·경고만`으로 좁게 잡았더니 **아무것도 안 해 주는 어른**이
됐다. 영진은 답을 모를 뿐이고, **일하는 법은 아는 사람**이다.

| 층 | 영진이 하는 일 | 예 |
| --- | --- | --- |
| **관측** | 화면으로 위에서 본다. **조종석은 앞만 본다** | 왼쪽이 내려앉는 것을 **먼저 본다** |
| **지형** | 최악이 아니라는 확인(**답은 아님**) | `왼쪽은 수문에서 멀다. 계속 가라.` |
| **몸** | 정비하는 사람의 조언 — 기술이 아니라 **몸 쓰는 법** | `어깨를 붙이고 허리로 받아라` |
| **절차** | 확인할 수 없을 때 **어떻게 할지** | `지나가면 한 번이고 밟으면 두 번이다` |
| **사후** | 위로가 아니라 **아는 사람의 사실** | `물은 다시 빼면 된다.` |

- **여전히 금지:** 답을 알려 주기 / 판단을 대신하기 / 해설
- **`네 발이 도면이다`** — 모르는 이유(`여기 도면은 나한테 없다`)를
  대고 나서 **단아 쪽으로 권한을 넘긴다.** 이것이 이 인물의 방식이다
- **금지:** 즉각 깨달음 / 논리 정리 / 확신 선언 / 매끈한 전술 산문

### ⚠ 가드 ③(유인 — 지는 걸 계속한다)

- **흘릴 수 없으면 같이 간다.** EP48 흘리기 실패(EP52)의 뒤집음 —
  실패한 기술이 버려지지 않고 **방향을 바꿔** 쓰인다
- 밀리는 것을 **멈추지 않는다.** 발을 옮기며 **밀리는 선만** 튼다
- **저것은 방향이 바뀌는 걸 모른다.** 앞만 밀면 되니까
- **★ 대가:** 유인하는 동안 **수문과의 거리가 더 줄어든다.**
  이득만 있는 선택으로 쓰지 않는다

### ⚠ 가드 ④(노동 — 계산 금지)

- **자기 발로 상판을 깬다.** 저것이 올 자리를 밟고 또 밟는다
- **좁게 딛는 것이 여기서는 이점이다** — 하중이 한 점에 모인다.
  **넓게 깔린 저것은 못 하는 일.** EP52에서 그를 지게 만든
  **바로 그 성질**이다
- **몇 번 밟았는지 세지 않는다.** 세면 계산이 되고,
  **계산은 수아의 문법**이다
- 균열 ③이 여기 붙는다: **무섭고 지겹다.** 맞는지도 모르는 채로
  발만 구르고 있다
- **금지:** 횟수·시간 계량 / 효율 판단 / 성공 예감

### ⚠ 가드 ⑤(붕괴 — 단계적으로)

**한꺼번에 꺼지면 우연처럼 보인다.**

| 단계 | 내용 |
| --- | --- |
| ⓐ | **한쪽이 먼저 내려앉는다** |
| ⓑ | **저것은 모르고 계속 민다** |
| ⓒ | **미는 힘이 자기를 더 밀어 넣는다** |
| ⓓ | 폭이 넓으니 **통째로** 간다 |
| ⓔ | **낮은 무게중심 = 기어 나올 자세가 안 나온다** |

- **적의 강점이 그대로 패인**임이 **순서로** 보여야 한다
- **결착 = 한 번.** 기울면서 드러난 **바닥에 붙어 있던 면**은
  껍질이 아니다.
  ※ EP45(부서질 때까지 두들김)와 **대비**로 읽히되,
  **기술을 익혀서가 아니라 지형이 만들어 준 자리**임이 분명해야 한다.
  격투 성장으로 읽히면 안 된다

### ⚠ 가드 ⑥(대가와 값)

- **대가 = 물이 안 빠진다.** 배수로가 무너져 물이 고인다.
  전조등에 비친 **수면이 아까보다 넓다.** 해설 0 —
  생활로 돌아오는 것은 EP54
- **★ 값 = 말이 없다.** `네 덕분이야`(EP49) **재사용 금지**

| | EP49 | **EP53** |
| --- | --- | --- |
| 방식 | **말로** 준다 | **말이 없다** |
| 수아 | **모른다** | **안다** |

  - 단아가 **종이에 표시를 해서 돌려준다**(현장에서 확인한 것을
    그 줄 옆에 적거나 그린다)
  - **수아의 종이에 단아의 필적이 처음 들어가는 자리**
  - **수아의 반응도 말이 아니다** — 보고, 접어서 둔다
  - **금지:** 고맙다는 말 / 수아의 자각 언어화 / 설명

### ⚠ 가드 ⑦(승계)

- **화계:** 단아→영진 **반말**(교신 포함) / 수아→단아 반말
- **시점 지칭:** 서술문에서 영진은 **`할아버지`**
- **전투 톤:** **균열 3회**(거슬림 / 틀리면 지는 거다 / 무섭고 지겹다)
- **전투 화 리듬:** 혼잣말·소리 묘사 **초고부터**. 대화 **13%+**
- **물리량 전달:** 피해 0이어도 밀림·자세 붕괴·조종석 진동
- **영진 한 손** / **수아 전투 교신 0**(귀환 후 한 컷만)
- **작가용 개체 명칭 0** — 지면 지칭은 `누르는 놈`·`넓적한 것`

- **금지:** 앵커·클로·로켓 / 반입구 / 센티널·루시 / 새 증상 /
  `개수`·`화` / EP45·EP48·EP52 문장 재사용 / EP10 발파 장면 재현

## 4. 장면별 잠금

### Scene 1 — 또 그 소리

- **고정:** 이어 붙이기(가드 ①) / 또 밀림 / 또 깨짐 / **또 그 소리** /
  `여기 아래가 비었나`
- **균열 ①:** 알아챔이 아니라 **거슬림.** 지금 그럴 때가 아닌데
- **금지:** 상황 요약 / 즉각 깨달음

### Scene 2 — 겹친다

- **고정:** 가드 ② 6단계 순서 그대로 / 영진에게 **반쯤만** /
  **확신 0**
- **균열 ②:** 틀리면 그냥 지는 거다. **그런데 지금도 지고 있다**
- **금지:** 논리 정리 / **영진이 답을 주기**
  ※ 절차·권한 이양은 허용(가드 ②-B) — `네 발이 도면이다`

### Scene 3 — 같이 간다

- **고정:** 밀리는 걸 멈추지 않는다 / **선만 튼다** / 저것은 모른다 /
  **수문과의 거리가 더 줄어든다**
- **§6-6 첫 노출:** **밀리면서 방향을 트는 운용**
- **금지:** 반격 / 우세 전환 / 흘리기 재시도

### Scene 4 — 밟는다

- **고정:** 저것이 올 자리를 **밟고 또 밟는다** / **좁은 접지가
  이점** / **횟수 0** / 시간 감각 없음
- **균열 ③:** 무섭고 지겹다
- **금지:** 계량 / 효율 / 성공 예감 / 정비 척도 어휘 전용
  (여기는 **전투 중의 노동**이다)

### Scene 5 — 꺼진다

- **고정:** 가드 ⑤ ⓐ~ⓔ **순서대로** / **결착 한 번** /
  바닥에 붙어 있던 면 = 껍질이 아님
- **금지:** 기술 습득으로 읽히는 서술 / EP45·EP40 결착 재현 /
  환호·승리 선언

### Scene 6 — 남은 것

- **고정:** **넓어진 수면**(해설 0) / 새벽 귀환 /
  **종이에 표시해서 돌려주기**(말 0·수아 반응도 말 0) /
  훅 = 영진의 장부 **`버틸 것이 없다.`**
- **금지:** `네 덕분이야` 계열 / 수아의 자각 언어화 / 정리 서술
