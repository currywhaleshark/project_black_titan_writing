## 2. 회차 전체 리듬

```text
어둠: 남은 감각으로 세계를 다시 세우는 셈
→ 오답의 실행: 왼팔이 풀린다 — 통했다
→ 반 박자 뒤: 주먹이 닿기 전에 팔꿈치와 목
→ 힘으로 풀수록: 나뉜 견인력이 자세를 찢는다 — 방재벽이 등을 지나간다
→ 정비실: 검은 사각형들과 꺼내 둔 밀봉재
→ 물: 노면을 잃는 발바닥 — 틀려 가는 셈
→ 훅: 지면 표시가 사라진 수평계, 늘어나는 수심
```

- 문체 축은 **셈**이다 — EP20이 끝낸 감각 재고를 이어받아, 맞던 셈이
  하나씩 어긋나는 과정을 감각 정보의 불일치로만 쓴다(패배 해설 0).
- 시점: S1·S2·S4·S5 단아 밀착(**시각 서술 0** — §6-①) / S3 정비실
  (수아 밀착 + 영진, 군 반 컷).
- 씬 밴드: S1 1,000~1,300 / S2 1,600~1,900 / S3 1,100~1,400 /
  S4 900~1,200 / S5 400~700 (목표 5,800)
- 리듬: S1 느린 재고 → S2 성공의 가속과 급정지, 감기는 단문 누적 →
  S3 손의 서술(정적) → S4 어긋나는 셈의 반복 → S5 계기의 정지.

## 3. 장면별 문단 비트 잠금

### Scene 1 — 어둠 속의 셈 (1,000~1,300자)

1. 소등 직후 연속 — 비상등 주황. **감각 재고 가동(EP20 말미 이어받기,
   문장 재사용 0):** 발바닥 노면·허리 압박·무릎 묶임·스피커. 시각
   서술 0의 개시 — 어둠을 묘사하지 않고 **남은 것만** 서술.
2. **영진 무전 실무(잠금):** 짧은 확인 문답 2~3행 — 위치·기울기 계열
   (`발바닥 뭐 밟고 있냐` 계열의 실무 언어). 개체 해설 0.
3. **오답 확신의 재확인(잠금):** `몸에 넷, 땅에 넷. 하나씩.` —
   왼팔부터. 확신의 근거 1줄 상한(봄 내내 힘으로 안 풀린 게 없었다는
   관성 — 합리로 읽히게, §6-②). 씬 마감: 왼팔의 촉수를 잡는다.

### Scene 2 — 힘으로 풀수록 (1,600~1,900자) ※ 이 화의 심장

1. **왼팔 해방(성공 미끼 — 잠금):** 힘으로 벗겨 낸다 — 늘어나다가,
   벗겨진다. 통했다는 반 박자(확신의 정점 — 짧게). 몸통을 향해
   나가는 왼팔.
2. **재포박(잠금):** 주먹이 닿기 전에 — 풀린 촉수가 팔꿈치를, 다른
   팔이 목을 감는다. **공격이 아니라 복구**의 행동(의도 해설 0,
   순서의 물리만). 목을 감는 감각은 압박 계열 상한(조임 공포 과장 0,
   질식 서술 0).
3. **분산 견인의 함정(잠금):** 뒤로 버티며 힘을 쓸수록 — 옹벽·방재벽·
   철골에 나뉜 견인력이 서로 다른 각도에서 온다. 버티는 다리가 상대할
   방향이 매번 틀리는 결(§5 — 속도 없는 소모전). 자세가 무너지는
   과정 2~3비트.
4. **한 대도 못 때린 채(잠금):** 방재벽이 등을 지나간다 — 감각으로만
   (등 뒤의 하중이 사라지는 결). 두 달 만에 처음으로 밀려나는 쪽.
   FS-004 가드: 관통·꿰뚫 0, 감김·조임·당김 계열만.
5. 씬 마감(잠금): 발바닥의 정보가 바뀐다 — 마른 노면에서 물에 잠긴
   바닥으로. 수몰 구도심의 시작(지명 서술은 물성으로 — 잠긴 도로·
   잠긴 골조 계열).

### Scene 3 — 정비실 (1,100~1,400자) ※ 수아 첫 실전 합류(비전투 잠금)

1. 정비실 — **검은 사각형들**(끊긴 외부 화면)과 공개 재난방송(피난
   행렬 위치·위험구역만)을 번갈아 보는 수아. 이 화 유일의 시각 정보
   구역(§6-①). B3 상한: 관찰과 준비만.
2. **수아의 손(잠금):** 예비전원 확인, 밀봉재를 꺼내 두기 — `언니가
   돌아올 때 필요한 것`의 목록을 손으로 만드는 서술(발화 최소 0~2
   문장 — 전술·위치 어휘 0). EP17 옮겨 적기의 리듬 계승(문장 0).
3. **영진의 감지(상한 문면 — §6-④):** 팔의 움직임 설명 0. 무전
   너머의 양상에서 — `부수려는 놈이 아니야. ……모르겠다, 뭐가
   다른지.` 계열 반 문장(느낌+무지. `데려가려 한다` 0).
4. **군 반 컷(잠금):** 상황실 — 대피 완료 집계에 집중. 수중전 지휘 0.
   `구조 수단 없음` 계열의 건조한 확인 1~2행(기록명 `다완 흡착체`
   사용 가능). 경상자 신원 미등재 유지(B4 — 집계 숫자 언급도 0).

### Scene 4 — 운반 (900~1,200자)

1. 물이 깊어지는 과정 — 발바닥이 노면을 잃어 간다(끌리는 것 →
   뜨는 것). 견인 팔이 침수 구조물을 **갈아 잡는** 소리·진동(물속
   전달음 — G0-010 개체음 허용).
2. **틀려 가는 셈(잠금):** 남은 감각으로 방향·깊이를 세지만 기울기와
   물소리의 정보가 서로 어긋난다 — 맞던 셈이 안 맞는 최초의 경험
   (해설 0, 어긋남의 나열만).
3. **마지막 저항 1회(잠금):** 더 큰 힘으로 — 오답의 끝까지. 결과:
   목의 촉수가 자리를 고쳐 잡을 뿐. **`다른 방향` 계열 깨달음 0**
   (이 화는 오답 안에서 끝난다 — EP22 창구).
4. 씬 마감: 외벽을 두드리는 물소리의 변화 — 얕은 데서 깊은 데로.

### Scene 5 — 훅: 수심 (400~700자) ※ 조종석 밀착

1. 남은 계기의 재고 — 화면 전부 검고, 살아 있는 것은 숫자와 바늘뿐.
   (EP20 감각 재고 문장 재사용 0 — 이번엔 계기 쪽.)
2. **훅(개요 고정 — 잠금):** 수평계에서 **지면 표시가 사라진다.**
   발바닥이 알려 주던 것을 계기도 알려 주지 않는다. **수심 숫자만
   한 칸씩 늘어난다.** 끝(§6-5: 수심 수치는 자릿수 억제 — `한 칸씩`
   계열 우선, 구체 숫자 상한 1회).
