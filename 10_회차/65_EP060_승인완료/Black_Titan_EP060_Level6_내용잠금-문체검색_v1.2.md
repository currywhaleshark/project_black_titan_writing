## 1. 이 화의 형태

**같은 교전을 이어받는다.** 시간 경과 0, 격납고 복귀 0, 회상 도입 0.

그리고 **쫓기를 그만두는 것이 답**이다. 빠른 쪽이 돌아가고 느린 쪽이 질러간다.

## 3. 가드

### ⚠ ①(이어받기 — 첫 문장이 뛰는 중)

- **시간 경과 0 · 격납고 복귀 0 · 회상 도입 0 · 상황 요약 0**
- `어제는…`·`그날 아침…` 류가 붙으면 EP59를 끊어 놓은 의미가 없어진다
- 진입 상태(SNAP-059 `engagement_open`): 거리 벌어짐 / **사슬 반쯤 나간 채 닻을 끄는 중** / 자국 = 어깨·허리·왼쪽 종아리 / 통 밴드 덜 조여짐

### ⚠ ②(빠른 쪽이 돌아가고 느린 쪽이 질러간다)

- 저것은 **얕은 선을 잇는다** — 구불구불하게
- 이쪽은 **깊은 데를 가로지른다** — 느리지만 직선
- **금지:** 저것이 왜 얕은 데를 타는지 **인물이 원리로 설명하기**(관찰만) / 속도 비교 수치

### ⚠ ③(EP30 자료 회수 · 영진은 지형만)

- **★ 보낸 게 아니라 뿌린 것이다(사용자 확정 2026-08-14).** 받는 사람이
  정해져 있지 않았고 **영진은 받아서 갖고 있었을 뿐**이다.
  EP57 정본 표현과 같은 계열 — **`어딘가의 거인에게 보라는 듯 정보만
  뿌렸다`**. `지원하되 관여하지 않는다`의 정확한 형태가 이것이다
- **★ 계보 정정(2026-08-14 확인):**
  - **최초 살포 = EP30 · 5월 12일**(「폐허 아래의 관」 · 개체는
    **관망 매복 개체**. **성게형 아님**)
  - **정례화 = EP33** — `거인이 자기들 자료를 쓴다는 걸 눈치챘는지,
    요즘 군은 **매번 자료를 뿌려댔다**`
  - EP60까지 **약 6주**(한 달 반). **넉 달도 3개월도 아니다**
- **★ 그래서 `오랜만에 꺼내 쓴다`가 아니다.** 계속 쓰고 있었다.
  **오늘 특별한 건 자료가 아니라 그걸로 목을 짚었다는 것**이다 —
  늘 보던 걸 **처음 그 용도로** 본다
- **★ EP33의 관계가 그대로 유지된다:** 저쪽은 이쪽이 쓴다는 걸 알고
  뿌리고, 이쪽은 받아 쓰면서 아무 말 안 한다. **서로 아는 채로 말이
  없다.** 그리고 **뿌린 쪽은 오늘 그게 어디에 쓰였는지 모른다**
- **금지:** 군이 영진에게 **줬다**는 뉘앙스 / 수신인·전달 관계 암시 /
  고마움·감격 / **`넉 달 만에`류 시간 과장** / 자료를 꺼내는 동작에
  무게 싣기(평소 보던 것이다)
- 영진의 몫: **얕은 데·깊은 데·건물 위치·저것이 타는 선.** 거기까지다
- **★ 질러가겠다는 결정은 단아가 한다**(§2-B — 메카닉이지 전략가가 아니다)
- **금지:** 영진의 작전 지시 / `저기로 가라` / 자료의 출처를 감격스럽게 다루기

### ⚠ ④(질러가는 대가)

- 느리고, 발밑이 안 보이고, 잔해에 걸리고, **닻이 물속을 끌린다**
- **거리 숫자가 줄지 않는다**
- 도착했을 때 **이미 오고 있는 게 보이는** 정도로 아슬아슬해야 한다
- **금지:** 여유 있는 도착 / 준비 완료 후 대기

### ⚠ ⑤(코칭 — 한 마디)

- **정본 문면(v2.2 §4-2):** **`무기를 쏜다고 생각하지 마라. 왼팔이 길어진다고 생각해`**
- **부연 0 · 비유 해설 0 · 반복 0**
- 앞에 **두 번 빗나가야** 한다(겨누려고 했기 때문)
- 그다음: **겨누기를 그만둔다** → 어디를 맞힐지가 아니라 **손이 갈 데를 본다** → **박힌다**
- **★ 성공한 이유를 아무도 말로 정리하지 않는다.** EP58에서 원인을 말로 안 만든 것과 짝이다
- **금지:** 환호 / 요령 정리 / `그거였구나` 류

### ⚠ ⑥(고무줄 — 서술 기법까지 잠금)

- **실제 1~2초.** 줄다리기가 아니다
- **늘어나는 구간:** 감각을 **하나씩 짧은 문장으로** 쌓는다 — 발이 밀리고, 팔이 뻗어지고, 몸이 앞으로 기울고. 시간을 늘려 쓰되 문장은 짧게
- **반전은 한 문장**으로 끊는다
- **직후에 `짧았다`를 놓는다** — 체감과 실제의 낙차
- **★ EP50 회수:** 아흐레 동안 **오래** 버티는 걸 했는데 실제로 쓴 건 **한순간**이다. **인과를 문장으로 정리하지 않는다** — `팔이 안 떨렸다`까지
- **금지:** 길게 끄는 힘겨루기 / 이 악물기 / 회상 삽입

### ⚠ ⑦(세 부족함이 한 동작에 — 세지 않는다)

- 사출(**거리**) → 박고 버티기(**지지**) → 걸고 당기기(**인장**)가 순서대로 쓰인다
- **★ `세 개가 하나가 됐다` 류 정리 문장 0.** 독자가 잇는다
- **금지:** 봄·저번 실패의 나열 회상 / 사다리 요약

### ⚠ ⑧(격파는 짧게)

- 산은 **멈추게 만드는 데까지**다
- **처음으로 멈춰 있다** → 멈추면 지는 걸 저것도 알았다 → 멈춘 뒤는 **맨손으로 된다**
- 어떻게 끝내는지 길게 안 쓴다. **사체는 물에 닿으면 붉게 풀린다**(EP5 정본)
- **금지:** 통쾌함 / 복수 / 승리 선언 / 저것의 마지막 반격

### ⚠ ⑨(이겼는데 안 웃는다)

- 끝났는데 **아무 느낌이 없다**
- 사슬을 감으면서 왼팔을 본다
- **★ 팔이 하나 더 생긴 게 아니라 팔이 길어진 것.** 저기 박힌 게 **내 손끝**이었다는 감각이 안 지워진다
- **무섭지도 좋지도 않고 낯설다**
- 영진의 말은 짧다. **축하 아님**
- **금지:** 위로 / 정리 / 성장 선언 / 다음 각오 — 여기서 정리하면 **EP61의 명명이 가벼워진다**

### ⚠ ⑩(승계)

- **화계:** 단아→영진 반말(교신 포함) / 수아 등장 시 존댓말(영진)·반말(단아)
- **시점 지칭:** 서술문에서 영진은 **`할아버지`**
- **명명 게이트:** `그것`·`닻`·`사슬`·`통`·`등판`. **`앵커` 0**(EP61) / `로켓`·`추진`·`점화`·`노즐`·`사출기` 0
- **등각류 지칭:** `빠른 놈`·`작은 것`. **작가용 명칭 0**
- **질량 있는 속도 유지:** 지나가면 뒤늦은 파도 / 꺾으면 물이 벽처럼 서고 바닥이 파임
- **균열 2~3회** / 새 증상 0 / 영진 한 손·안경 0 / 반입구 0 / 현서 0 / 목격 최소

## 5. 장면별 잠금

### Scene 1 — 그만 쫓는다 ※ 가드 ①②③ 집행

- **고정:** **뛰는 중으로 시작** → 저것이 곧게 안 가고 휘어 간다 → **영진이 자료를 편다**(늘 보던 것 · EP30~33 계보) → 얕은 선/깊은 데/건물 → **선들이 만나는 목** → **단아가 결정한다**
- **★ 자료를 꺼내는 데 무게를 안 싣는다.** 새로 얻은 게 아니라 **늘 있던 것**이고, 오늘 다른 건 **그걸 이동 경로 읽는 데 쓴다**는 것뿐이다
- **균열 ①:** 쫓는 걸 멈추는 게 무섭다
- **금지:** 회상 도입 / 상황 요약 / 영진의 지시 / 원리 설명

### Scene 2 — 깊은 데 ※ 가드 ④ 집행

- **고정:** 무릎 → 허벅지 → 허리 / **느려진다**(물속의 부하) / 발밑이 안 보인다 / 잔해에 한 번 크게 휘청 / **닻이 물속을 끌린다** / 거리 숫자가 안 준다
- **균열 ②:** 늦으면 이 짓이 다 헛것이다
- **금지:** 여유 / 결의

### Scene 3 — 목 ※ 전장

- **고정:** 물에서 나온다 → 건물 사이·**좁다** → 바닥이 **단단하다**(드러난 옛 도로) → 폭을 몸으로 잰다 → **이미 오고 있는 게 보인다**
- **금지:** 준비 완료 후 대기 / 지형 해설

### Scene 4 — 왼팔이 길어진다 ※ 가드 ⑤ 집행

- **고정:** 건너편 벽에 쏜다 → **두 번 빗나간다**(겨누려고 했다) → 감을 시간이 없는데 감아야 한다 → **코칭 한 마디** → **겨누기를 그만둔다** → **박힌다** → 팔로 짚은 것 같았다
- **금지:** 부연 / 환호 / 요령 정리 / `그거였구나`

### Scene 5 — 버틴다 ※ 가드 ⑥⑦ 집행

- **고정:** 사슬을 가로질러 놓고 **발을 박는다**(다리 높이) → 온다 → **좁아서 못 꺾는다** → **걸린다** → **늘어나는 구간**(발이 밀리고·팔이 뻗어지고·몸이 기울고 — 짧은 문장으로 쌓기) → **한계** → **뒤집힌다**(한 문장) → 다리 여럿이 걸려 통째로 넘어감 → 물이 벽처럼 서고 바닥이 파이는데 **이번엔 저것이 고른 게 아니다** → 건물에 처박힘 → **`짧았다`**
- **아흐레:** `팔이 안 떨렸다`까지. **정리 문장 0**
- **금지:** 힘겨루기 연장 / 이 악물기 / 사다리 요약

### Scene 6 — 멈췄다 ※ 가드 ⑧ 집행

- **고정:** **처음으로 멈춰 있다** → 멈추면 지는 걸 저것도 알았다 → **맨손으로 된다**(짧게) → **붉게 풀린다**
- **금지:** 통쾌함 / 복수 / 승리 선언 / 마지막 반격

### Scene 7 — 안 웃는다 ※ 가드 ⑨ 집행

- **고정:** 아무 느낌이 없다 → 사슬을 감는다 → **왼팔을 본다** → **저기 박힌 게 내 손끝이었다** → **낯설다** → 영진의 짧은 말(축하 아님)
- **끝:** **아직 이름이 없다**
- **금지:** 위로 / 정리 / 성장 선언 / 다음 각오
