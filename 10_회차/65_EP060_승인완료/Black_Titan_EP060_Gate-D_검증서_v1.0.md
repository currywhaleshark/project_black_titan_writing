## 5. 신설 정본

- **★ 덫의 물리:** 닻을 **한쪽 벽에 박고 기체가 반대편 기둥이 된다.** 사슬 이쪽 끝은 원래 팔에 붙어 있다 — `기둥이 둘 필요한데 하나밖에 없으면 나머지 하나를 자기가 하면 된다`
- **★ 고무줄:** 걸리고 뒤집힐 때까지가 **짧다.** 늘어나는 구간에 힘이 쌓이고 **한계에서 반전**된다. **체감과 실제가 안 맞는다**
- **★ 지형이 저것의 무기를 깎는다:** 다리로 밀어 가므로 **깊은 데를 못 쓰고**, 좁은 데서는 **꺾을 수가 없다.** 트인 데에서 무적이던 것이 좁은 데에서 무력해진다
- **★ 같은 성질의 다른 면(계보 추가):** 단단한 바닥이 EP59에서는 **저쪽 편**이었고 EP60에서는 **버틸 자리**가 된다. EP4 갯벌(하중 집중)·EP53(좁은 접지)과 같은 문법
- **★ 폐허에는 값이 안 남는다:** 고칠 사람이 없는 자리에서는 EP54 계열의 청구가 발생하지 않는다. **처음으로 부수고도 값이 안 나온 전투**
- **★ 신체이미지 수용:** **팔이 하나 더 생긴 게 아니라 팔이 길어졌다.** 걸렸을 때 당겨진 게 사슬이 아니라 팔이었고 **놓을 생각을 한 번도 안 했다.** 무섭지도 좋지도 않고 **낯설다**
- **★ 승리의 감각 3단:** 봄 첫 승리 = **손이 떨렸다** / 방재벽 = **허탈** / 오늘 = **아무것도 아니었고 그게 제일 이상했다**
- **소리의 정상화:** EP59 내내 저것의 소리는 늦게 왔다. **닻이 박히는 소리가 처음으로 제때 왔다** — 걸렸다는 증거
- **격언 계보:** `빠른데 돌아간다` / `지금 이쪽이 하고 있는 건 저것이 피한 일이었다` / `여기서는 못 움직인다. 저것도 못 움직인다` / **`도구는 겨눠서 쓴다 … 팔은 안 그런다`** / `붙어 있는 건 무겁다 … 팔이 무거우면 그냥 팔이 무거운 거다` / **`팔로 짚은 것 같았다`** / `기둥이 둘 필요한데 하나밖에 없으면 나머지 하나를 자기가 하면 된다` / **`짧았다`** / `달라진 건 저것도 이쪽도 아니고 서 있는 자리였다` / **`처음으로 부수고도 값이 안 나왔다`** / **`아무것도 아닌 게 제일 이상했다`**
