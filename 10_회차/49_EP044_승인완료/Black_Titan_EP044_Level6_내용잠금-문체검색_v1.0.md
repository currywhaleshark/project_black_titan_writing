### §1-B. 전장 구조 잠금 (사용자 2026-08-12 — 신설 절차)

**⚠ 상시 절차:** 전투 화는 **집필 전에 전장 구조를 먼저 확정**한다
(수심·엄폐물·시야·기동 여지·소모 자원). 구조가 정해져야 전술과
긴장이 따라온다.

- **수심 = 기체 허벅지 높이**(수중전 아님 — **상반신 전부가 물 위**).
  걸을 때마다 물이 허벅지에서 갈라지고, 밀릴 때 물보라가 인다
- **지형 = 수몰 구시가지 아파트 단지**(방재벽 외곽). **높이 정합
  필수(사용자 2026-08-12):** 기체 52m ≈ 아파트 17층. 엄폐가 되려면
  **물 위로 열몇 층이 남아 있어야 한다** — 아래 대여섯 층 침수 +
  상부 십몇~스물몇 층 노출. `삼층·사층` 계열 금지
- **엄폐 = 유한 자원(핵심):** 동 뒤로 붙으면 가려지지만 **오래
  버티지 못한다.** 작살 가시가 벽을 물고 **위층부터 뜯겨 나간다** →
  동이 사라지는 게 아니라 **낮아진다**(머리 위 → 어깨 → 가슴 →
  허리 → 못 가림). 남은 동의 수 = 남은 시간. 다음 동까지는
  **서너~네 걸음**(기체 보폭 기준)의 맨몸 구간
- **질량 정합(사용자 2026-08-12):** 52m 질량에 맞지 않는 동작 금지 —
  **구르기·몸 날리기·잽싼 회피** 불가. 대신 **벽을 손으로 밀며
  옆으로 빠지기, 어깨 틀기, 몸 낮추기, 무겁게 뛰기(물의 저항)**.
  회피는 빠름이 아니라 **각도와 엄폐**로 한다
- **시야 = 밤·전조등 + 도시 불빛**(방재벽 안쪽의 노란 띠가 배경).
  물 위라 궤적이 보임 — 오는 것이 보이는데 못 피하는 공포
- **기동 = 물의 저항**(뛰면 느리고 무겁다), 밀리면 발이 바닥을
  긁으며 물살에 실려 더 간다
- **적 위치 = 물 위로 반쯤 드러난 반구**(가시가 수면 위에서 발사)
- **금지:** 수중전 어휘(잠수·부유물·물속 어둠 계열), 도시 건물
  파괴의 민간 피해화(**수몰 구시가지 = 무인**), 방재벽 안쪽 진입
- **STYLE_ONLY:** C 문체 프로필·앵커, 말투카드 봄편 v0.4
- **금지:** 격파(EP45)·가시 조각 대조 결론(EP45)·`개수`·`성게형`
  (작가용)·역장 원리·수아 조언·군 개입·새 증상·저림/흐림·`초여름`
  (현재)·교복·**`화`(회차 단위)**·앵커 명명, EP30·35·38·43 문장
  재사용

## 2. 회차 전체 리듬 — 전투 화(여름 첫 실전)

```text
호출: 몸이 기억하는 순서 — 마른 입
→ 조우: 낯익은데 다르다 — 그리고 움직인다
→ 사격: 겨눈다 — 맞는다 — 버텼다 — 몇 번까지?
→ 한계: 붙으면 이기는데, 붙을 수가 없다
→ 훅: 쏘고, 쉬고, 쏘고 — 간격이 있다
```

- **전투 톤 최우선:** 균열 3(S1 마른 입 / S2 낯선 익숙함의 공포 /
  S3 `저건 나를 부수려고 왔다`). 쿨내 0
- **자신감 궤적:** 봄 최고점에서 출발 → **첫 동요**(무너짐 아님 —
  각오는 유지되고 셈만 흔들림). 여름의 하강은 여기서 첫 눈금
- **버팀의 불안(이 화의 신경):** 안도 → 불안의 반복 구조. 맞을
  때마다 안심이 아니라 **잔고가 줄어드는 감각**(횟수를 세는 몸)
- **삼분법:** 단아 = 몸으로 부딪히며 — 원리는 못 묻고(여유 0)
  횟수를 걱정하고, 마지막에 리듬을 몸으로 줍는다
- 씬 밴드: S1 900~1,200 / S2 1,100~1,400 / S3 1,300~1,600 /
  S4 1,100~1,400 / S5 700~1,000 (목표 5,800)
- 클리프행어 = 전투 지속(EP45 = 시간 경과 0)

## 3. 장면별 문단 비트 잠금

### Scene 1 — 호출 (900~1,200자) ※ 절차 재가동

1. 22:30 이후 — 영진의 호출(짧게: `내려와라` 계열·설명 최소).
   계단·불 켜지는 지하
2. **절차의 몸:** 체육복(EP43에서 개어 둔 것 — 회수)·조종석·레일
   대차·수밀격벽. **몇 주 만인데 순서가 다 있음**(잊으라 해도 못
   잊는 자리 — EP43 대구·문장 재사용 0). **수아 = 화면 앞 착석**
   (확인자 위치 — 발화 0~1 상한)
3. 균열 ①: 물이 차오르는 동안 **마른 입**(봄 계보). 각오와 두려움이
   같이 있는 상태 — `온다면 받아 준다`의 이행

### Scene 2 — 낯익은 것 (1,100~1,400자) ※ 조우·위화감

1. 방재벽 밖 수몰 구시가지 — 허벅지 물을 가르며 전진. 솟은 건물들
   사이, 전조등 끝에 **물 위로 반쯤 드러난 반구**(흑색·따개비 질감·
   녹색 점광). **낯익음의 확인**
2. **§6-6 첫 노출(위화감·잠금):** 가시가 다르다 — **배열이 고르게
   정리됨·뿌리가 두꺼움·끝이 작살처럼 벌어짐**(관찰 층위·해설 0·
   `개수` 금지). 단아 = 말로는 못 짚고 몸이 먼저 이상해함
3. **움직인다(대비 축):** 봄의 그것은 붙박이였다 — 이건 자리를
   옮기고 각도를 튼다. 균열 ②: **익숙한 얼굴이 낯설게 구는 공포**
4. 접근 개시 — 봄의 승리 공식(붙어서 부수기)대로. 아직은 아는
   싸움이라고 생각하는 채로

### Scene 3 — 쏜다 (1,300~1,600자) ※ 심장

1. **첫 발:** 접근 중 — 가시 하나가 곧추서고 **쏜다.** 봄에 없던
   동작(잡기·조이기·끌기가 아니라 **발사**). 오는 것이 보이는 반
   박자
2. **첫 피격(가드 ② 집행 — 충격 필수):** 어깨께 명중 — **몸이
   반 걸음 밀리고**, 디딘 발이 바닥을 긁고, **조종석이 통째로
   흔들리고**, 등받이가 등을 친다. 불꽃 같은 것이 일고 물보라가
   터진다. **뚫리지는 않았다.** ※ **여기까지가 단아가 아는 전부**
   (원리 0). 아프지 않은데 온몸이 흔들리는 감각의 이상함(맞은
   자리는 멀쩡한데 몸이 밀려 있는 어긋남)
3. **안도 → 불안(최상위 가드 집행):** `버텼다`의 반 박자 → 곧바로
   **`몇 번까지 버티지?`** — 계기 확인 반 박자·다음 발이 같으리란
   보장 0. **`안 통한다` 계열 서술 금지**
4. **의도의 공포(잠금):** 버텼다는 사실보다 **겨누고 쐈다는 사실.**
   봄의 것들은 회수하려 했고 이건 부수려 한다 — 균열 ③: **`저건
   나를 부수려고 왔다`**(속말)
5. **연사 개시:** 하나가 아니라 여럿·간격을 두고 계속. 물속이 가시로
   그어지는 그림. **맞을 때마다 밀린다**(전진분이 깎이는 물성 —
   가드 ②). 그리고 맞을 때마다 **잔고가 줄어드는 감각**(횟수를 세는
   몸 — 안심 0)

### Scene 4 — 닿지 않는 주먹 (1,100~1,400자) ※ 맨손의 한계

1. 접근 시도 — 다가가면 **거리를 벌리며 쏜다.** 붙으면 이기는데
   붙을 수가 없다(봄 공식의 무력화). **이유 두 겹(가드 ②):** ①
   저쪽이 물러난다 ② **맞으면 이쪽이 밀린다** — 세 걸음 가고 한
   걸음 밀리는 산수
2. **건물 엄폐 전진(유한 자원 집행):** 벽 뒤에 붙으면 가려진다 —
   그러나 몇 발이면 벽이 뜯기고 무너진다. **건물이 하나씩 줄어드는
   시계**(다음 건물까지 맨몸 구간). 저쪽은 값을 안 내고 이쪽만 낸다
   (EP35 계보·문장 재사용 0)
3. **교신(상한):** 영진 1~2회(상태 확인·`무리하지 마라` 계열 —
   전술 지시 0). **수아 = 무언 반 컷**(화면 앞 손 — 조언 0)
4. **숙제의 각인:** 팔이 남는데 쓸 데가 없다 — **손이 닿는 데까지
   가는 것이 오늘의 전부**(앵커 명명 0·필요성의 감각만)

### Scene 5 — 훅: 간격 (700~1,000자) ※ 개요 고정

1. 소모 국면의 호흡 — 맞고, 밀리고, 다시 붙고
2. **리듬의 발견(훅 잠금):** 연사 속에서 무언가가 들리기 시작 —
   쏘고, 쉬고, 쏘고. **간격이 있다.** 길이를 세기 시작하는 몸
   (**깨달음 상한 = `간격이 있다`까지** — 활용·격파는 EP45)
3. 끝: 가시가 그은 물속에서 접근 각을 재기 시작(전투 미종결·
   EP45 = 시간 경과 0)
