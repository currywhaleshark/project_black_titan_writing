## 3. 브리프 밖에서 들어간 것 (Gate D 승인)

1. 수아가 믿음을 처음 소리 내어 말한다 — `뒤에서 들어온 게 저를 지나갔어요. 그래서 제가 다쳐서 타이탄이 선 거죠?`
2. 왜 깊이 이어졌나 — `처음부터 잘 맞았어요.` / `타이탄은 너한테 따로 맞출 게 없었어.`(6-7 정본)
3. **`언니도 알아요?` `아니.` / `언니한테 말해도 돼요?` `네가 정해.`** → 신규 SUA-TELL-DANA
4. 마감 셈 — 이름 하나 · 모르는 것 하나 · 정할 것 하나
