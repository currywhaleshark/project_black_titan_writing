## 2. 회차 전체 리듬 — 전환 화(평온 → 대비)

```text
토요일: 파형 둘, 셋 — 겹치는 페이지
→ 저녁: 돌려 말하지 않기 — 말없이 올라오는 통
→ 월요일: 익숙해진 교실 — 또 시작인가 보네
→ 방과후: 각자의 준비 — 얼룩진 어깨
→ 밤: 실루엣 — 멈추지 않는다
```

- **전환 화 문법:** 긴장의 점층 — 단 공포 재탕이 아니라 **재가동의
  물성**(봄에 만든 절차들이 하나씩 깨어나는 그림: 장부 대조·가족
  공유·통제 통지·규칙 문자·몸 만들기)
- **이중 무언(S2 심장):** 영진 상한 문면 → 수아의 통 → 영진의 반
  박자. 정체는 아무도 입에 올리지 않는데 전원이 아는 상태의 서술
  (독자 포함 — 명언 없이 전모가 전달되는 구조)
- **혜정 반의식(S3~4):** 행동·문자만. 심리 서술 0 — `또 시작인가
  보네`가 무엇의 시작인지 혜정이 스스로 묻지 않는 것까지가 반의식
- 씬 밴드: S1 1,000~1,300 / S2 1,100~1,400 / S3 1,100~1,400 /
  S4 900~1,200 / S5 700~1,000 (목표 5,500)

## 3. 장면별 문단 비트 잠금

### Scene 1 — 주말의 대조 (1,000~1,300자) ※ 영진

1. 토요일 오전 — **파형 2건째.** 봄 장부와 여름 화면을 나란히 놓는
   대조의 물성(페이지를 넘기다 멈추는 손·자로 짚는 두 파형)
2. **겹침의 확인:** 굴러간 놈의 이동 기록 페이지(S2 국면 — 페이지
   층위 묘사·정체 명언 0). 간격의 셈(봄보다 짧다)
3. 저녁 무렵 **3건째** — 접근 패턴화(방위가 일정해짐). 아이들을
   부르기로 하는 반 박자(봄 문법의 무게 — `이런 자리는 봄에 몇 번
   있었다` 결·문장 재사용 0)

### Scene 2 — 가게의 저녁 (1,100~1,400자) ※ 이중 무언

1. 저녁상 뒤 가게 — 봄 문법 재가동: 화면의 파형 셋·간격·방향.
   **`봄 기록하고 겹치는 데가 있다`**(상한 — 무엇의 기록인지 안
   말함·아이들도 안 물음)
2. **수아의 무언 추론(잠금):** 설명을 듣던 수아가 말없이 일어남 →
   **선반 아래 통을 꺼내 작업대에 올린다**(가시 조각 — 봄에 넣어 둔
   것). 영진, 통을 보고 반 박자(수아가 무엇을 그렸는지 아는 눈) —
   **둘 다 발화 0.** 단아만 통과 두 사람을 번갈아 보는 반 박자(언니
   는 반 박자 늦게 따라잡는 결 — 삼분법 정합)
3. **플래그 깨짐:** 단아 속말 1문장(`계속 이랬으면 좋겠다`던 게
   깨지는 씁쓸함) → 즉시 각오 전환(`온다면 받아 준다` 결 — 자신감
   유지)
4. 영진 마감: `며칠 지켜보자`(관측 강화 — 짧게)

### Scene 3 — 교실의 온도 (1,100~1,400자) ※ 학습된 반응

1. 월요일 — **공개 통지**(외곽 수로·부두 통제 재개. 인트라넷 게시
   결·`남해방위사령부` 명의 = 명준 ○ 층위)
2. **학습된 교실(잠금):** 봄이면 술렁였을 것이 절차처럼 소화됨 —
   `또 왔나 보네` 온도. 성호 = 검은 거인 재등장 기대 발표체(통계
   포함), **혜정 = 통제 구역 실무 정리**(어느 길이 막히는지·학원
   동선 재편 — 반의식 1눈금: 정리가 빠른 이유를 본인은 안 물음),
   한결 = 게시물 정독 반 컷 후보
3. **단아 = 아는 자의 침묵:** 교실의 소문과 집의 저녁 사이(봄 내내
   하던 이중생활의 재개 — 반 박자·과장 0)
4. 하굣길 반 컷: 수다 속 통제 화제 1비트(예진 완충)

### Scene 4 — 대비 (900~1,200자) ※ 각자의 준비

1. **각자의 준비 재가동:** 단아 = 언덕길 달리기(몸 만들기 — 두려움
   보다 준비가 앞서는 자신감의 결), 수아 = 겹친 화면 세팅(기록
   체계), 영진 = 부표 감시 강화(교대 없는 밤의 예고)
2. **격납고 반 컷(§6-⑤):** 맨몸 점검 — 봄을 다 치른 기체(얼룩진
   어깨 = 훈장 셈 재확인 1문장 상한). 조종석에 앉아 보는 반 박자
   (예열 — 기동 0)
3. **혜정 문자(반의식 잠금):** **`또 시작인가 보네. 알지? 늦으면
   늦는다고`** — 같이 소문을 소화한 사이의 규칙 재가동(전달 아님).
   단아의 답 = `알지`(짧게 — 세 자리 체계의 평시 가동. **혜정 심리
   해설 0**)

### Scene 5 — 훅: 곧장 (700~1,000자) ※ 화면 층위

1. 월요일 밤 — 수리점 단말 앞 영진(감시 강화 첫 밤). 파형이 아니라
   **실루엣이 되는 시각**(방재벽 외곽 감시 화면)
2. **훅(개요 고정):** 수면을 가르며 오는 **반구형 실루엣.** 봄의
   그것들은 오다가 멈추고, 잠복하고, 기다렸다 — **이것은 멈추지
   않는다. 곧장 온다.** 끝(정체 명언 0·출격 0·아이들 호출은 EP44
   개시점)
