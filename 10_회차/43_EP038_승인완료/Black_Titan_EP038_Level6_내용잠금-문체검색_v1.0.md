## 2. 회차 전체 리듬 — 전투 화(단아 밀착 + 밤의 두 화면)

```text
재개: 흩어지는 힘 — 밀어내도 돌아오는 것
→ 방패: 폐건물 뒤 — 지붕 너머의 상체 — 건물째 뚫린다
→ 차폐: 기둥과 벽 — 두 번의 멈칫 — 왜인지는 모른 채
→ 밤: 썼다 지우는 손 — 나란히 놓이는 두 장 — 채널 앞의 머뭇
→ 문장: 꽃이 눈이야 — 숨는 상대가 바뀐다 — 한 걸음씩, 일직선
```

- **전투 톤 가드:** 균열 3회 배치(S1 무거워지는 팔·밀리는 발밑 /
  S2 방패 붕괴 속 참기 실패〔`침착하자` 변주 — 재사용 0〕 / S2~3
  재포박의 공포). 쿨내 0.
- **자신감 궤적:** 오해 = 합리적 오답(멈칫 경험→`놓치는 놈` 추론 —
  자기 셈으로 고른 방패). 값을 치르되 바닥 0 — 수아의 문장을
  **받아서 자기 것으로 만드는 회복**(재해석·구조물 선택 = 단아 몫).
- **셈 삼분법 — 이 화의 핵심 대비:** 단아 = 몸으로 두 번 부딪히고도
  왜인지 못 읽음 / **수아 = 화면 두 장을 나란히 놓고 읽음**(머리로
  그리는 아이의 봄 내내 쌓은 기록 습관이 한 문장으로 터지는 화).
  같은 사실, 두 문법.
- **수아 톤 가드(최우선 국면):** 끼어들기 전 머뭇(손을 쥐었다 펴는
  반 박자·한 발짝 뒤) → 문장은 짧고 정확하게 → 이후 침묵. 뾰족함 0·
  지휘 0. 영진 = 말없이 자리 내주기(차단 0 — 허락은 침묵으로).
- 씬 밴드: S1 900~1,200 / S2 1,200~1,500 / S3 1,000~1,300 /
  S4 700~1,000 / S5 1,100~1,400 (목표 5,800)
- 클리프행어 = 전투 지속(EP39 시간 경과 0 — 위기 지속 4호 예상).

## 3. 장면별 문단 비트 잠금

### Scene 1 — 흩어지는 힘 (900~1,200자) ※ 시간 경과 0 재개

1. 기둥 뒤 숨 고르기에서 **문장 하나 사이로 재개**(경과 서술 0).
   넓은 놈 재접근 — 밀고 밀리기.
2. **힘 분산 물성(개요):** 두들김이 흡착발·겹갑판에 넓게 먹힘 —
   한 점을 때려도 온몸으로 나눠 받는 상대(EP37 이불더미 손맛의
   상급 — 문장 재사용 0).
3. **반복 구조 노출:** 밀어내도, 꽃이 눕는 방향을 따라 한 박자 늦게
   돌아온다(단아 시점 = 이유 미상. `또 저런다` 수준 상한).
4. 균열 ①: 무거워지는 팔의 셈·발밑이 조금씩 외해로 밀리는 자각.

### Scene 2 — 잘못 고른 방패 (1,200~1,500자) ※ A 심장 1

1. **오해의 논리(잠금):** 기둥 뒤에서 멈칫했었다 → **`놓치는
   놈이구나`** → 더 큰 것 뒤에 숨으면 이긴다(승수의 셈 — 합리적
   오답. 성격 결함 아님).
2. 반쯤 무너진 폐건물 뒤로 — 낮은 각도 완전 차단, **반 박자 안도.**
3. **독자만 아는 공포(잠금):** 지붕 너머로 드러난 상체 — 크레인
   꼭대기의 꽃·원반이 먼저 돌고, **젖은 어깨 장갑에 광택이
   스친다**(단아 무자각 — 서술은 광택 사실까지).
4. **정면 돌파(개요 고정):** 한 박자 뒤 — 속도를 줄이지도 모서리를
   찾지도 않고 **폐건물 정면에 넓은 몸을 밀어 넣는다.** 외벽·기둥이
   안쪽으로 연달아 무너지고, 잔해를 배 밑으로 눌러 넘으며 곧장
   닿음(부수 피해 물성 — 부수려는 게 아니라 **지나가는** 파괴).
5. **재포박·끌기 재개**(운반막 — 더 깊이). 균열 ②: 방패가 무너지는
   소리 속 참기 실패 반 박자(`침착하자` 계열 변주).

### Scene 3 — 두 번의 멈칫 (1,000~1,300자) ※ A 심장 2

1. **두 번째 탈출:** 이음매 — 이번엔 힘이 아니라 각도로 겨우(값이
   비싸짐: 탈출마다 팔 하나 몫의 셈).
2. **진짜 차폐(개요 고정):** 기둥+높은 창고 벽이 **함께 겹치는
   각도** — **원반까지 완전히 가려진 순간에만 군부형 정지.**
3. **대비 완성:** 꽃이 옆으로 시야를 되찾으면 **한 박자 늦게
   재출발** — 폐건물(뚫림)과 여기(멈춤)의 두 결과가 단아 안에
   나란히 쌓임. **상한: `같은 숨기인데 왜 다르지`까지**(원리 도달 0
   — 깨달음은 수아 문장 이후).

### Scene 4 — 밤의 두 화면 (700~1,000자) ※ B1 재배치 + B3 준비

1. **혜정의 방(§6-① 잠금):** 답 없는 대화창. **두 번째 메시지를
   쓴다 — 지운다**(문면 후보: `아직이지` 계열 한 줄 — **전송 0**).
   화면 끝에 남은 자기 말(`뭘 보내야 되는지는 알지`)을 오래 봄.
   휴대폰을 엎어 놓지 않고 세워 두는 물성(기다림의 각도) — 반 컷
   상한(수다 없음: 혼자 있는 밤 = 가드 예외).
2. **수리점(§6-② 잠금):** 수아 — 겹친 기록화면 위에 전투 위치가
   얹힘. **차이 두 장을 나란히 놓는 손**(폐건물 국면 / 기둥+벽 국면
   — 시각·위치 표기). 읽은 것을 말로 옮기기 전, **채널 앞에서 손을
   쥐었다 펴는 머뭇**(한 발짝 뒤의 아이). **영진: 말없이 의자를
   반 뼘 비켜 주는 한 팔 몸짓**(허락 = 침묵·차단 0).

### Scene 5 — 꽃이 눈이야 (1,100~1,400자) ※ B3 심장 + 훅

1. **수아 문면(§6-⑤ — 화 첫 개입·고정):** **`언니, 큰 건 눈이
   없어. 꽃이 눈이야.`** 한 문장. 이후 침묵(추가 지시 0 — 채널
   너머에서 숨 죽이는 결).
2. **재해석(단아의 몸 문법):** 문장이 두 번의 멈칫과 맞물리는 순간
   — `납작한 놈한테서 숨는 게 아니라 꽃한테서 사라지는 거다`(수신
   확인 = 짧게: `……알았어` 계열 상한). 부수는 싸움 → **회로 끊는
   싸움**으로 전환 — **구조물·각도 선택 = 단아**(크레인 기초 지목:
   물속에 고정된 제일 두꺼운 것).
3. **훅(개요 고정 문면):** 꽃과 자기 사이에 크레인 기초가 정확히
   들어오도록 **한 걸음씩** 옆으로 — **꽃도 그 움직임을 따라 돈다**
   — 군부형은 방향을 받지 못한 채 **물 위에서 납작하게 멈춰 있다.**
   끝(결착 0·다음 지정 갱신 대기 국면 — EP39로).
