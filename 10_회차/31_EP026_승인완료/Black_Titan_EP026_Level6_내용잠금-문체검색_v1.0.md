## 2. 회차 전체 리듬

```text
인양장: 호통 — 기태야 — 차렷
→ 두 개의 시계: 갑자기 일이…까지 쓴 손 — 지우는 손 — 고쳐 쓰는 손
→ 시장: 먼저 와 있던 봉지들 — 규칙 한 줄 — 평범한 오후
→ 교실(월): 감점표 — 탈환 — 다시 잰다
→ 활동지: 첫 줄 할아버지 — 멈추는 연필
```

- 문체 축은 **문장**이다 — 쓰다 만 문장, 고쳐 쓴 문장, 규칙이 된
  문장, 끝내 못 쓴 문장. 이 화의 사건은 대부분 문장의 사건.
- 시점: 전편 단아 밀착. S1~S3 = 5/6 금(재량휴업), S4~S5 = 5/9 월.
  장 전환부에 주말 경과 1문장 상한.
- 씬 밴드: S1 1,100~1,400 / S2 1,000~1,300 / S3 1,300~1,600 /
  S4 1,000~1,300 / S5 500~800 (목표 5,500)
- 톤 가드: 단아 몸 먼저(상자부터 드는), 수아 요체·맞받기 0,
  기태 = 무서움과 보호가 같은 동작.

## 3. 장면별 문단 비트 잠금

### Scene 1 — 인양장의 호통 (1,100~1,400자)

1. 금요일 아침 인양장 — 연락선 지연(하역 순서 밀림). 부품 = `가게
   짐`·`소모품` 결(명칭·용도 서술 0). 재량휴업 언급 반 줄(`학교 안
   가는 금요일`).
2. **기태 첫인상 재현(잠금 — 리마인드 = 서사):** 크레인 반경으로
   붙은 자매에게 **먼저 호통**(`애들이 인양장에 왜 들어와` 계열 신규
   문면). 밀어내는 손이 정확히 위험선 바깥 방향 — 무섭게 구는 것과
   지켜 주는 것이 같은 동작(해설 0, 방향의 물리로).
3. **`기태야`(잠금):** 영진의 낮은 호명 — 기태 즉시 차렷·안전모
   고쳐 쓰기·상자부터 챙김. 낙차 크게, 비트 1~2로 짧게. 단아 속말
   상한 1줄(`저 무서운 형이…` 계열 관찰 — EP7 기억 소환 반 줄).
4. 하역 실무 — 수아 품목표 대조(요체, 빠진 것 확인 1비트), 무거운
   상자는 기태·영진 몫으로 분리.

### Scene 2 — 쓰다 멈추는 손 ① (1,000~1,300자)

1. 열 시 임박 — 하역 미완. 두 시계의 충돌(약속과 배 — 조바심의 몸:
   발끝, 시계 확인 횟수).
2. **습관의 문장(잠금):** 입력창에 `갑자기 일이 생겼다`까지. 두 달
   치 관성의 문장 — 거기서 어제의 줄이 떠오름(`늦으면 늦는다고는
   해` 재인용 1회 상한).
3. **고쳐 쓰기(잠금):** 지운다 → 영진에게 허락 문답(`도착 확인,
   수아랑 해도 돼?` — 영진 짧은 승낙 + 가라는 손짓) → **`가게 짐
   받고 20분 늦는다`** 발신(공개 상한 집행).
4. **답신(잠금 — §6-④ 결):** `ㅇㅋ` 계열 한 글자. 무게는 이쪽에만
   있었다는 결(허탈+안도 반 박자, 해설 0). 뛰기 시작하는 발.

### Scene 3 — 시장의 규칙 (1,300~1,600자) ※ B1 핵심

1. 이십 분 뒤 시장 입구 — **먼저 와 있던 물성:** 혜정 손의 장 본
   봉지 하나, 예진 손의 간식 둘(하나는 단아 몫으로 산 것 — 올 것을
   전제한 구매). 화내는 기색 0.
2. **규칙 문면(잠금):** 혜정 — `못 오는 것보다, 아무 말 없이
   기다리게 하는 게 싫어.` 앞뒤로 캐묻기 0(늦은 이유는 문자로 이미
   충분하다는 태도). 단아의 답 — 다음엔 먼저 알리겠다는 약속 1문장
   (거창하지 않게).
3. **예진 완충(잠금):** 화해 선언 0 — 간식을 입에 물려 주는 것으로
   국면 전환. 시장 구경 1~2비트(미란 좌판 배경 상한 반 컷 — 발화 0
   허용).
4. 씬 마감: 평범한 오후의 물성(웃음소리·나란한 걸음) — 셈·해설 0.

### Scene 4 — 기록표 (1,000~1,300자) ※ 5/9 월

1. 주말 경과 1문장 상한 → 월요일 교실. 성호 — 목발을 책상 옆에
   세워 두고 체육 기록표에 **감점 표시 중**(단아 칸에 붉은 줄 계열).
2. **시비 왕복(잠금):** 발견 → 탈환 → 정정(`내 기록에 왜 손을 대`
   계열 신규 문면) → 성호 `깁스만 풀리면 전부 다시 잰다` → 응수 —
   **완전한 평소 온도**(부상 배려 언급 0, 둘 사이에는).
3. 주변 반 컷 상한 1(예진 관찰 계열) — 연애 코드 0.

### Scene 5 — 훅: 쓰다 멈추는 손 ② (500~800자)

1. 하교 직전 — 주호의 활동지 배부. 제목 문면 그대로: **`내가 고마운
   어른에게 묻고 싶은 것`**(어버이날 주간 활동 결 반 줄).
2. **훅(개요 고정 — 잠금):** 첫 줄에 `할아버지` — 쓰는 데 반 박자도
   안 걸림. 그 아래 **빈 두 번째 칸 — 연필이 멈춘다.** 누구를
   쓰려다 멈췄는지, 왜 멈췄는지 서술 0(어머니/엄마 단어 0). 멈춘
   연필의 물성에서 컷(§6-③ 수미상관 — 씬 2와 같은 손, 다른 결말).
   끝.
