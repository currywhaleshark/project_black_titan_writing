## 2. 회차 전체 리듬

```text
학교: 깜빡임은 아직 놀잇거리 → 복도의 한 박자(C1)
→ 지휘소: 높은 곳에 앉은 것 → 구획이 하나씩 떨어지는 지도
→ 수리점: 촛불 아래 셈 → 접어 넣는 점검 목록
→ 밤: 구역별로 꺼지는 도시 → 다리의 각도 → 격납고 조명
```

- 이 화의 문체 축은 **점층**이다 — 같은 정전이 씬마다 다른 크기로
  보인다(놀잇거리 → 작전 대상 → 생활 부담 → 위협). 어휘 온도를 씬별로
  분리: 학교=생활어, 군=보고어, 수리점=품목어, 밤=무언 계열.
- 전투 0. 거미게형은 S2에서만 등장(단아와 같은 씬 금지 = C1 분리).
- 씬 밴드: S1 1,300~1,600 / S2 1,500~1,800 / S3 1,100~1,400 /
  S4 600~900 (목표 5,500)
- 시점: S1 단아 / S2 군(외부) / S3 단아(가족) / S4 중립 무언 →
  격납고 1컷. §6-8 호칭 준수 — 군 씬 내부 고유명 0.

## 3. 장면별 문단 비트 잠금

### Scene 1 — 학교: 깜빡이는 하루 (1,300~1,600자) ※ 괴수 명사 0

1. 아침 교실 — 순간정전의 생활 신호: 전자칠판 재부팅, 벽시계 리셋
   (EP13의 시계 모티프 재사용 가능 — 문장 전이 0), 급식 조리 순서 조정.
   `짧게, 자주` 끊기는 결 — 발전량 부족 서술 0.
2. 아이들에게는 놀잇거리 — 꺼질 때마다 환호 계열 1비트. 학급 26명 파생.
3. **B4 1비트(잠금):** 성호의 정전 원인 발표 — 오답 나열(변압기 폭발설·
   절전 훈련설 계열 2~3개). **검은 거인 연동설 금지.** 체육대회 연습
   차질 투덜 1문장.
4. **C1 발현(잠금 — 이 화의 핵심 수위):**
   - 배치: 복도 이동 중, 나갔던 조명이 돌아오는 순간.
   - 문면 계열: 초점이 한 박자 늦게 맞는다 + 관자놀이를 짧게 찌르는
     것 1~2문장. **해설 0, 병명·시력 어휘 0.**
   - 자기 해석 한 줄: `정전 때문에 눈이 놀랐나` 계열 — 속말 1회로 처리
     (이 화의 유일한 속말).
   - **목격자 0**(혜정·예진 포함 — 복도에 있어도 보지 못한다).
   - 이 씬에 괴수·연구단지·탑 명사 0. 이후 전 씬에서 재발 0.
5. 하교 — 꺼진 신호등 사거리, 수신호 1컷. 연습 단축 공지(시간표가
   정전에 밀리는 낌새).

### Scene 2 — 남방사·연구단지: 높은 곳의 괴수 (1,500~1,800자) ※ 단아 증상 언급 0

1. 지휘소 — 외곽 센서 이상 보고로 개시. `발전소는 멀쩡합니다` 계열
   실무 대사 명시(공격 오독 차단).
2. **첫 노출(잠금):** 화면+현장 교차 —
   - 해안 → 방재벽 → 외곽 구조물 → 열교환탑 고정의 이동 경로를
     관측 보고 리듬으로.
   - 여덟 개의 긴 보행지, 서로 다른 높이·방향으로 벌어짐. 벌어질 때마다
     센서값 뒤틀림 → 안전계통이 전력·냉각 구획을 차례로 분리.
   - **눈 초록 점등 1컷(G0-009).** §5: 소리 지연 1회(다리가 탑을 딛는
     것이 보이고 반 박자 뒤 소리), 크기 대조물(변전탑·크레인).
   - 지면 명명: `다각 보행체`·`고소 점거 개체` 계열 군 기능어까지.
     `거미게형` 0.
3. **B2(잠금):** 고명준 —
   - 결정: 기술진 대피·전력구획 분리·예상 낙하구역 통제 우선. 정체
     추적 확대 0. 직접 포격 보류(구조물 붕괴 위험 — 근거 1문장).
   - **공개 비상주파수 송출**: 구조물 하중·접근금지 구역 반복. 의도는
     서진과의 실무 문답 1교환 상한(`누가 듣습니까` → `듣는 쪽이 있으면
     좋겠군` 계열 — 거인 명시 0).
   - 투덜 축소판 1~2문장(EP12 §3 문장 전이 0).
4. 씬 마감: 구역별 소등이 상황판 지도 위에서 번지는 이미지 — `파도`
   어휘는 여기서 1회만(제목 회수, 해설 0).

### Scene 3 — 수리점: 촛불 아래 셈 (1,100~1,400자)

1. 저녁 — 정전 구역 순번표(인트라넷 공지 계열)가 벽에 붙는 생활 물성.
   손전등·발전기 점검, 냉장고 걱정 무명 손님 1~2(카드 생성 0).
2. **C4 추정 상한(잠금):** 영진 —
   `전기를 먹는 게 아니다. 높은 데서 뭘 찾는 거다.`
   근거는 무전·공지의 공개 정보까지만. 무엇을 찾는지 모름. 타이탄
   회피·상쇄 어휘 0. 이 한 줄 외 확장 0.
3. 가족 결: 단아의 시간표가 정전표와 겹쳐지는 실감(연습 단축·훈련 보류
   계열). 수아 발화 0~2(생활 수준 — 방과후·하랑 언급 가능하되 1문장).
   **C1 언급 0 — 단아는 복도 일을 말하지 않는다.**
4. 마감: 영진이 격납고 점검 목록을 접어 주머니에 넣는다 — 선언 대사 0,
   동작 1컷.

### Scene 4 — 밤: 다리의 각도 (600~900자) ※ 무언 계열, 중립 시점

1. 언덕/창밖 — 도시 불빛이 구역별로 꺼져 가는 밤. 꺼진 구역과 남은
   구역의 대비를 공간 계량으로(§1-4 계열).
2. **훅 1단(고정):** 열교환탑 꼭대기의 실루엣이 몸을 돌려 구래동
   방향으로 다리 각도를 맞춘다. 이유·위협 해설 0. 초록 점 1컷 허용
   (재점등 아님 — 어둠 속 위치 표지).
3. **훅 2단(고정):** 수리점 지하 — 격납고 조명이 켜진다. 누가 켰는지
   서술 0. 끝.
4. 두 훅 사이 연결 해설 0 — 병치만으로 다음 화 동기.
