## 2. ★ 재독 검사

### ① 미완결 재독 — **통과**

마지막 세 문단에 **퇴각·결의·원인 정리 전부 0**.

- 퇴각 0 — 끌고 가는 쪽을 골라 계속 쫓는다
- 결의 0 — `그래도 막아야 한다` 류 없음. 마감은 **`앞에서 물이 갈라지고 있었다`**
- 원인 정리 0 — 왜 안 맞는지·왜 못 잡는지를 문장으로 만들지 않았다
- 끊는 자리의 상태 고정 이행: **사슬 반쯤 나감 / 감으면 늦고 안 감으면 못 움직임 → 끌고 간다**

### ② 민첩성 재독 — **통과**

저것이 움직이는 문단마다 **질량이 남는다.**

- 지나가면 **물이 갈라지고 한참 뒤에 파도가 발밑을 친다**(`발이 한 번 뜨는 느낌`)
- 급선회 = **물이 벽처럼 서고**(사람 키의 몇 배·건물 창으로 들이침), **바닥이 활처럼 파이고**(물이 그리로 흘러듦), **소리가 그다음에 온다**
- `5층짜리가 옆으로 누워서 달려가는 것 같았다` / **`가벼워서 빠른 게 아니었다`**
- 다리 = 도는 게 아니라 **밀어 낸다.** 부서진 걸 밟으면 부수고 지나간다
- 팔랑거림·순간이동·공중 도약 **0**
