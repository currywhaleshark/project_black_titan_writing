## 1. 이 화의 형태

**끝나지 않는다.**

이 화에는 결말이 없다. 퇴각도 결의도 원인 정리도 없이 **궁지에서 끊고**, EP60이 **같은 교전을 시간 경과 0으로** 이어받는다.

그래서 이 화의 성패는 **마지막 세 문단**에 달려 있다.

## 2. 전장 구조 — **최종 잠금**

**외곽 수몰 시가지.** EP60이 같은 지형을 반대로 쓴다.

| --- | --- | --- |
| ① | 수심 | **썰물.** 정강이~무릎. **드문드문 바닥이 드러난 고지대** |
| ② | 엄폐물 | 건물 상층부가 서 있다. **이 화에서는 트인 데에서 싸운다** — 엄폐가 이쪽 시야만 막는다 |

## 3. 개체 잠금 — 등각류형 (§6-6 첫 노출)

- **외형:** 마디 갑각. 다리 여럿. 길고 낮다. **사람 기준으로는 건물만 하다**
- **★ 질량 있는 속도(과한 민첩성 금지):**
  - **직선은 빠르다.** 지나가면 물이 갈라지고 **한참 뒤에 파도가 밀려와** 발밑을 친다
  - **꺾는 데 값을 치른다.** 급선회하면 **물보라가 벽처럼 서고, 드러난 바닥이 길게 파이고, 소리가 뒤늦게 터진다**
  - **그 값을 치르고도 이쪽이 늦다**
  - **다리가 여럿이라 걸음을 안 고른다** — 가벼워서가 아니라 **디딜 데가 많아서**
- **행동:** 직선으로 붙었다 떨어진다. **스치면서 긁는다.** 안 뚫린다
- **지면 지칭:** `빠른 놈`·`작은 것`
- **금지:** 작가용 속도 수치 / 벌레 같은 팔랑거림 / 공중 도약 / 정지 후 대치 / 이쪽을 부수려는 집착

## 4. 가드

### ⚠ ①(훅의 배신)

- **`내일 다시 한다`가 연습이 아니라 실전으로 돌아온다.** 이게 첫 타격이다
- 어제 두 시간 걸려 붙인 것을 **급하게, 덜 조인 채로** 다시 붙인다
- **학교는 못 간다** — 한 줄로 스치고 지나간다
- **금지:** 각오 / `올 줄 알았다` / 준비된 태세

### ⚠ ②(미완성을 들고 나가는 명분 — 한 줄)

- 맨손으로 잡을 수 있는 상대면 두고 가도 된다. **아닌 걸 안다**
- **영진의 판단 한 줄**로 처리하고 논쟁을 만들지 않는다
- **금지:** 두고 갈지 말지의 갈등 장면 / 자신감 / 시험 삼아

### ⚠ ③(질량 있는 속도 · `안 보인다`의 뜻)

- **형체는 보인다.** 못 보는 게 아니라 **반응이 못 따라간다**
- **본 것은 늘 지나간 것이다**
- 감각 순서: **물살 → 자국 → 뒤늦은 소리 → 뒤늦은 파도**
- **금지:** 과한 민첩성 / `순간이동` 계열 / 시야에서 사라짐 / 속도 수치

### ⚠ ④(2단 발사가 실전에서 더 나쁘다)

- 훈련장에서 **어색함**이던 정적 구간이 여기서는 **치명적**이다
- `푸슉` → **정적**(그 사이에 저것이 이미 딴 데 있다) → 불 → 빈 물
- **감는 동안 못 움직인다.** 그 사이에 또 지나간다
- **★ 이게 EP60의 답을 만든다** — 움직이는 걸 맞히는 게 아니라 **지나갈 자리에 미리 놓는 것.** 다만 **이 화에서 그 결론을 내지 않는다**
- **금지:** 근접 성공 / 요령 습득 / `다음엔 될 것 같다`

### ⚠ ⑤(붙잡을 수가 없다 — 이 화의 진짜 패배) ※ v1.1 정정

**★ 저것이 뭘 하고 있는지가 매 순간 읽혀야 한다(사용자 지적 2026-08-14).**
`왔다 갔다 했다`로 뭉뚱그리면 **지나간 상대 앞을 어떻게 다시 막는지**가
안 읽힌다.

- **행동 패턴:** 이 일대를 **안 떠난다.** 지나가고 → **크게 한 바퀴 돌아
  다시 온다** → 또 지나간다. **돌아오는 게 보이니까 앞을 막을 수 있다**
- **★ 공격은 한다(2목적 이행 · 개요 §5-B 정합):** 정면으로 안 올 뿐이다.
  **틀어서 정면을 피하고 옆으로 붙어 치고 나간다.** 스치면서 긁는 것이
  **저것의 싸움 방식**이다 — **`이쪽을 부수려고 하지 않는다`는 틀렸다**
- **왜 안 멈추나:** **멈추면 지는 걸 저것도 안다.** 속도가 유일한 무기다
- **누적:** 한 번에 크게 안 다치는데 **지나갈 때마다 자국이 하나씩 는다**
  (어깨 → 허리 → 종아리). 밀린 적도 크게 맞은 적도 없는데 **자국만 늘었다**
- **★ 전환(Scene 5):** 여섯 번째에 **원을 안 닫는다.** 돌다가 그대로 펴서
  나간다 — **여기서 할 게 없다고 판단한 것.** 이쪽이 못 잡는다는 걸
  저것이 먼저 알았다
- 앞의 셋과 안 겹친다: 성게형=안 닿음 / 질량형=밀림 / 따개비=붙어 있음 /
  **등각류=붙잡을 수가 없음**
- **금지:** 대치 / 붙어서 하는 교전 / 관통상 / 기체 대파 / `뭘 하는지 모르겠다`로
  뭉개기

### ⚠ ⑥(목격 0)

- **새벽이고 외곽이다.** 사람이 없다
- **몰리는 걸 사람들이 보면 여론이 비난으로 튄다**(S10 몫)
- 다만 **가는 방향이 도시**라는 게 압력이다
- **금지:** 구경꾼 / 여론 / 방송 / 군

### ⚠ ⑦(끊는 법 — 이 화의 성패)

**마지막 세 문단에 이 셋이 없어야 한다.**

| 금지 | 이유 |
| --- | --- |
| **퇴각** | 빠른 것이 도시로 가는데 물러나면 성립하지 않는다 |
| **결의** | `그래도 막아야 한다` 류가 붙으면 EP60의 코칭이 들어갈 자리가 없다 |
| **원인 정리** | 왜 안 되는지를 여기서 문장으로 만들면 EP60이 죽는다 |

- **아무것도 정리되지 않은 채로 끊는다**
- 끊는 자리의 상태: **사슬이 반쯤 나가 있고, 감으면 늦고 안 감으면 못 움직인다**

### ⚠ ⑧(승계)

- **화계:** 단아→영진 반말(교신 포함) / 수아→영진 존댓말 / 수아→단아 반말
- **시점 지칭:** 서술문에서 영진은 **`할아버지`**
- **영진**(§2-B): **관측·경고·거리 통보·장착 절차.** 전술 0·답 0·한 손·안경 0
- **수아:** 출격 전까지(부표 시각·물때). **전투 교신 0**·현장 동행 0
- **명명 게이트:** `그것`·`닻`·`사슬`·`통`·`등판`. **`앵커`·`로켓`·`추진`·`점화`·`노즐`·`사출기` 0**
- **균열 2~3회** / 새 증상 0 / 작가용 개체 명칭 0 / 반입구 0 / 현서 0

## 6. 장면별 잠금

### Scene 1 — 새벽 ※ 가드 ① 집행

- **고정:** 어두울 때 부표 → **어제 그 시각의 정반대** → 신호가 봄 것들과 안 맞는다(빠르다) → 어제 푼 장비를 **다시 붙인다** → 학교 생각이 한 줄 스친다
- **균열 ①:** **다시 하기로 한 건 연습이었다**
- **금지:** 각오 / 준비된 태세

### Scene 2 — 들고 나간다 ※ 가드 ②⑥ 집행

- **고정:** 두고 갈지 잠깐 문제가 된다 → **영진의 판단 한 줄** → 수아는 여기까지(부표 시각·물때) → **새벽이라 아무도 안 본다** → **덜 조인 채로 나간다**
- **금지:** 갈등 장면 / 자신감 / 구경꾼

### Scene 3 — 안 보인다 ※ 가드 ③ 집행 · §6-6 첫 노출

- **고정:** 썰물·드러난 바닥 → **물살로 먼저 안다** → **소리가 나중에 온다** → 한 번 스친다(긁히고 안 뚫림) → 형체를 본다(**마디 갑각·다리 여럿·작지 않다**) → **지나간 뒤 파도가 발밑을 친다**
- **균열 ②:** 봄부터 다 봤고 **본 다음에 무서웠다.** 이건 **본 게 늘 지나간 것**이다
- **금지:** 과한 민첩성 / 대치 / 명명

### Scene 4 — 싸워 주지 않는다 ※ 가드 ④⑤ 집행

- **고정:** 막아선다 → **방향을 튼다** → **꺾는 값**(물보라가 벽처럼·바닥이 파임·뒤늦은 소리) → **그런데도 이쪽이 늦다** → 또 막아선다 → **또 지나간다** → 쏜다(`푸슉`·정적·불·빈 물) → 두 번 세 번 → **감는 동안 또 지나간다**
- **핵심 한 줄:** **힘이 남았는데 쓸 데가 없다**
- **금지:** 근접 성공 / 요령 / 교전다운 교전 / 원인 정리

### Scene 5 — 못 따라간다 ※ 가드 ⑤ 집행

- **고정:** 쫓는다 → **한 걸음마다 고른다** → 저쪽은 **디딜 데가 많아서** 안 고른다 → 거리가 벌어진다 → **한 번 벌어지면 안 좁혀진다** → 영진의 관측 교신(위치·방향·거리)
- **균열 ③:** **뒤에 남는다**
- **금지:** 영진의 전술 / 지름길 발견 / 분투 묘사로 만회

### Scene 6 — 그쪽 ※ 가드 ⑦ 집행

- **고정:** **방향을 잡는다 — 도시 쪽이다** → 거리는 영진이 말해 준다 → **시간은 아무도 말 안 한다** → **사슬이 반쯤 나가 있다**(감으면 늦고 안 감으면 못 움직인다)
- **끝:** **궁지에서 끊는다**
- **금지:** 퇴각 / 결의 / 원인 정리 / 다음 화 예고 / 장면 요약
