### 2-A. ★★★★★★ 명료성 가드

**규칙 ① 용어 → 풀이.** 현서는 **정확한 용어**를 쓴다(과학자). 그리고 **바로 풀이가 따라온다** — 현서가 한 번 풀거나, 아이가 묻거나, 시점 인물이 받는다.

| 용어 | 풀이 방식 |
| --- | --- |
| **배양** | 현서 `세포를 길러서 키웠다는 거야.` |
| **소각 장치** | 현서 `불을 붙여서 안에서부터 태우는 장치.` |
| **신경세포** | 현서 `머리가 몸한테 말을 전하는 세포.` |
| **난자** | 현서 **`난자가 뭔지는 배웠니?`** / 단아 **`…학교에서요.`** |
| **수정란** | 단아 받기 — 사람 아기가 처음 되는 것 · 거기에 저것 세포를 합쳤다 |

**규칙 ② 되풀이 문장.** 조각마다 아래 문장이 **대사나 서술에 그대로** 있어야 한다.

| 조각 | 독자가 되풀이할 수 있어야 하는 한 문장 |
| --- | --- |
| ① | 저 밖에도 사람은 산다. 괴물은 단아가 싸운 괴수이고, 바다 밑에서 왔다 |
| **막아야 하는 이유** | **괴수는 대수몰로 바닷물을 올렸고, 지금도 사람 사는 땅을 바다로 바꾸고 있다** |
| 왜 | 괴수는 대포로 안 되고 같은 것끼리만 다치게 해서, 현서는 막으려고 같은 것을 배양했다 |
| ②③ | 이 집 지하에서 키웠는데 스스로 생각하게 돼서 말을 안 들었다 |
| ④ | 그래서 미리 몸 안에 넣어 둔 소각 장치로 태웠다 |
| 발상·가설 | 태우고 남은 신경세포를 현서의 난자와 합쳐 사람으로 낳으면, 사람으로 자라서 그걸 움직일 수 있다고 봤다. 동물로 먼저 확인했다 |
| **⑤** | **현서는 확신 없이 자기 몸으로 했고, 그렇게 단아를 낳았다. 단아는 현서의 친딸이다** |
| **⑥** | **단아가 제대로 자라는 걸 보고 두 번째 배양을 했고, 거기서 블랙 타이탄과 수아가 나왔다. 수아도 현서가 낳았다. 블랙 타이탄은 할아버지 말처럼 군 시제기가 아니었다** |
| ⑦ | 두 딸이 자유롭게 사는 것이 현서가 떠나는 조건이었다 |

**규칙 ③ 「그것」 착지.** 괴수 / 처음 배양한 것 / 타이탄 — **나올 때마다 어느 쪽인지 명사로.** 현서 대사: 괴수 = `그것들`(첫 언급 `뻘에서 나오는 거`) · 처음 것 = **`처음 거`** · 타이탄 = **`그 검은 거`**.
