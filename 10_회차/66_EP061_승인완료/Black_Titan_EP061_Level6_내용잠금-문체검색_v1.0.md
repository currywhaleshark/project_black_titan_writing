## 1. 이 화의 형태

**전투 0.** 값을 치르고, 적고, 이름을 붙인다.

그리고 **아크를 요약하지 않고 닫는다.** 세 번의 부족함이 한 물건으로 모였다는 건 독자가 잇는다.

## 2. 가드

### ⚠ ①(결석의 뒷일 — 세 번째 오해)

- **결석은 6/28 화요일 하루.** EP59~60이 같은 날 아침이므로 **이틀이 아니다**
- **영진이 담임(김주호)에게 아프다고 둘러댔다.** ○ 등장 — **통화 언급까지**
- **문자는 오전 중에 쌓인 것이다.** 급식·점심 얘기 **0**
- **★ 혜정의 약속(EP32 정본 회수):**
  `늦으면 늦는다고 했으니까 됐어. **그런데 아프면 아프다고도 해.**`
  단아 = `진짜 아프면 먼저 말할게.`
- **★ 비대칭이 이 장면의 값이다:** **단아는 약속을 안 어겼다** — 안 아팠으니 먼저 말할 게 없었다. **그런데 혜정 쪽에서는 어긴 걸로 보이고, 정정할 수가 없다**
- **오해의 세 번째다:** 성호 = 겁으로 읽음(EP58) / 예진 = 집안일로 읽음(EP58) / **혜정 = 약속을 어긴 걸로 읽음(EP61).** 셋 다 틀렸고 셋 다 못 고친다
- **혜정은 추궁하지 않는다** — **규칙 하나를 다시 놓는 말투**(EP32 카드). 그 줄 다음에 또 수다가 이어진다
- **★ 답장도 거짓말이다:** 미안하다고 쓰는데 **뭐가 미안한지 자기도 헷갈린다.** 안 아팠으니까
- **금지:** 죄책감의 언어화 / 고백 충동 / 들킬 위기 / 혜정의 추궁 / 예진의 눈치채기

### ⚠ ②(정비 척도 — 뻘이 제일 일이다)

- 세척·점검은 **공업 규모.** 손걸레 계열 금지
- **뻘이 사슬 마디마다 끼었고 감개 안쪽까지 들어갔다**
- 스친 자국 셋(어깨·허리·왼쪽 종아리) → 갈아 낸 자리 세 군데
- **푸는 데 두 시간**(EP58 붙이는 데 두 시간과 대칭). 크레인·체인블록
- **밀린 발자국은 현장에 두고 왔다** — 여기 남은 건 물건뿐이다

### ⚠ ③(값 — 한쪽으로 정한다)

- **기태 ● 필수**(간격 3). `어이, 조수` 유지 · **단아 쪽의 미세한 긴장 존속**
- **화계:** 영진→기태 **하게체** / 기태→영진 존댓말 / 단아→기태 존댓말
- **EP51 정본 승계:** `고철은 무게로 나가고 그걸로 끝인데, 장비는 어디서 나와서 어디로 갔는지가 종이에 남는다`
  → **종이에 안 남는 쪽**이 이 집 방식이다. **값을 어떻게 치르는지 한쪽으로 정한다**(애매하게 두지 않는다)
- **★ 기태는 뭘 만들었는지 안 묻는다.** 물을 게 없어서가 아니라 **안 묻는 게 이 바닥 방식**이라서
- **금지:** 장비 목격 / 용도 질문 / 영진과의 긴장 재연 / 감사 인사

### ⚠ ④(표 — 한 칸은 안 늘고 한 칸은 생긴다)

- **개체 표:** 이름 없이 생김새와 행동 — `길고 낮음. 다리 여럿.` / `밀어서 감.` / `얕은 데로만 감.` / `멈추면 못 일어남.`
- **★ `남은 것` 칸이 이번엔 안 는다.** 고칠 사람이 없는 데였다(EP60) — EP54부터 한 줄씩 늘던 게 **처음으로 멈춘다**
- **★ 기체 표에 항목을 신설한다.** 새로 붙은 게 있으니 칸이 필요하다
- **★ 그런데 뭐라고 적을지 모른다** — `닻`이라고 적으면 **마당에 있던 그 닻하고 안 갈라진다**
- 수아가 묻는다: **이거 뭐라고 적어요**
- **수아 4금 유지:** 잘난척·남 탓·변명·말 끊기 0. **이름 평가도 안 한다**

### ⚠ ⑤(명명 — 단아가 정한다)

- **명명식이 아니다.** 적을 칸이 필요해서 붙는다
- 아무도 바로 대답을 못 한다. 그동안 부를 일이 없었다 — **`그거`로 다 통했다**
- **★ 단아가 휴대폰으로 사전을 뒤진다.** **쇠**를 치고 **닻**을 친다. 나온 걸 붙인다
- **★ `아이언 앵커`**
- **★ 별로인 걸 다들 안다.** 너무 있는 그대로고 멋이 없다. **그런데 아무도 말 안 한다**
  - 영진은 원래 그런 걸 안 따진다
  - 수아는 언니가 정한 걸 그냥 적는다
  - **단아 자신도 안다. 아는데 다른 게 안 떠오른다**
- **적히니까 그게 이름이 된다**
- **★ 삼분법:** 몸으로 겪은 사람이 이름을 붙인다. 영진이 붙이면 **물건 이름**이 되고 단아가 붙여야 **몸의 이름**이 된다
- **★ 가족 내부 명칭** — 밖에 나가는 이름이 아니다(간판 계보: 시청·군·언론의 공식 명명 0)
- **금지:** 거창함 / 명명 선언 / 좋은 이름인지 따지는 대사 / 다른 후보를 늘어놓기 / 웃음을 명시하기

### ⚠ ⑥(몸이 바뀐 이야기로 닫는다)

- 밤. 자기 전에 왼팔을 본다 — **기체 팔이 아니라 자기 팔**
- **무기를 얻은 이야기가 아니다.** 봄에 팔이 낯설었고, 몇 달 걸려 사라졌고, **오늘 한 번 더 늘어났다**
- 아직 낯설다. **낯선 게 나쁜 건 아니라는 것도 안다**
- **금지:** 성장 선언 / 각오 / `이제 나는` 류

### ⚠ ⑦(아크를 요약하지 않는다)

- 세 번의 부족함이 한 물건으로 모였다 — **독자가 잇는다**
- 대신 **그 물건이 만든 게 아니라 모은 것**이라는 사실만 **물건들로** 놓는다: 인양장의 체인, 트럭에 실려 온 것, 마당에 있던 것, 주말 밤
- **금지:** 사다리 나열 / `거리·지지·인장` 요약 / 봄부터의 회고 / 다음 각오

### ⚠ ⑧(훅 두 겹)

- **① 간격이 또 짧아졌다** — 장부 앞쪽을 넘겨 보면 **날짜 사이가 줄어들고 있다.** 관측이 아니라 **빈도**의 문제
- **② 학교 쪽으로 향하는 무엇** — **암시 한 줄. 명시 0**(S10 인계)
- **금지:** 예고 / 불길함의 언어화 / 인물의 예감

### ⚠ ⑨(승계)

- **화계 5종:** 단아→영진 반말 / 단아→기태 존댓말 / 수아→영진 존댓말 / 수아→단아 반말 / **영진→기태 하게체**
- **시점 지칭:** 서술문에서 영진은 **`할아버지`**
- **영진**(§2-B): 정비·통화·응대·장부. **명명은 단아 몫**
- **균열 2~3회** / 새 증상 0 / 작가용 개체 명칭 0
- **금지:** 반입구 / 배양·소재·유래 / **현서** / 센티널 / `개수`·`논`
- **★ `앵커`는 이 화부터 허용**(가족 내부 명칭). 다만 **명명 장면 이전에는 0**

## 4. 장면별 잠금

### Scene 1 — 돌아와서 ※ 가드 ② 집행

- **고정:** 낮·격납고 → 눕히고 씻긴다 → **뻘이 제일 일** → 자국 셋 → **푸는 데 두 시간** → **밀린 발자국은 현장에 두고 왔다**
- **균열 ①:** 아직 몸에 남은 것
- **금지:** 전투 회상 / 손걸레 계열

### Scene 2 — 문자 ※ 가드 ① 집행

- **고정:** 단체방에 쌓인 것(**오전 중**) → 혜정 다수(왜 안 왔냐 / 담임이 아프다더라 / 뭐가 아픈데 / **어제까지 멀쩡했잖아** / 조회 때 뭐 했는지 / 필기 사진) → **`아프면 아프다고 하기로 했잖아`** → 그 뒤에 또 수다 → 예진 한 줄 → **담임 통화를 나중에 안다** → **미안하다고 쓴다**
- **★ 비대칭 한 줄:** 안 어겼는데 어긴 걸로 보인다
- **금지:** 추궁 / 죄책감 언어화 / 급식·점심 / 들킬 위기

### Scene 3 — 값 ※ 가드 ③ 집행

- **고정:** 오후 → 기태(`어이, 조수`) → **고철값 계산**(무게로 나가는 것 ↔ 종이에 남는 것) → **한쪽으로 정한다** → **안 묻는다** → 마당 정리(**이제 거의 없다**)
- **금지:** 장비 목격 / 용도 질문 / 감사

### Scene 4 — 표 ※ 가드 ④ 집행

- **고정:** 저녁 → 넉 장 → 개체 표(이름 없이) → **`남은 것` 칸이 안 는다** → **기체 표에 항목 신설** → **`닻`으로는 안 갈라진다** → **이거 뭐라고 적어요**
- **금지:** 수아의 이름 평가 / 결정적 한마디

### Scene 5 — 이름 ※ 가드 ⑤ 집행

- **고정:** 아무도 대답 못 함 → **`그거`로 다 통했다** → **휴대폰 사전**(쇠·닻) → **`아이언 앵커`** → 소리 내어 한 번 → **다들 별로인 걸 아는데 아무도 말 안 함** → 수아가 적음 → **적히니까 이름이 된다**
- **금지:** 거창함 / 명명 선언 / 후보 나열 / 웃음 명시 / 공적 명칭화

### Scene 6 — 왼팔 ※ 가드 ⑥⑦ 집행

- **고정:** 밤 → **자기 팔을 본다** → 봄의 낯섦 → 몇 달 → **오늘 한 번 더 늘어났다** → **낯선 게 나쁜 건 아니다**
- **물건들로만 놓는 아크:** 인양장의 체인 / 트럭에 실려 온 것 / 마당에 있던 것 / 주말 밤
- **균열 ③(택1)**
- **금지:** 사다리 요약 / 성장 선언 / 각오

### Scene 7 — 훅 ※ 가드 ⑧ 집행

- **고정:** 영진이 장부를 편다 → 옆 칸의 **세 줄은 그대로** → **앞쪽을 넘겨 보면 날짜 사이가 줄어들고 있다** → **학교 쪽으로 향하는 무엇**(한 줄)
- **끝:** 여름은 아직 절반도 안 지났다 계열
- **금지:** 예고 / 예감 / 불길함의 언어화
