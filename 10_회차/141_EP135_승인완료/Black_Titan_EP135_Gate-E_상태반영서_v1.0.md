## 2. ★★★★★★ 이 회차가 한 일

**온다. 그런데 왜 오는지 모른다.**

> **`되는 것과 안 되는 것 사이에서 자기가 한 일이 똑같았다.`**
> **`그러면 이건 자기가 하는 게 아니었다.`**
> **`거기까지 생각하고 멈췄다. 그다음을 어떻게 생각해야 하는지 몰랐다.`**

### 2-1. ★★★★★★ 작가용 기전이 확정됐다 — 지면 0

사용자 확정(2026-08-25):

| | |
| --- | --- |
| **이전 방식** | 「내가 의도하면 기체가 움직인다」 2단계 — **조종 방식이 가짜라는 걸 알아버려서 못 쓴다** |
| **되는 방식** | **중간 단계를 끊고 「내가 움직인다」고 느낀다** |
| **깨지는 조건** | **느껴야 하니 의식적으로 하려고 할수록 안 된다** |

**★★★ 지면 처리는 배치만이다.** 그 순간에 뭘 하고 있었는지만 적고 **인과는 0**.

| 시도 | 그때 하고 있던 것 | |
| --- | --- | --- |
| **1** | **순서라서 했다** — `아침에 신발을 신는 것처럼` | **★ 온다** |
| 2 | 아까하고 똑같이 하려고 한다 | 안 온다 |
| **3** | **듣는 동안 한 번 더 했다** | **★ 온다** |
| 4~6 | 찾는다 | 안 온다 |
| **7** | **세느라고 놓칠 뻔했다** | **★ 온다** |
| 8~12 | 센다 | 안 온다 |
| **13** | 세는 것 자체가 지겨워진 뒤 | **★ 온다** |
| 14~20 | 팔이 무거워진다 | 안 온다 |
| **마지막** | **찾는 것도 그만뒀다** | **★ 온다** |

**★★★ 의식이 붙기 시작하는 자리가 곧 안 되기 시작하는 자리다.**
그래서 초고의 의식 서술 세 덩이를 씬3(첫 시도 앞)에서 **씬4(두 번째 시도 뒤)로 옮겼다.**

### 2-2. ★★★★★ 단아의 오판이 규칙의 그림자다

**관찰은 정확하다** — 자기가 한 일이 똑같은데 결과가 갈린다.
**결론은 정확히 반대다** — 하려고 할 때 안 되니까 자기가 하는 게 아닌 것처럼 보인다.

**★★ 「단순한 조종기술이 아니다」는 여전히 도달 전이다.**

### 2-3. ★★★★★ 열 번에 세 번은 나가서 못 쓴다

> **`그리고 열 번에 세 번이면 나가서는 못 쓴다. 그건 세 본 적이 없어도 알았다.`**
> **`여름에 열 번에 세 번이었으면 여름을 못 넘겼다.`**

**★★★ 본인이 안다.** 출격 논의의 실질 조건이 여기서 확정됐다.

### 2-4. ★★★★★★ 「반응 확인」 넉 자

> `확인란에 표시를 하면 그건 한 걸로 친다.` / `한 걸로 치면 그다음이 굴러간다.`
> **`오늘 남는 건 반응 확인 넉 자다.`**
> **`칸이 있는 것만 남는다.`**

**EP131 「이름 쓰는 칸은 있었다. 왜 그렇게 했는지 쓰는 칸은 없었다」의 직계 회수다.**
서류가 사람을 대신하는 계열(EP130 조건 넷 · EP134 보호자 칸)과 같은 층에 붙는다.
