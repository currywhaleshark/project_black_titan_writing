### ⚠ 가드 ①(간척지 정본 — 2026-08-13 사용자 확정)

**논·농지가 아니다.** 방재벽 밖 매립지에 있는 것은
**창고·야적장·수문 관리동·배수펌프장** — **일하는 데지 사는 데가
아니다.**

- 따라서 **인명 피해 0.** 피해는 **물건과 장비**다
- 이것이 이 화에서 **비난이 아직 안 나오는 개연성**을 만든다
- ※ EP52 승인본 1곳 소급정정 완료

### ⚠ 가드 ②(물이 하루를 관통한다)

**물이 안 빠진다**가 여섯 장면 전부에 다른 얼굴로 나온다.

| § | 물의 얼굴 |
| --- | --- |
| 1 | 트럭과 사람들이 그리로 간다 |
| 2 | 교실에서 말이 된다 |
| 3 | 기체 발바닥에 그 바닥이 박혀 있다 |
| 4 | 표에 적힌다 |
| 5 | 물 먹은 장비가 수리점에 온다 |
| 6 | 장부에 줄이 하나 는다 |

- **단아가 사과하지 않는다.** 자책의 언어화 0 —
  `미안한 것도 아니고 안 미안한 것도 아닌` 상태까지

### ⚠ 가드 ③(도시 — 곤란함까지, 비난은 0)

| 단계 | 회차 | 내용 |
| --- | --- | --- |
| 편들기 첫 눈금 | EP46 | `그 거인 안 오면 어떡해` |
| 해석의 분열 | EP49 | 같은 영상, 다른 말 |
| 소진 | EP50 | `일상이 소문보다 빨랐다` |
| **손해의 발견** | **EP54** | **이겨도 우리 쪽이 손해를 본다** |

- 아이들 입에서는 `이긴 거 맞대` / **`근데 거기 창고들 다 잠겼대`**
  정도. **누구네 아버지가 거기 일하러 갔다**는 식의 전달
- **금지:** 항의·비난·원망 / 어른의 논평 / 단아를 겨눈 말
  ※ **S10(학교 파손)이 그 자리다.** 여기서 쓰면 그때가 약해진다
- 밤이라 **형체 목격 0.** 결과만 본다

### ⚠ 가드 ④(세척 — 이번 몫은 발과 다리)

**공업 규모 정본**(EP33·EP49). **재현이 아니라 이번 몫으로 쓴다.**

| EP49 | **EP54** |
| --- | --- |
| 발목·정강이 | **발바닥 홈·발가락 관절 틈** |
| 뻘·해초 | **콘크리트 조각·철근 부스러기** |
| 이물 = 두 팔로 안는 덩어리 | 같은 척도 유지 |

- 고압세척기 총대(반동을 몸으로·단아 몫)·비계·안전선 밖 진행표·
  손 들어 신호·**발목 하나에 반나절**
- **손걸레·조각 몇 개 계열 금지**
- **자기가 밟은 결과를 자기가 빼낸다. 말은 안 한다**
- 균열 ②: 팔이 아직 무겁다 — **어제 노동의 여운이지 증상이 아니다**
  (`저리다`·`둔하다` 계열 어휘 **금지**)

### ⚠ 가드 ⑤(빈 칸 — 이름을 붙이지 않는다)

EP50에서 `아직 없어. / 생길 것 같아서.`로 만든 **개체 표의 빈 칸**이
여기서 처음 채워진다.

- 들어가는 것은 **생김새와 행동**이지 **이름이 아니다**
  (명명 게이트 · **`-형` 절대 금지**)
- 결: `넓적함. 낮음.` / `밀기만 함.` / `바닥에 붙어 다님.` —
  **수아의 어휘로, 짧게**
- **EP53 회수:** 단아의 필적이 든 간척지 종이를 수아가 **어디에
  두는지**가 이 장면에 들어간다
- 단아가 옆에서 본다 — **자기가 겪은 일이 글자로 바뀌는 것**
- **금지:** 수아의 전술 제안 / 해석 / 단독 작업

### ⚠ 가드 ⑥(오미란 재등장 — 간격 20)

**소개문을 새로 쓰지 않는다.** 리마인드 3요소만 세운다.

| 요소 | 정본 |
| --- | --- |
| 자리 | 수산시장 좌판(**목이 제일 좋은 자리**)·노란 고무장갑 |
| **어민회 일** | 그래서 **간척지 어구·자재 창고가 남 일이 아니다** |
| 거래처 | 수리점에 선풍기·침수 센서를 맡기는 사이 |

- **화계:** 단아 → 미란 **존댓말** / 미란 → 단아 **반말**
  (호칭 = **`수리점 손녀`**) / 미란 → 영진 **반말**(편한 사이)
- 결: 목소리로 밀어 주는 사람. 걱정을 미안함으로 포장한다
  (`바쁠 텐데 미안해서 어쩌나` 계보 — **문장 재사용 0**)
- **배정호 ○ 언급만**(간격 43 — 등장시키지 않는다)

### ⚠ 가드 ⑦(목록의 새 줄 — 답이 아니다)

- 어제 `버틸 것이 없다`를 적었으니 오늘은 답이 될 물건을 적을
  차례인데, **영진도 아직 모른다**
- 그래서 **목록 문법 그대로 흐리게** 적힌다 — **`발에 뭐라도.`** 계열
- **단아가 보고도 안 묻는다**(`안 물어보는 집` 계보·문장 재사용 0)
- ※ **작가용 아이러니(지면 0):** 그 답은 결국 **팔에서** 온다
- **금지:** 앵커 명명·설계·용도 / 반입구 / 목요일 배송 진행
  (**6/23이므로 이틀 뒤**)

### ⚠ 가드 ⑧(승계)

- **화계:** 단아→영진 반말 / 수아→영진 존댓말·수아→단아 반말 /
  단아→미란 존댓말
- **시점 지칭:** 서술문에서 영진은 **`할아버지`**
- **영진의 지원 범위**(상시 가드 §2-B): 이 화는 전투가 없으므로
  **수리 실무와 절차**로 나온다. 해설·판단 대행 0·**한 손**
- **혜정 = 평온.** 생활 수다 1~2교환·**눈금 추가 0**(S10 예약)
- **새 증상 0** / **작가용 개체 명칭 0**

- **금지:** 앵커·클로·로켓 / 반입구 / 센티널·우편물(**EP57**) /
  기태 등장(미등장) / `개수`·`화` / EP33·EP49·EP7 문장 재사용

| 3 | 세척 | 1,000~1,200 | 발과 다리(균열 ②) |

## 3. 장면별 잠금

### Scene 1 — 물

- **고정:** 새벽 귀환 후 두어 시간 자고 등교 / 간척지 쪽으로 **트럭과
  사람들이 간다**(보이거나 들리거나) / 배수 복구는 며칠짜리 일
- **균열 ①:** **자기가 한 일인데 자기 일이 아니게 된 자리.**
  미안한 것도 아니고 안 미안한 것도 아닌 상태
- **금지:** 사과 / 자책 / 어른의 설명

### Scene 2 — 교실

- **고정:** 혜정 생활 수다 1~2교환(평온) / **물 얘기가 돈다**
  (밤이라 아무도 못 봤는데 잠긴 건 다 안다) / 가드 ③ 집행
- 단아는 **아무 말도 안 한다**(EP49 계보·문장 재사용 0)
- **금지:** 비난·항의 / 혜정 눈금 / 단아의 해명 충동

### Scene 3 — 세척

- **고정:** 가드 ④ 그대로. **발바닥 홈·관절 틈·콘크리트 조각·철근**
- **§6-6 첫 노출:** **자기가 부순 것이 자기 몸에서 나오는 감각**
- **균열 ②:** 팔이 무겁다(**증상 어휘 0**)
- **금지:** 손걸레 계열 / EP49 문장 재사용 / 통증

### Scene 4 — 빈 칸

- **고정:** 가드 ⑤ 그대로. **이름 없이 생김새와 행동** /
  간척지 종이의 처리(EP53 회수)
- **금지:** `-형` / 수아의 해석 / 전술

### Scene 5 — 값

- **고정:** 물 먹은 **간척지 쪽 장비**가 들어온다 / **오미란 ●
  리마인드 3요소**(가드 ⑥) / 접수·수리비 = **값이 숫자로 적힌다** /
  어른들이 그 얘기를 **하다가 만다**
- **균열 ③:** 값이 오가는 걸 **옆에서 듣고 있는 자리**
- **금지:** 오미란의 정체 접근·위장 의심 / 배정호 등장 /
  단아를 겨눈 말

### Scene 6 — 목록과 소문

- **고정:** 여름 장부 뒤쪽 / 어제 줄(**`버틸 것이 없다.`**)이 거기
  있다 / **목록에 흐린 줄 하나 추가**(가드 ⑦) / 단아가 보고도 안 묻는다
- **훅:** **방재벽 순찰이 뭘 봤다더라** — **출처가 흐리고 본 사람이
  확실치 않다.** 경보 0·관측 0·해석 0
  ※ **관측 체계가 놓쳤다는 말은 아직 하지 않는다**(EP55 몫)
- **금지:** 소문의 확인 / 영진의 반응 서술 / 다음 화 예고
