## 4. 신설 정본

- **★ 간척지 용도(사용자 확정 2026-08-13):** 방재벽 밖 매립지 —
  **논·농지 아님.** 있는 것은 **창고·야적장·수문 관리동·배수펌프장**.
  **일하는 데지 사는 데가 아니다** → 침수 피해는 **물건과 장비**이고
  **인명 피해 0**. ※ EP52 승인본 1곳 소급정정
- **호칭의 축약:** 오미란은 **시장에서는 `수리점 손녀`**,
  **수리점 안에서는 `손녀`**라고 부른다. 장소가 이미 말해 주는 것은
  호칭에서 뺀다
- **★ 수아가 이름을 안 붙이는 이유(대사로 정본화):**
  **`붙이면 그렇게 부르게 돼.`** — 명명 게이트가 작가 규칙이 아니라
  **인물의 판단**으로 성립한 자리
- **`남은 것`(개체 표의 예약 칸):** EP50에서 `아직 없어. / 생길 것
  같아서.`로 만든 칸의 정체. **봄에는 아무것도 안 남았고**(용해·
  수거물 0) 여름 들어 남기 시작한다. 첫 줄 = `배수로. 물 안 빠짐.`
- **값의 층위:** 종이 위의 숫자는 짧다. 실제 값은 **창고 하나 값 ·
  창고 여러 개 · 그 안에 있던 것들 · 그물 손질이 반으로 주는 값**.
  `그게 다 어디에 적히는지 단아는 몰랐다. 어딘가에는 적힐 것이다`
- **여론 5단계 — 손해의 발견:** 소문(무서움) → 걱정(못 봄) →
  해석의 분열 → 소진 → **`그럼 이긴 거야, 진 거야?`**
  ※ **비난이 아니라 농담으로 온다.** 그래서 더 답이 없다
- 격언 계보: `자다 만 잠은 안 잔 것보다 이상하다` / `자기가 한 일인데
  자기가 못 치우는 일이 됐다` / `뭉개졌다는 건 밟혔다는 뜻이다` /
  `지우면 지운 자리가 남는다` / `붙이면 그렇게 부르게 돼` /
  `화를 낼 데가 없어서 말이 끊긴 것 같았다`
