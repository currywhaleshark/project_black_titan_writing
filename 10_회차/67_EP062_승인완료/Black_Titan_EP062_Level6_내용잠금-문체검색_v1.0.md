## 1. 이 화의 형태

**전투 0. 사건 0.** 아크가 사건으로 열리지 않는다.

이 화가 남기는 것은 **표에 생긴 칸 하나**다. 그리고 그 칸은 이 화에서
**아무 뜻도 갖지 않는다.** 열다섯 화 뒤에 6·5·4·3·2가 되지만, 오늘은
고르지 않은 숫자 몇 개일 뿐이다.

**★ 이 화의 성패는 「아무것도 아닌 것을 아무것도 아닌 채로 놓아두는 것」에
달려 있다.** 복선처럼 쓰면 망한다. 강조하지 않고, 되짚지 않고, 마지막에
다시 언급하지 않는다.

동시에 **S9의 값이 회수된다.** 이름이 붙은 물건은 이제 그냥 그 이름으로
불린다 — **명명의 값은 특별해지는 것이 아니라 평범해지는 것**이다.

## 2. 가드

### ⚠ ①(결석의 뒷일 — 닫히지 않는다)

- **6/28 화요일 하루 결석.** 이틀 아님. 영진이 담임(김주호)에게
  아프다고 둘러댔다 — **○ 언급까지**
- **EP61에서 이미 문자로 한 번 지나갔다.** 오늘은 **얼굴을 보는 것**이다
- **혜정 = 캐묻지 않는다.** 대신 **평소보다 말이 많다** —
  어제 있었던 시시한 일을 쏟는다. **절제는 수다 사이에서 온다**
- **★ 혜정 단답 금지.** 안 묻는 것은 **`어디`와 `왜` 둘뿐**이다.
  나머지는 평소대로 많이 말한다
- **예진 = 딴 얘기를 길게.** EP61의 `푹 자.` 계보 — 안 캐묻는 사람
- **★ EP32 약속은 회수하지 않는다.** 단아는 약속을 안 어겼는데,
  그걸 말하려면 **거짓말을 하나 더 해야 한다.** 그래서 말하지 않는다
- **금지:** 죄책감의 언어화 / 고백 충동 / 들킬 위기 / 혜정의 추궁 /
  사과 / **화해의 마무리**

### ⚠ ②(★ 은폐 장소 규칙 — 신설 상시 가드)

- **기체·앵커·장착 부품은 격납고 밖으로 안 나온다.**
  **앞마당은 조달 자재 적치까지**다
- 장착·해체 = 격납고 천장 크레인 + 체인블록, **두 시간.**
  **밖에서는 안 푼다**(BT-01A v0.3 §2-C)
- **동선:** 가게 → 지하 연결통로 → 격납고(LOC-02). 집은 단층
- **★ 이 은폐가 서 있어야 EP73 혜정의 목격이 사건이 된다**
- **금지:** 마당에 놓인 앵커 / 밖에서의 점검 / 이웃의 시선 비트

### ⚠ ③(표의 칸 — 결론 0)

- 수아의 점검표 **넉 장**(기체·개체·관측·집안일 — SNAP-061). 위치 = **상 위**
- **거기에 칸이 하나 는다 — `간격`.** 지난 것들을 소급해 채운다
- **★ 숫자를 지면에 적는다**(아라비아 숫자 규칙). 그리고 **고르지 않다**
- 왜 만드느냐 → **`적어 두면 나중에 보인다`**까지만.
  **패턴 0 · 추론 0 · 불안 0**
- **삼분법:** 수아 = 머리로 그림 / **단아는 그 칸을 대충 보고 넘긴다**
- **★ 수아 4금:** 잘난척 · 남 탓 · 변명 · 말 끊기
- **금지:** 수아가 뜻을 알아채는 것 / 영진이 의미를 짚어 주는 것 /
  칸을 이 화 끝에서 다시 언급하는 것

### ⚠ ④(성호 — 씨만 뿌린다)

- **100미터 3차 청구.** 봄부터 미뤄진 미결 채권
- **날짜를 안 정한다.** `이번엔 진짜`까지. **여기서 뛰지 않는다**
- 시비가 아니라 **채권 추심**의 어조(`dana-seongho-rivalry`)
- **화계:** 반말 대 반말. 단아가 피하지 않는다
- **금지:** 달리기 실행 / 승부 예고의 무게 / 성호의 걱정

### ⚠ ⑤(신호 — 위기감 0)

- 관측 단말 **하나**, 부표 **7·5·2**(정본 — 다른 번호 금지)
- **신호 한 건. 멀고, 방향만 안다.** 정체·크기·속도 0
- **정체 칸은 비워 둔다**(SNAP-061 `정체 칸 공란 유지` 승계)
- 단아는 보고 **자러 간다.** 「또 오는구나」 정도
- **금지:** 급박한 어휘 / 다음 화 예고 / 불길함의 명시 /
  가족의 긴장 고조

### ⚠ ⑥(문면 — 상시)

- **화계 5종:** 단아→영진 반말(교신 포함) / 단아→기태 존댓말 /
  **수아→단아 반말** / 수아→영진 존댓말 / 영진→기태 하게체
  — **★ 혼재 장면(Scene 4·5)은 청자별로 갈라 쓸 것.** 반복 유출 지점
- **서술문에서 영진 = `할아버지`.** `저 사람`·`그 노인` 금지
- **영진:** 왼팔 결손 — 팔짱·양손 동작 금지. **안경 0.** 한 손 기반
- **영진 지원 범위 §2-B:** 기술·경험·관측·절차·담백한 지지까지.
  **전략가로 쓰지 않는다**
- **정비 척도:** 공업 규모. 손걸레 계열 금지
- **숫자:** 구체 수치 = 아라비아 숫자 / 시각·어림치 = 한글
- **작가용 개체 명칭 0.** 봉인(세포기원·현서 장비·닻 표면 배양) 0
- **`아이언 앵커` = 가족 내부.** 밖에서 안 쓴다. 회당 2~3회 이하,
  **설명 0**

## 4. 문체 검색 (`STYLE_ONLY` — 장면 기능별)

**사건이 아니라 기능으로만 뽑는다.** 아래 지점의 **박자·문장 길이·
대사 행동**만 가져오고 **내용은 절대 가져오지 않는다.**

| 기능 | 참조 | 무엇을 뽑는가 |
| --- | --- | --- |
| 여름 아침 등교 | **EP41 §1**(6월 첫 화요일 아침) | 더위를 몸의 감각으로 여는 방식. **★ 같은 여름 아침이므로 어휘가 겹치지 않게 검수** |
| 학교 수다·미결 채권 | **EP58 학교부** | 아이들 대화의 밀도, 성호의 청구 어조 |
| 기록하는 손 | **EP61 §표**(수아가 칸을 만드는 장면) | 적는 행위를 사건으로 쓰지 않고 **그냥 적는** 박자. **★ 직전 화이므로 반복 위험 최대 — 구도를 바꿀 것** |
| 신호로 닫기 | **EP41 §5 말미**(부표 그래프·밤 바다 냄새) | 위기감 없이 닫는 마지막 문단의 호흡 |

**★ 반복 위험 경보 2건.** EP41(여름 아침)과 EP61(표)은 **가장 가까운
동형 장면**이다. 검색은 하되 **문장 구조를 의도적으로 다르게** 잡는다.
