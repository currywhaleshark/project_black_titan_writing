## 2. 회차 전체 리듬

```text
교실: 지우개가 먼저 움직인다 — 진짜 질문
→ 방과후: 한 송이 옆의 두 번째 송이 — 엄마 것도
→ 저녁 전: 두 질문 — 반쯤 돌았다 돌아오는 몸 — 끝내 줄 수 없는 이야기
→ 저녁: 구겨지게 달린 꽃 — 세 그릇 — 처음 말이 된 빈자리
→ 밤: 치우지 않은 꽃
```

- 문체 축은 **놓인 것들**이다 — 이 화의 감정은 발화가 아니라 물건의
  배치로 말한다: 두 송이의 간격, 반쯤 돈 몸, 세 그릇, 창틀의 꽃.
  해설은 전부 물건에게 양보.
- 시점: 전편 단아 밀착(5/10 화 하루). S2~S5 = 집.
- 씬 밴드: S1 1,100~1,400 / S2 1,000~1,300 / S3 1,400~1,700 /
  S4 1,200~1,500 / S5 500~800 (목표 5,800)
- 감정 화 주의: 무게는 침묵과 부작위로만. 잔소리·놀림의 온기는
  평소 온도 유지(EP25 계보). 아이다운 균열 2~3(멋쩍음·괜히 딴짓·
  물컵을 오래 쥠).

## 3. 장면별 문단 비트 잠금

### Scene 1 — 고마운 어른 (1,100~1,400자) ※ 교실

1. 활동지 시간 — **주호 범위 확장(잠금):** `부모님께 묻는 게 아니라,
   나를 돌봐 준 어른께 묻는 거다` 계열 1~2문장(가족 형태 비교 0,
   반 아이들 무명 배경 — 각자 쓰는 소리의 결만).
2. **고쳐 쓰기(잠금):** 첫 칸 질문 `왜 맨날 최악부터 생각하느냐`까지
   썼다가 — **지우개가 먼저 움직인다**(몸 먼저) — 지운 자리에
   **`왜 우리를 혼자 키웠느냐.`** 고쳐 쓴 뒤의 반 박자(자기가 쓴
   문장을 자기가 낯설어하는 결 — 해설 0).
3. **혜정 절제(잠금):** 옆자리 — 훔쳐보지 않고 자기 카네이션 카드만
   접는 손. 시선이 한 번 왔다가 종이로 돌아가는 반 컷(B1 상한 —
   발화 0).
4. 둘째 칸 = 여전히 공란(EP26 재서술 최소 — 1문장 상한).

### Scene 2 — 두 송이 (1,000~1,300자) ※ 방과후 집

1. 방과후 거실/방 — 수아의 색종이 카네이션. **한 송이는 완성**(철사
   줄기까지), **둘째를 접는 중.** 만들기의 손 서술(EP23 계보 —
   문장 0).
2. **문답(잠금 문면):** `하나는 할아버지 거고, 그건?` →
   **`엄마 것도 있어야 하는 것 같아서.`** — 수아 톤: 변명도 도전도
   아닌 조용한 당연함. 뒤에 덧붙임 0(설명하지 않는 아이).
3. **단아의 반 박자(잠금):** 언니로서 해 줄 말을 찾다가 못 찾는
   결 — `그러네` 계열 반 마디 상한. 아는 척의 재고가 비어 있다는
   자각(해설 0 — 멋쩍은 딴짓 1비트로).
4. 씬 마감: 책상 위 **두 송이의 나란함**(간격의 물성).

### Scene 3 — 물을 수 없던 것 (1,400~1,700자) ※ 심장

1. 저녁 전 가게/거실 — 계기의 겹침(두 송이가 보이는 자리 + 가방 속
   활동지). 공기가 바뀌는 반 박자.
2. **수아 먼저(§6-② 잠금):** `할아버지. 엄마는 어떤 사람이었어요?`
   계열 — 떠난 이유가 아니라 **사람**부터(한 발짝 뒤의 질문법).
3. **단아 직구(잠금):** 활동지의 문장이 입으로 — `왜 혼자 키웠어?`
   계열(공격이 아니라 궁금함의 직구 — 목소리 크기 평소).
4. **영진의 빈손(잠금 — §6-③ 1회):** 몸이 반쯤 돌았다가 — 어딘가로
   가려다 — 돌아온다. 무엇을 가지러 가려 했는지 서술 0(있는지조차).
   손이 빈 채로 식탁 모서리를 한 번 짚는 물성.
5. **잠금 문면:** 사이를 두고 — `……내가 대신 끝내 줄 이야기는
   아니다.` 추가 설명 0. **아이들은 더 밀지 않는다**(이 집의 문법 —
   침묵이 자리에 앉는 결. 수아가 조용히 두 송이를 자기 쪽으로 반 뼘
   당겨 놓는 비트 허용).
6. 침묵의 대가 — 영진의 얼굴 반 컷(감수하는 얼굴 — 형용 최소).

### Scene 4 — 세 자리의 저녁 (1,200~1,500자)

1. **카네이션 달기(잠금):** 단아 — 잔소리+고마움 동시 배출(`옷에
   구멍 나도 몰라` 계열 + **`왜 맨날 최악부터 생각해?`를 웃으며
   묻는 변주** — 낮의 진짜 질문과 수미 대구, 영진의 답은 실무형
   반 마디 허용). 접이꽃이 비뚜로·구겨지게 달리는 물성.
2. 수아의 국수 세 그릇 — 끓이고 나르는 손(EP25 문장 0). 잔소리
   공평 배분 1비트.
3. **공백의 발화(잠금 — 문면 후보):** 따뜻한 상에서, 웃음 끝에 —
   단아: `우리 셋이서도 꽉 차네` 하려다 `……셋이라 그런가, 좀 넓다`
   계열(문면은 초고에서 — **무겁지 않게, 그러나 처음으로** 세 자리의
   미완결이 말이 되는 순간. 발화자 = 단아 기본, 받는 침묵 = 둘).
4. 저녁의 종료 — 온기 유지(설거지·티격 반 비트).

### Scene 5 — 훅: 창틀 (500~800자) ※ 밤

1. 밤 — 단아, 물 마시러 내려옴(발소리 죽인 결).
2. **훅(개요 고정):** 소파/방 쪽 — 영진 가슴에 **구겨진 채 아직
   달려 있는** 카네이션(잘 때까지 안 뗀 꽃 — 관찰만). 수리점 창틀 —
   **받는 사람 없는 두 번째 카네이션**이 세워져 있다.
3. **부작위 컷(잠금):** `수아는 그것을 치우지 않았다.` 계열 마지막
   문장(해설 0 — 치우지 않았다는 사실만). 끝.
