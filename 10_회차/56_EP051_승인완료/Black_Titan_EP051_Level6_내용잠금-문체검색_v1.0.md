### ⚠ 가드 ①(기태 — 무서움은 닳지 않는다)

간격 17이다. 다시 세우되 **소개문을 새로 쓰지 않는다.**

| 요소 | 지면에서 | 출처 |
| --- | --- | --- |
| 소속 | 인양장에서 일하고 수리점에 낡은 장비를 맡기러 온다 | EP7·EP33 |
| 호칭 | **`박사님`**(영진에게). 영진은 **`기태야`** | EP26·EP33 |
| 말투 | **건들건들·통보하는 말투.** 묻는 게 아니라 정하고 통보한다 | EP33 |
| 행동 | **챙긴다.** 미는 방향이 안전한 쪽이고, 그늘진 자리를 고른다 | EP7·EP26 |

- **단아 쪽 = 여전히 무섭다(사용자 정정).** 인상도 말투도 그대로다.
  **완화·해소·친근함 0.** EP26의 모순(무섭게 구는 것과 챙기는 것이
  한 사람 안에)은 **풀리지 않은 채로** 유지된다
- **새로운 것은 상황이다.** EP7에서는 슬금슬금 피할 수 있었는데,
  오늘은 **피할 데가 없고 옆에서 같이 일해야 한다**
- **`기태야` 제압 그림은 이번 화에서 쓰지 않는다**(정본이되 매 출연
  반복하면 개그가 된다 — 사용자 지시)
- **문장 재사용 0:** `아는 얼굴이라고 안 무서운 게 아니다`(EP7),
  `무섭게 굴던 것과 챙겨 주는 것이…`(EP26), `어이, 조수. 그 펌프
  함부로 들지 마라`(EP33) — **전부 금지.** 기능만 전이

### ⚠ 가드 ②(닻을 묻는 법 — 3중 은폐)

**나중에 그것이 핵심이었다고 밝혀져도, 이 화를 다시 읽으면 단서가
없어야 한다.** 그래서 세 겹으로 묻는다.

1. **더미에 섞는다** — 개별 흥정 0. `저쪽 건 다 그냥 가져가세요`
   결로 **안 나가는 고철 더미째** 넘어온다
2. **화면에 안 싣는다** — 가게 트럭에 안 들어간다. **대형 트럭이
   며칠 뒤 따로** 온다. 이 화에서 닻은 **말로 한 번 스칠 뿐**이다
3. **아무도 안 본다** — 영진의 시선 정지 0·반응 0, 단아의 의문 0,
   기태의 부연 0

- **손을 얹어 보는 컷도 쓰지 않는다.** 만지면 그 순간 표시가 난다
- 이름은 한 번 지나가거나 **아예 안 지나가도 된다**

### ⚠ 가드 ③(작가용 봉인 — 이 화는 특히 쉽다)

**물건이 아직 안 왔으므로 노출할 것 자체가 없다.**

- 세포기원 소재·현서가 남긴 장비·표면 배양 — 전부 **0**
- **표면 질감 암시도 0.** 제작 전이니 아직 그냥 쇠다
- **앞마당 반입구도 0.** 확정된 정본이지만 이 화에서 열지 않는다
- 금지 어휘: `앵커`·`로켓`·`추진`·`클로`·`무기`·`배양`·`소재`·
  `현서`(장비 맥락)

### ⚠ 가드 ④(승계)

- **화계:** 단아→영진 **반말** / 단아→기태 **존댓말**(거래처 어른) /
  영진→기태 **반말**
- **시점 지칭:** 서술문에서 영진은 **`할아버지`**(`저 사람` 금지)
- **영진 왼팔 결손:** 한 손 기반 몸짓. 목록을 들고 물건을 가리키는
  동작이 많은 화이므로 **특히 주의**
- **혜정 = 미등장**(눈금 0) / **수아 = 동행 안 함**(작업 아니므로
  EP28 조건 무관) / **새 증상 0**

- **공간:** LOC-05 수리점·앞마당(**단층 촌집 동선**), **구래항
  인양장(신규)**, 돌아오는 길의 방재벽·수문(한 컷), 관측 단말
- **STYLE_ONLY:** C 문체 프로필·앵커, 말투카드 봄편 v0.4
- **금지:** 앵커 명명·설계 / 센티널·루시 / 정체 확정 / 출격·전투 /
  우편물 / `개수`·**`화`(회차 단위)** / `초여름`·`교복`·`인터넷` /
  EP7·EP26·EP33·EP41·EP50 문장 재사용

## 3. 장면별 잠금

### Scene 1 — 일요일 아침

- **고정:** 어젯밤 신호를 아무도 입에 올리지 않는데 영진이 아침부터
  트럭을 뺀다 / 단아가 따라나서는 이유 = **무거운 걸 들 사람**
  (본인도 그렇게 알고 있다) / 수아는 상 위의 표 넉 장(EP50 회수)
- **균열 ①:** 어젯밤 파형을 봤는데 오늘 하는 일이 고철 싣기라는 것.
  **불평이 아니라 어리둥절**
- **금지:** 신호에 대한 해석·불안의 언어화 / 목록의 용도 추측

### Scene 2 — 인양장

- **고정:** 물에서 건져 낸 것들이 마당에 쌓인 곳. 녹·물때·크레인·
  와이어. **소리가 큰 장소** / 기태 리마인드 4요소(가드 ①) /
  **단아는 여전히 무섭다 + 오늘은 못 피한다**
- **§6-6 첫 노출:** 인양장의 공간 — 건져 낸 것들의 결(물때·굴 껍데기·
  삭은 도색). **바다에서 나온 것은 다 무겁다**는 감각
- **금지:** 인물 소개문 / 무서움의 완화 / `기태야` 제압 / EP7·EP26의
  담장·크레인 반경 장면 재현

### Scene 3 — 한 줄

- **고정:** 두루뭉술한 줄들은 **무반응으로 통과** → **딱 한 줄에서
  손이 멈춘다** → **통보한다**(`이건 고철이 아닌데요` 결·캐묻기 0)
  → 영진의 **반쯤짜리 대답** → **기태도 더 안 묻는다** →
  **된다/안 된다만 정리**(어디 있고·언제 되고·뭐가 걸리는지)
- **단아의 자리:** 옆에서 본다. **어른 둘이 서로 안 묻는 것**을 본다
  (EP50 `안 물어보는 집`의 바깥판 — 문장 재사용 0)
- **금지:** 기태의 호기심·추측·농담성 캐물음 / 영진의 해설 /
  단아의 질문(이 장면에서는 안 묻는다)

### Scene 4 — 안 나가는 것들 ※ **가드 ② 집행 장면**

- **고정:** 마당 한쪽의 안 나가는 고철 더미 → **더미째 값을 안 받는다**
  (`저쪽 건 다 그냥 가져가세요` 결) → **가게 트럭에 안 들어간다** →
  **대형 트럭이 며칠 뒤에 따로** 온다
- **닻:** 더미의 여러 개 중 하나. **강조·시선·반응·의문 0.**
  손을 얹지 않는다
- **금지:** 개별 흥정 / 닻만 따로 언급 / 단아의 관심 / `제일 큰`
  계열의 수식(EP50 목록에서 이미 썼다 — 여기서 반복하면 표시가 난다)

### Scene 5 — 싣는 일

- **고정:** 가게 트럭에 **작은 것들**(사슬·도르래·강재 토막·용접봉) /
  **사람 몸의 척도** — 드는 것과 못 드는 것이 갈린다 / 못 드는 것은
  기계가 든다
- **EP50 회수(연결 문면 0):** 팔을 오래 들고 있는 일이 **처음으로
  쓸모를 보인다.** 단아는 **알아채지 못한다.** 독자만 안다.
  ※ `버티는`·`오래`라는 말로 연결을 만들지 않는다
- **기태의 챙김 1회 — 새 형태로.** 음료수·`허리 나간다` 계열 재사용
  금지. **무서운 사람이 챙기는 것이 여전히 안 풀린다**
- **균열 ②:** 손바닥·어깨의 감각. 열세 살의 피로
- **금지:** 단아의 자각·성장 서술 / 훈련과의 명시적 연결

### Scene 6 — 안쪽

- **고정:** 돌아오는 길에 **방재벽·수문 한 컷**(설명 0 — EP52~53·
  EP55~56 밑돌) / 수아의 관측 표에 어젯밤 줄 기입 / 개체 표의 빈 칸은
  여전히 빈 채 / 관측 단말 = **아직 있고 어제보다 안쪽**
- **끝:** 영진의 장부 — 오늘 실은 것들에 줄, **큰 것들 옆에는 날짜**
  (대형 트럭 오는 날). 그러고 관측 쪽을 본다. **해석 발화 0**
- **금지:** 정체·크기 추정 / 출격 준비 / 반입 방법 서술
